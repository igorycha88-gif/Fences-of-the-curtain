# Документация изменений: Добавление расчета типа забора "Евроштакетник"

## Обзор изменений

Добавлена полноценная поддержка расчета стоимости забора типа "Евроштакетник" в калькулятор. Расчет выполнен на основе модели PicketType (Евроштакетник) с учетом специфических параметров: тип профиля, покрытие, шаг установки и тип монтажа.

### 2. `src/services/calculator/picketCalculator.ts` (НОВЫЙ ФАЙЛ)

**Создан новый модуль для расчета евроштакетника:**

Основные функции:
- `calculatePicket()` - основная функция расчета количества евроштакетника
- `getActivePickets()` - получение активных евроштакетников из БД с кэшированием

**Интерфейсы:**
- `PicketCalculationResult` - результат расчета с деталями:
  - `category`: 'picket'
  - `nomenclatureId`, `nomenclatureName`, `quantity`, `unit`, `pricePerUnit`, `totalPrice`
  - `picketShape`, `picketCoating`, `picketStep`, `picketMountingType` - параметры расчета

- `PicketCalculationError` - ошибка при отсутствии подходящего евроштакетника

**Константы подписей:**
- `MOUNTING_TYPE_LABELS` - подписи типов монтажа (Односторонний, В шахматном порядке)
- `SHAPE_LABELS` - подписи типов профилей (П-образный, М-образный, Полукруглый)
- `COATING_LABELS` - подписи покрытий (Пластизол, Пурал и т.д.)

**Формулы расчета:**

Односторонний монтаж:
```
picketsPerRow = fenceLengthMm / (picketWidthMm + picketStepMm)
picketsCount = roundUp(picketsPerRow)
```

В шахматном порядке:
```
picketsPerRow = fenceLengthMm / (picketWidthMm + picketStepMm)
picketsCount = roundUp(picketsPerRow) * 2
```

**Кэширование:**
- Используется Redis с ключом `CACHE_KEYS.PICKETS_ACTIVE`
- TTL: `CACHE_TTL.REFERENCE_DATA`

**Поиск подходящего евроштакетника:**
- Фильтрация по: `length >= fenceHeightMm`, `picketShape`, `picketCoating`
- При отсутствии подходящего выбрасывается ошибка `NO_PICKET_FOUND`

**Расчет цены:**
- Цена за единицу рассчитывается на основе: `width * length * retailPricePerMeter / 1000000`

## Технические детали реализации

### Валидация

**На стороне клиента (UI):**
- Поля `picketShape`, `picketCoating`, `picketStep`, `picketMountingType` отображаются только при выборе типа забора "Евроштакетник"
- Все поля евроштакетника обязательны при условии, что выбран хотя бы один из них
- Шаг валидируется: целое число от 1 до 10 см

**На стороне сервера (API):**
- Проверка, что все параметры евроштакетника указаны корректно
- Ошибка `MISSING_PICKET_PARAMETERS` при неполных данных
- Ошибка `NO_PICKET_FOUND` при отсутствии подходящего евроштакетника в базе

### Формулы расчета

**Количество евроштакетников:**
- **Односторонний монтаж:** 
  - `picketsPerRow = fenceLengthMm / (picketWidthMm + picketStepMm)`
  - `picketsCount = roundUp(picketsPerRow)`
  
- **В шахматном порядке:**
  - `picketsPerRow = fenceLengthMm / (picketWidthMm + picketStepMm)`
  - `picketsCount = roundUp(picketsPerRow) * 2`

**Перевод единиц:**
- Длина забора: метры → миллиметры (`* 1000`)
- Шаг: сантиметры → миллиметры (`* 10`)
- Результат округляется вверх (используется `roundUp`)

**Цена за единицу:**
- `pricePerUnit = (width * length * retailPricePerMeter) / 1000000`
- `totalPrice = picketsCount * pricePerUnit`

### Поиск и выбор евроштакетника

**Критерии поиска:**
1. Активность: `active: true`
2. Срок действия: `validUntil` не истек или отсутствует
3. Длина: `length >= fenceHeightMm` (длина евроштакетника не меньше высоты забора)
4. Тип профиля: `picketShape` точно совпадает
5. Покрытие: `picketCoating` точно совпадает

**Приоритет сортировки:**
1. По приоритету (`priority: asc`)
2. По длине (`length: asc`)

**Обработка ошибок:**
- При отсутствии подходящего евроштакетника выбрасывается ошибка с детальной информацией
- Предлагается пользователю выбрать другие параметры или связаться с поддержкой

### Интеграция с существующей системой
