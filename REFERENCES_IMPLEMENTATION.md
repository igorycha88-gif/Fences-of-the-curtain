## Реализованные функции

#### Типы заборов (Fence Types)

## Как использовать

### 1. Доступ к разделу

1. Авторизуйтесь в админ-панели (admin@fences.ru / admin123)
2. В sidebar найдите раздел "Справочники"
3. Выберите нужный справочник:
   - Типы заборов
   - Высоты материалов
   - Типы покрытия
   - Лаги
   - Столбы

### 2. Управление типами заборов

1. Перейдите в "Справочники" → "Типы заборов"
2. Нажмите "Добавить" для создания нового типа
3. Заполните форму:
   - Название (обязательно)
   - Описание
   - Коэффициент сложности (0.5 - 3.0)
   - Шаг установки столбов (1.5 - 4.0 м)
   - Количество лаг (2 или 3)
   - Порядок сортировки
   - Активность
4. Нажмите "Создать"

### 3. Управление высотами материалов

1. Перейдите в "Справочники" → "Высоты материалов"
2. Найдите нужный материал в списке (используйте поиск)
3. Нажмите на карточку материала для раскрытия
4. Нажмите "+ Добавить высоту"
5. Заполните форму:
   - Высота (1.0 - 5.0 м)
   - Коэффициент цены (0.5 - 3.0)
   - Флаг нестандартной высоты
   - Комментарий (например, "Под заказ")
6. Нажмите "Добавить"

### 4. Управление типами покрытия

1. Перейдите в "Справочники" → "Типы покрытия"
2. Нажмите "Добавить" для создания нового типа
3. Заполните форму:
   - Название (обязательно)
   - Описание
   - Базовая стоимость (руб/м²)
   - Коэффициент наценки (1.0 - 3.0)
   - Порядок сортировки
   - Активность
4. Нажмите "Создать"

### 5. Управление лагами

1. Перейдите в "Справочники" → "Лаги"
2. Нажмите "Добавить" для создания новой лаги
3. Заполните форму:
   - Название (обязательно)
   - Описание
   - Ширина сечения (20 - 100 мм)
   - Высота сечения (20 - 100 мм)
   - Толщина металла (1.0 - 5.0 мм)
   - Базовая цена за метр погонный (руб)
   - Порядок сортировки
   - Активность
4. Нажмите "Создать"

### 6. Управление столбами

1. Перейдите в "Справочники" → "Столбы"
2. Нажмите "Добавить" для создания нового столба
3. Заполните форму:
   - Название (обязательно)
   - Описание
   - Ширина сечения (40 - 120 мм)
   - Высота сечения (40 - 120 мм)
   - Толщина стенки (1.5 - 5.0 мм)
   - Цена за метр погонный (руб)
   - Цена с бетонированием (руб/шт)
   - Порядок сортировки
   - Активность
4. Нажмите "Создать"
