## Нерешённые проблемы

### ⚠️ PROB-003: Недетерминированная сортировка панелей

**Проблема:** Prisma возвращает панели в непредсказуемом порядке

**Симптомы:**
- Тест TC-LKP-001 ожидает `3D-панель 2000x2500` (width 2500)
- calculatePanel3D возвращает панель с `panelWidth: 3000`
- Тест TC-CAL-001 получает `quantity: 17` вместо `20`

**Причина:** Prisma использует внутренний ID записи для сортировки, а не только поля `priority` и `panelHeight`

**Попытки исправления:**
1. Добавлен `orderBy: { id: 'asc' }` - не помогло
2. Отключено использование кэша в `calculatePanel3D` - не помогло
3. Перегенерирован Prisma Client - не помогло

**Влияние:** Тесты не могут проверять правильный подбор панели

**Статус:** Требуется глубокая отладка или изменение архитектуры
