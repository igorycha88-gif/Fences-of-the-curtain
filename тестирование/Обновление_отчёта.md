## Новые проблемы

### PROB-001: Redis недоступен

**Ошибка:**
```
[Cache] Redis error, falling back to memory: calculator:panel3d:active
Error: Stream isn't writeable and enableOfflineQueue options is false
```

**Влияние:**
- Кэш работает в памяти
- Каждый запрос читает из БД
- Потенциальные проблемы с производительностью

**Решение:** Запустить Redis контейнер:
```bash
docker-compose up -d redis
```

---

### PROB-002: Тесты ожидают фиксированные ID

**Пример:**
```javascript
expect(result.nomenclatureId).toBe('test-panel-2000');
```

**Причина:** Seed создаёт записи с автогенерируемыми ID (CUID)

**Влияние:** Тесты TC-LKP-001, Активные панели, validUntil проваливаются

**Решение:** Использовать реальные ID из БД:
```javascript
beforeAll(async () => {
  const panels = await prisma.panel3D.findMany();
  testPanel2000Id = panels.find(p => p.name.includes('2000x2500'))?.id;
});
```
