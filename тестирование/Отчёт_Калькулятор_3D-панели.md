## 3. Обнаруженные дефекты

### BUG-001: Некорректный расчёт количества панелей
**Серьёзность:** High  
**Локация:** `src/services/calculator/panel3DCalculator.ts:78`

**Описание:**
Количество панелей рассчитывается с добавлением +2 к результату:
```typescript
const panelsCount = roundUp(fenceLengthMm / usefulWidth) + 2;
```

**Ожидаемое поведение (по ЧТЗ):**
```typescript
const panelsCount = roundUp(fenceLengthMm / usefulWidth);
```

**Влияние:**
- Расчёт стоимости завышается на 2 панели × цена панели
- Пример: для забора 50м с ценой 5000₽/шт - завышение на 10 000₽

**Пример:**
- Длина забора: 50 м (50000 мм)
- Ширина панели: 2500 мм
- По ЧТЗ: 50000 / 2500 = 20 панелей
- Фактически: roundUp(50000 / 2500) + 2 = 22 панели
- Завышение: 2 панели = 10 000₽

---

### BUG-002: Архитектура отличается от ЧТЗ
**Серьёзность:** Low  
**Локация:** Структура проекта

**Описание:**
- В ЧТЗ запланированы отдельные модули `panel3DLookup.ts` и `panel3DCalculator.ts`
- В реализации логика поиска объединена с расчётом в одном файле `panel3DCalculator.ts`
- Модуль `panel3DLookup.ts` отсутствует

**Влияние:**
- Тесты, написанные по ЧТЗ, импортируют несуществующий модуль
- Усложняет поддержку и тестирование

**Рекомендация:**
Сохранить текущую архитектуру (упрощённая версия) или создать `panel3DLookup.ts` для соответствия ЧТЗ

---
