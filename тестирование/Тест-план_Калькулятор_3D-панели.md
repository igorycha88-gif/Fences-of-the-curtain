## 1. Введение

### 1.1 Цель тестирования
Проверить корректность реализации калькулятора забора из 3D-панелей согласно требованиям ЧТЗ v1.0.

### 1.2 Объект тестирования
- Справочник 3D-панелей (Panel3D)
- Калькулятор 3D-панелей
- Интеграция в fenceEstimateService
- API для управления справочником
- UI в админ-панели

---

## 2. Тестовая стратегия

### 2.1 Уровни тестирования

| Уровень | Инструменты | Покрытие |
|---------|-------------|----------|
| Unit-тесты | Jest | Критичные бизнес-логики |
| Integration-тесты | Jest + Supertest | API и сервисы |
| E2E-тесты | Playwright | Критические пользовательские сценарии |

### 2.2 Приоритеты тестирования

**Высокий приоритет (P0):**
- Подбор 3D-панели по высоте
- Расчёт количества панелей
- Расчёт высоты столбов (+1200 мм)
- Подбор фурнитуры и работ
- API для расчёта сметы

**Средний приоритет (P1):**
- CRUD операции в админ-панели
- Привязка фурнитуры и работ
- Фильтрация и пагинация
- Ворота и калитка

**Низкий приоритет (P2):**
- UI/UX в админке
- Валидация на клиенте
- Импорт/экспорт

## 5. E2E-тесты

**Файл:** `e2e/calculator-panel3d.spec.ts`

### 5.1 Критические сценарии

#### TC-E2E-001: Расчёт забора из 3D-панелей
**Приоритет:** P0

**Предусловия:**
- Пользователь авторизован
- В справочнике есть активные панели

**Шаги:**
1. Открыть страницу калькулятора
2. Выбрать тип забора "3D-панели"
3. Ввести длину: 50 м
4. Ввести высоту: 2.0 м
5. Выбрать количество лаг: 2
6. Нажать "Рассчитать"
7. Проверить результат

**Проверки:**
- Отображается категория "3D-панели"
- Количество: 20 шт
- Спецификации: высота 2000 мм, ширина 2500 мм
- Столбы: высота 3200 мм, количество 21 шт
- Итого совпадает с ожидаемым

#### TC-E2E-002: Расчёт с воротами
**Приоритет:** P0

**Шаги:**
1. Открыть калькулятор
2. Выбрать тип забора "3D-панели"
3. Ввести длину: 50 м
4. Установить флаг "Ворота"
5. Выбрать тип "Распашные"
6. Ввести ширину: 3.5 м
7. Нажать "Рассчитать"

**Проверки:**
- Ворота добавлены в смету
- Длина забора скорректирована: 50 - 3.5 = 46.5 м
- Панели рассчитаны для 46.5 м

#### TC-E2E-003: Расчёт с калиткой
**Приоритет:** P0

**Шаги:**
1. Открыть калькулятор
2. Выбрать тип забора "3D-панели"
3. Установить флаг "Калитка"
4. Ввести ширину: 1.0 м
5. Нажать "Рассчитать"

**Проверки:**
- Калитка добавлена в смету
- Длина забора скорректирована

#### TC-E2E-004: Расчёт с воротами и калиткой
**Приоритет:** P0

**Шаги:**
1. Открыть калькулятор
2. Выбрать тип забора "3D-панели"
3. Длина: 50 м
