**Источник:** 4 книги (Косарев «36 фильтров Google», Молочков «Самоучитель», Бардин «Толковое руководство», «SEO в эпоху ИИ») — аудит от 2026-10-20
**Маршрут:** Аналитик → Разработчик → Тестировщик (DevOps не требуется — markdown-файлы, рантайм не затронут)

## Цель

Любая SEO-задача в проекте выполняется по правилам, выведенным из 4 книг. Правила оформлены как скилл opencode, который обязан загружаться при SEO-задачах (метатеги, страницы, контент, гео, sitemap, robots, скорость, разметка).

## Задачи

1. **TASK-FRT-001**: Создать `.opencode/skills/seo-development/SKILL.md`:
   - frontmatter: `name: seo-development`, description с триггерами («Use for ANY SEO task...»)
   - содержание: чек-листы по книгам (см. структуру ниже)
2. **TASK-DOC-001**: Добавить строку скилла в таблицу скиллов в `AGENTS.md` (раздел 9) с пометкой «обязателен при SEO-задачах».

## Структура скилла (обязательные блоки)

1. Триггеры применения (когда загружать)
2. 10 железных SEO-правил (нарушение = баг): лимиты метатегов (title ≤ 74 / desc ≤ 160 — константы проекта), честный lastmod, один H1, alt без «фото N», next/image в публичных, детерминированная вариативность, канониклы, уникальность гео-страниц, SSL+скорость, перелинковка
3. Чек-лист новой/изменяемой страницы
4. Контент-требования (уникальность, плотность ключей 3–5%, LSI, E-E-A-T, цифры вместо прилагательных)
5. Гео-страницы (Pigeon/Possum: NAP, отзывы по городам, никакого клонирования)
6. Анти-паттерны (запреты: Math.random, фиктивный lastmod, keyword stuffing, дубли, `<img>` в публичных, клише)
7. SEO-чек-лист Тестировщика (проверка при приёмке SEO-задач)
8. Источники — 4 книги и где лежат

## Критерии приёмки

1. Скилл лежит в `.opencode/skills/seo-development/SKILL.md`, frontmatter валиден (name совпадает с папкой, description с триггерами в третьем лице).
2. Правила из всех 4 книг отражены (Бардин: URL/alt/перелинковка/скорость; Косарев: фильтры Panda/Pigeon/TrustRank/переоптимизация; Молочков: title/уникальность/мобильность/аналитика; «ИИ»: вопросные запросы/E-E-A-T/брендинг).
3. AGENTS.md ссылается на скилл.
4. Пройдены проверки структуры (markdown-lint не требуется; frontmatter парсится).
