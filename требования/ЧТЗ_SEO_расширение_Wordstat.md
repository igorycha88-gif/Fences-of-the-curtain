# ЧТЗ: SEO-расширение сайта по данным Wordstat (Wordstat Top Queries)

## 1. Цель задачи

Закрыть выявленные SEO-пробелы по данным анализа Wordstat (2 730 запросов, срез ≥300 + гео полностью): создать посадочные страницы под высокочастотные кластеры спроса, дополнить существующие страницы недостающими подкластерами, добавить информационные статьи в блог.

**Бизнес-результат:** охват ~650 тыс. дополнительных показов/мес по кластерам: откатные ворота (426 030), забор жалюзи (59 455), забор под ключ (43 602), арочный/двускатный навес (15 067), шахматка (4 937), металлочерепица (1 109).

## 2. Маршрутизация

- Маршрут: 2 (сложная задача, ADR создан — расширение по существующим паттернам, без изменения архитектуры)
- Исполнитель после ЧТЗ: 💻 Разработчик
- Ветка: `master2`

## 3. Архитектурное решение (ADR, кратко)

- Новые страницы услуг: **статические `page.tsx`** по паттерну `src/app/(public)/garazhi-iz-sendvich-panelej/page.tsx`
- Статьи блога: через **модель `BlogPost` в Prisma** (seed-скрипт)
- **Без миграций БД** (новые модели не нужны)
- SEO: `generatePageMetadata` (`src/lib/seo/metadata.ts`), JSON-LD (Service + FAQPage + BreadcrumbList), sitemap — обновить
- Компоненты: готовые `Breadcrumbs`, `JsonLdScript`, `LeadForm`, `CommercialFactors`, `FaqAccordion`, `Header/Footer`
- Логирование: серверных операций нет (статические страницы) — логирование в seed-скрипте и в LeadForm уже есть; новые клиентские формы не создаются

## 5. Требования к SEO-метаданным каждой новой страницы

- Title: `[Ключевой запрос] — цена за [метр/штуку] | Заборы и Навесы` (≤70 симв.)
- Description: с ключом + гео «Московская область» + CTA (≤160)
- Keywords: топ-10 запросов кластера (из анализа Wordstat)
- Canonical, OG, robots: index,follow — через `generatePageMetadata`
- H1 = главный запрос кластера; H2 = подкластеры
