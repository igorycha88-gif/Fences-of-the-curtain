## 1. Описание задачи

Создать новый справочник «Автоматика» (приводы, моторы, пульты для ворот) с полной интеграцией в бизнес-процесс:
- Админ-панель: CRUD номенклатуры с ценами, связями работ и фурнитуры
- Пользовательский калькулятор: опциональное добавление автоматики к **откатным воротам**
- Смета: номенклатура автоматики попадает в смету наравне с воротами
- Админ-калькулятор: добавление/удаление автоматики как любого другого номенклатурного элемента

## 3. Техническая спецификация

### 3.1. Модель БД: `AutomationType`

```prisma
model AutomationType {
  id             String    @id @default(cuid())
  name           String
  description    String?
  retailPrice    Float
  purchasePrice  Float?
  image          String?
  active         Boolean   @default(true)
  validFrom      DateTime?
  expirationDate DateTime?
  createdAt      DateTime  @default(now())
  updatedAt      DateTime  @updatedAt
  priority       Int       @default(0)

  @@index([active])
  @@index([validFrom])
  @@index([expirationDate])
  @@index([priority])
  @@index([name])
}
```

**Обоснование полей:**
- `name` — название (например: «Привод CAME BK-1200», «NICE ROBUS 600»)
- `description` — описание, характеристики
- `retailPrice` — розничная цена (видна всем)
- `purchasePrice` — цена закупки (только ADMIN, nullable)
- `image` — изображение (для будущего использования)
- `active`, `validFrom`, `expirationDate` — стандартные поля управления доступностью
- `priority` — порядок сортировки

**Почему модель проще чем GateType:** Автоматика не имеет размеров/толщин — это законченный комплект с фиксированной ценой. Подбор автоматики по воротам не нужен — пользователь выбирает из списка.
