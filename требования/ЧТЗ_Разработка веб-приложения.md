## 1. Общая информация

## 2. Цели и задачи

### 2.1 Бизнес-цель
Создать современный веб-сайт для привлечения клиентов, предоставляющий онлайн-калькуляторы стоимости работ с возможностью автоматической отправки заявок менеджерам.

### 2.2 Пользовательская ценность
Клиенты могут быстро рассчитать стоимость забора или навеса онлайн, изучить услуги, просмотреть портфолио работ и оставить заявку без необходимости звонить в офис.

### 2.3 Ключевые метрики успеха
- Время загрузки главной страницы < 3 секунд
- Конверсия расчет → заявка ≥ 10%
- Поддержка одновременной работы 100+ пользователей

## 3. Требования к продукту

### 3.1 Функциональные требования

#### Публичная часть сайта

**User Story 1: Главная страница**
*Как посетитель сайта, я хочу увидеть на главной странице информацию о компании, преимущества, ссылки на калькуляторы и примеры работ, чтобы понять, что компания надежная и профессиональная.*

**Acceptance Criteria:**
- Хедер с логотипом, навигацией, контактным телефоном
- Hero-блок с заголовком, подзаголовком, CTA-кнопками ("Рассчитать забор", "Рассчитать навес")
- Блок преимуществ компании (3-6 пунктов с иконками)
- Ссылки на калькуляторы с визуальными превью
- Секция портфолио с галереей работ (3-6 превью)
- Отзывы клиентов (3-5 отзывов с рейтингом)
- Форма обратной связи (Имя, Телефон, Сообщение)
- Футер с контактами, реквизитами, соцсетями, навигацией
- Адаптивная верстка (mobile-first)
- Мобильная навигация (бургер-меню)

**User Story 2: Калькулятор забора**
*Как потенциальный клиент, я хочу рассчитать стоимость забора онлайн, указав параметры, чтобы получить предварительную оценку.*

**Acceptance Criteria:**
- Пошаговый или табличный интерфейс ввода параметров
- Поля ввода: тип забора, длина, высота, тип столбов, тип лаг, количество лаг, наличие калитки/ворот, тип покрытия, цвет, тип грунта, регион
- Визуализация выбранного типа забора (иконка/изображение)
- Мгновенный пересчет при изменении параметров
- Валидация всех полей (числовые диапазоны, обязательные поля)
- Отображение детального расчета: материалы, работы, итоговая сумма
- Кнопка "Скачать PDF"
- Кнопка "Заказать расчет" (отправка заявки)
- Сохранение расчета в localStorage для повторного доступа

**User Story 3: Калькулятор навеса**
*Как потенциальный клиент, я хочу рассчитать стоимость навеса онлайн, указав параметры, чтобы получить предварительную оценку.*

**Acceptance Criteria:**
- Поля ввода: тип навеса, назначение, длина, ширина, высота, материал каркаса, материал кровли, тип установки, наличие водосточной системы
- Визуализация типа навеса
- Мгновенный пересчет
- Валидация полей
- Детальный расчет: материалы, работы, итог
- Кнопка "Скачать PDF"
- Кнопка "Заказать расчет"
- Отображение чертежа с размерами (заглушка)

**User Story 4: Страница услуг**
*Как посетитель сайта, я хочу подробно ознакомиться с услугами компании и ценами, чтобы принять решение о заказе.*

**Acceptance Criteria:**
- Детальное описание каждого типа забора с фото
- Детальное описание каждого типа навеса с фото
- Цены на базовые комплекты
- Сроки выполнения работ
- Ссылки на соответствующие калькуляторы

**User Story 5: Портфолио**
*Как посетитель сайта, я хочу посмотреть примеры выполненных работ с фотографиями, чтобы оценить качество работы компании.*

**Acceptance Criteria:**
- Категории работ (заборы, навесы)
- Фильтрация по типу, материалу
- Галерея с возможностью увеличения фото
- Описание проекта
- Стоимость (опционально, по решению заказчика)

**User Story 6: Страница контактов**
*Как посетитель сайта, я хочу найти контактную информацию компании и посмотреть расположение офиса на карте.*

**Acceptance Criteria:**
- Карта с маркером офиса (Яндекс.Карты)
- Телефоны
- Email
- Режим работы
- Адрес
- Форма обратной связи
- Реквизиты компании

### 3.2 Нефункциональные требования

#### Производительность
- Время загрузки главной страницы < 3 секунд
- Время расчета калькулятора < 2 секунд
- Поддержка одновременной работы 100+ пользователей
- Оптимизация изображений (WebP, lazy loading)

#### Безопасность
- HTTPS протокол (SSL сертификат)
- Защита от SQL-инъекций (Prisma ORM)
- Защита от XSS-атак
- CSRF защита (встроена в Next.js)
- CAPTCHA в формах обратной связи (Google reCAPTCHA v3)
- Резервное копирование БД (ежедневно)
- Rate limiting на API endpoints (Redis)
- Санитизация пользовательского ввода

#### Масштабируемость
- Docker контейнеризация для легкого масштабирования
- Redis для кеширования
- Возможность горизонтального масштабирования приложения
- Оптимизация базы данных (индексы, запросы)

#### Совместимость
- Поддержка браузеров: Chrome, Firefox, Safari, Edge (последние 2 версии)
- Адаптивная верстка (desktop: 1920px+, tablet: 768-1024px, mobile: 320-767px)
- Минимальное разрешение экрана: 320px

#### Доступность
- Семантическая разметка (HTML5)
- ARIA атрибуты для скринридеров
- Контрастность цветов соответствует WCAG AA

## 5. API спецификация

### 5.1 Публичные API

#### POST /api/calculator/fence
Расчет стоимости забора

**Request:**
```json
{
  "fenceType": "PROFNASTIL",
  "length": 50,
  "height": 2.0,
  "postType": "post-id",
  "lagType": "lag-id",
  "lagRows": 2,
  "hasGate": true,
  "gateType": "SWING",
  "gateWidth": 4.0,
  "hasWicket": true,
  "wicketWidth": 1.0,
  "coating": "GALVANIZED",
  "color": "5005",
  "soilType": "soil-id",
  "region": "Москва"
}
```

**Response 200:**
```json
{
  "materials": [
    {
      "name": "Профнастил С8",
      "quantity": 100,
      "unit": "м²",
      "pricePerUnit": 450,
      "total": 45000
    }
  ],
  "works": [
    {
      "name": "Монтаж забора",
      "quantity": 50,
      "unit": "м.п.",
      "pricePerUnit": 800,
      "total": 40000
    }
  ],
  "materialsTotal": 50000,
  "worksTotal": 45000,
  "soilSurcharge": 5000,
  "grandTotal": 100000
}
```

**Validation:**
- length: number, min 10, max 1000
- height: number, min 1.5, max 3.5
- lagRows: enum 2|3
- coating: enum GALVANIZED|POLYMER_SINGLE|POLYMER_DOUBLE

**Кто должен согласовать ЧТЗ:**
- ✅ Заказчик (инициатор)
- ✅ Техлид / Архитектор
- ✅ Бизнес-аналитик (автор)

**Сроки согласования:**
- Черновик: 3-5 дней на ревью
- Финальная версия: 1-2 дня на утверждение

**Механизм обратной связи:**
- Комментарии в документе
- Встреча для обсуждения (если нужно)
- Финальное утверждение в чате/email

### 11.2 Критерии готовности к разработке

- ✅ Все заинтересованные стороны согласовали ЧТЗ

- ✅ Предоставлены материалы от заказчика (логотип, контент)

### 11.3 Механизм внесения изменений

**Процесс:**
1. Изменения фиксируются в новом разделе или примечании
2. Обновляется версия документа (1.1, 1.2...)
3. Повторное согласование с ключевыми стейкхолдерами
4. Зафиксировать версию для реализации

**Уровни согласования для изменений:**
- Незначительные изменения (опечатки, уточнения): аналитик + техлид
- Средние изменения (новые требования, приоритеты): все стороны
- Критические изменения (архитектура, сроки): все стороны + утверждение заказчика

## Приложение А: Формулы расчета

### Расчет забора

```
Стоимость материалов =
  (Стоимость профнастила/штакетника × Площадь) +
  (Стоимость столбов × Количество столбов) +
  (Стоимость лаг × Длина лаг) +
  (Стоимость ворот) +
  (Стоимость калитки) +
  (Стоимость крепежа)

Количество столбов = (Длина забора / 2.5) + 1

Длина лаг = Длина забора × Количество рядов лаг

Стоимость работ =
  (Длина забора × Стоимость монтажа за м.п.) +
  (Количество столбов × Стоимость бетонирования) +
  (Стоимость установки ворот) +
  (Стоимость установки калитки)

Итого = (Стоимость материалов + Стоимость работ) × Коэффициент грунта
```

### Расчет навеса

```
Площадь кровли = Длина × Ширина × Коэффициент_типа_навеса
  (для односкатного = 1.0, для двускатного ≈ 1.1, для арочного ≈ 1.15)

Стоимость материалов кровли = Площадь кровли × Цена материала за м²

Периметр навеса = (Длина + Ширина) × 2

Стоимость каркаса =
  (Периметр × Цена профиля для обвязки) +
  (Количество стропил × Длина стропил × Цена профиля) +
  (Количество опор × Высота × Цена профиля для опор)

Стоимость работ = Площадь кровли × Стоимость монтажа за м²

Итого = Стоимость материалов + Стоимость работ + Дополнительные элементы
```
