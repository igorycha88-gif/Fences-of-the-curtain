## 2. Цели и задачи

### 2.1 Бизнес-цель
Предоставить клиентам возможность самостоятельно рассчитать стоимость забора онлайн с актуальными ценами, а администраторам - гибкий инструмент управления параметрами расчета без участия разработчиков.

### 2.2 Пользовательская ценность
Клиенты получают быстрый предварительный расчет стоимости забора с детализацией материалов и работ, а менеджеры могут оперативно актуализировать цены и добавлять новые материалы через удобный интерфейс.

### 2.3 Ключевые метрики успеха
- Время расчета < 2 секунд
- Конверсия расчет → заявка ≥ 15%
- Время обновления цен админом < 5 минут
- Актуальность данных (разница между ценами в админке и прайс-листе ≤ 1%)

## 3. Требования к продукту

### 3.1 Функциональные требования

#### Публичная часть: Калькулятор забора

**User Story 1: Выбор типа забора**
*Как потенциальный клиент, я хочу выбрать тип забора из списка доступных вариантов, чтобы увидеть соответствующие материалы и цены.*

**Acceptance Criteria:**
- Список типов заборов (профнастил, евроштакетник, сетка-рабица, 3D-панели)
- Для каждого типа показывается изображение, название и краткое описание
- При выборе типа автоматически фильтруются материалы
- Отображение базовой цены за м² для выбранного типа

**User Story 2: Ввод параметров забора**
*Как потенциальный клиент, я хочу ввести параметры забора (длина, высота, столбы, лаги), чтобы получить точный расчет.*

**Acceptance Criteria:**
- Поля ввода:
  - Длина забора (м) - обязательное, min 10, max 1000, шаг 1
  - Высота забора (м) - обязательное, min 1.5, max 3.5, шаг 0.1
  - Тип столбов - выбор из справочника PostType
  - Толщина столбов (мм) - выбор из доступных толщин для выбранного типа столба (настраивается в админке)
  - Тип лаг - выбор из справочника материалов (категория LAGS)
  - Толщина лаг (мм) - выбор из доступных толщин для выбранного типа лаги (настраивается в админке)
  - Количество рядов лаг - выбор 2 или 3
- Наличие калитки:
  - Чекбокс "Наличие калитки"
  - При активации: выпадающий список типов калиток (GATES категории)
  - Поле ширины калитки (м) - min 0.8, max 1.5, шаг 0.1
- Наличие ворот:
  - Чекбокс "Наличие ворот"
  - При активации:
    - Выпадающий список типов ворот (распашные или откатные)
    - Поле ширины ворот (м) - min 2.5, max 6.0, шаг 0.1
    - Чекбокс "Автоматические ворота" (опционально)
    - При выборе автоматических: показывается надбавка к стоимости (настраивается в админке)
- Тип профиля (для профнастила/штакетника):
  - Выпадающий список из доступных профилей
  - Для каждого профиля показывается толщина металла (настраивается в админке)
- Тип покрытия:
  - Выпадающий список (оцинковка, полимерное одностороннее, полимерное двустороннее)
- Цвет (палитра RAL) - выбор из предопределенного списка
- Тип грунта:
  - Выпадающий список из справочника SoilType
  - Показывается коэффициент удорожания (%)
- Регион установки - текстовое поле (опционально)
- Валидация всех полей на клиенте (Zod)
- Автоматический пересчет при изменении любого параметра

**User Story 3: Просмотр результатов расчета**
*Как потенциальный клиент, я хочу видеть детальный расчет стоимости с разбивкой на материалы и работы, чтобы понимать, из чего складывается цена.*

  - Сумма по позиции

**User Story 4: Сохранение и скачивание расчета**
*Как потенциальный клиент, я хочу сохранить расчет и скачать его в PDF, чтобы показать семье или обсудить с менеджером.*

**User Story 5: Отправка заявки по расчету**
*Как потенциальный клиент, я хочу отправить расчет менеджеру для уточнения деталей и заказа.*

**Acceptance Criteria:**
- Кнопка "Заказать расчет"

  - Имя (обязательное, 2-100 символов)
  - Телефон (обязательное, regex для РФ)

**User Story 7: Управление материалами для заборов**
*Как менеджер, я хочу управлять справочником материалов, чтобы актуализировать цены и добавлять новые.*

**Acceptance Criteria:**
- Список материалов с таблицей (пагинация 20 записей)
- Колонки: Название, Категория, Цена, Единица, Активность, Действия
- Фильтрация по категориям:
  - Профнастил
  - Евроштакетник
  - Сетка
  - 3D-панели
  - Столбы
  - Лаги
  - Ворота
  - Калитки
  - Крепеж
- Создание нового материала:
  - Название (обязательное)
  - Категория (выбор из enum)
  - Единица измерения (м², м.п., шт, кг) - обязательная
  - Базовая цена за единицу (float, обязательная)
  - Описание (опциональное)
  - Изображение (загрузка файла)
  - Характеристики:
    - Толщина (float, опционально) - для категорий STAKHETNIK, PROFNASTIL, POSTS, LAGS
    - Ширина (float, опционально)
    - Высота (float, опционально)
    - Тип покрытия (string, опционально)
  - **Доступные толщины (для категорий PROFNASTIL, POSTS, LAGS):**
    - Массив чисел (мм), которые пользователь может выбрать в калькуляторе
    - Например: [0.4, 0.5, 0.6, 0.7] для профнастила
    - Для каждой толщины может быть своя цена (опционально)
  - Активность (boolean, default true)
  - Порядок сортировки (int, default 0)
- Редактирование материала (все поля)
- Массовое обновление цен (batch operation)
- Активация/деактивация
- Удаление (с проверкой на использование)
- Поиск по названию
- Экспорт/импорт материалов в Excel/CSV

**User Story 7.1: Управление ценами по толщинам**
*Как менеджер, я хочу указывать разные цены для разных толщин одного материала.*

**Acceptance Criteria:**
- При создании/редактировании материала можно задать массив цен по толщинам
- Структура: `[{ thickness: 0.5, price: 500 }, { thickness: 0.7, price: 700 }]`
- В калькуляторе пользователь выбирает толщину, а цена берется из соответствующей записи
- Если для выбранной толщины нет цены, используется базовая цена материала

**User Story 8: Управление типами столбов**
*Как менеджер, я хочу управлять типами столбов, чтобы актуализировать цены и технические характеристики.*

**User Story 10.1: Управление опциями ворот**

### 3.2 Нефункциональные требования

#### Производительность
- Время расчета < 2 секунд для любого набора параметров
- Время загрузки страницы калькулятора < 2 секунд
- Время загрузки данных из БД < 500 мс
- Кеширование материалов в Redis (TTL 5 минут)
- Оптимизация изображений (WebP, lazy loading)

#### Безопасность
- Авторизация required для всех эндпоинтов админки
- Ролевой доступ:
  - ADMIN: полный доступ ко всем операциям
  - MANAGER: чтение и редактирование, без удаления
  - CONTENT_MANAGER: только чтение и редактирование материалов и типов
- Rate limiting на public API (100 запросов/мин)
- Валидация всех входных данных (Zod)
- Логирование всех изменений в админке

#### Масштабируемость
- Пагинация списков в админке (20-50 записей на странице)
- Lazy loading для материалов
- Оптимизированные SQL запросы с индексами
- Кеширование частых запросов

#### Совместимость
- Поддержка браузеров: Chrome, Firefox, Safari, Edge (последние 2 версии)
- Адаптивная верстка для мобильных устройств
- Минимальное разрешение экрана: 320px

// Расширение модели FenceMaterial
model FenceMaterial {

// Новая модель для опций ворот
model GateOption {

## Приложение А: Детальные формулы расчета

### Формулы для калькулятора забора

#### 1. Количество столбов
```
postsCount = Math.ceil(length / 2.5) + 1
```
- Шаг установки столбов: 2.5 метра
- Округление вверх до целого числа

#### 2. Количество лаг
```
lagsLength = length * lagRows
```
- lagRows: 2 или 3 ряда

#### 3. Площадь покрытия
```
coverageArea = length * height
```

#### 4. Стоимость материалов
```
// Цена материала в зависимости от выбранной толщины
const profilePrice = getProfilePrice(profileId, selectedThickness)
const postPrice = getPostPrice(postId, selectedPostThickness)
const lagPrice = getLagPrice(lagId, selectedLagThickness)

materialsCost =
  (coverageArea × profilePrice) +
  (postsCount × postPrice) +
  (lagsLength × lagPrice) +
  (hasGate ? gatePrice : 0) +
  (hasWicket ? wicketPrice : 0) +
  (fastenersCost)

// Функция получения цены по толщине
function getProfilePrice(profileId, thickness) {
  const profile = materials.find(m => m.id === profileId)
  const priceEntry = profile.thicknessPrices?.find(p => p.thickness === thickness)
  return priceEntry ? priceEntry.price : profile.basePrice
}
```

#### 5. Стоимость работ
```
worksCost =
  (length × fenceInstallationPrice) +
  (postsCount × concretingPrice) +
  (hasGate ? gateInstallationPrice : 0) +
  (hasWicket ? wicketInstallationPrice : 0) +
  (gateOptionsCost) // Добавляем стоимость опций ворот

// Стоимость опций ворот
gateOptionsCost = 0
if (hasGate && gateAutomatic) {
  const option = gateOptions.find(o => o.name === "Автоматические ворота")
  if (option.priceType === "FIXED") {
    gateOptionsCost = option.priceValue
  } else if (option.priceType === "PERCENT") {
    gateOptionsCost = gatePrice * (option.priceValue / 100)
  }
}
```

#### 6. Коэффициент грунта
```
soilSurcharge = (materialsCost + worksCost) × (soilSurchargeCoef - 1)
```

#### 7. Итого
```
grandTotal = materialsCost + worksCost + soilSurcharge
```

### Детали расчета материалов

**Профнастил/штакетник:**
- Площадь покрытия = length × height
- Запас на нахлест = 10%
- Итого = coverageArea × 1.1

**Столбы:**
- Количество = postsCount
- Высота столба = height + 0.5 (заглубление)
- Длина = postsCount × (height + 0.5)

**Лаги:**
- Длина = lagsLength
- Запас на обрезку = 5%
- Итого = lagsLength × 1.05

**Крепеж:**
- Саморезы: ~15 шт/м²
- Заглушки: по количеству столбов
