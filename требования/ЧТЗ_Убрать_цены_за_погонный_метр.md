# ЧТЗ: Убрать отображение стоимости за погонный метр

## Маршрут: Стандартная задача (малая)
**Исполнитель:** Разработчик

## Проблема
В поиске Яндекса отображаются стоимости за погонный метр, которые ранее были убраны. Поле `priceRange` в БД может содержать старые значения. На публичных страницах и в JSON-LD может выводиться цена за метр.

## Решение
Всех посетителей вести в калькулятор — убрать любое отображение цен за погонный метр.

## Файлы для изменения

### TASK-FRT-01: Убрать priceRange из публичных страниц
- `src/app/(public)/services/page.tsx` — убрать запрос и вывод `priceRange`
- `src/app/(public)/services/[slug]/page.tsx` — убрать вывод `priceRange`, заменить на CTA-кнопку «Рассчитать стоимость»
- `src/app/(public)/services/[slug]/layout.tsx` — убрать `priceRange` из JSON-LD

### TASK-DB-01: Скрипт очистки БД
- Создать `scripts/cleanup-price-per-meter.ts` — обнулить `priceRange` во всех PageContent, почистить FAQ и контент

### TASK-SEED-01: Почистить сид-данные
- `scripts/seed-service-pages.ts` — убрать «погонных метров» из контента
- `scripts/seed-faq.ts` — убрать «погонных метров» из FAQ

## Критерии приёмки
1. На публичных страницах нет упоминаний «руб/м», «руб/м.п.», «за погонный метр»
2. JSON-LD не содержит priceRange с ценой за метр (только `'₽₽'` — уровень цен)
3. FAQ не содержит ответов с ценой за метр
4. Контент страниц услуг не содержит цен за метр
5. Скрипт очистки БД готов к запуску на проде
