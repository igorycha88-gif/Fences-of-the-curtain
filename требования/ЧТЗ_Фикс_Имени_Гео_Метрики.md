## 1. Контекст и root cause

Панель «Гео посетителей (топ-10, 24ч)» дашборда «Бизнес сайта» (site-business.json
на мониторинг-стенде) запрашивает метрику `business_geo_visitors_24h{city}`.

Сайт zabor-i-naves.ru через `GET /api/metrics/tracking` эмитит ту же по смыслу
метрику, но под именем **`business_visitor_geo_24h{city}`** (слова переставлены).
Расхождение в именовании между:
- `ЧТЗ_Бизнес_Метрики_Клики_и_Гео.md:92` → `business_visitor_geo_24h` (реализовано)
- `ЧТЗ_Централизованный_мониторинг.md:105` → `business_geo_visitors_24h` (контракт с мониторинг-стендом, по нему настроен дашборд)

Сбор гео-данных работает корректно: `/api/analytics/events` пишет в
`analytics:geo:daily:<МСК-дата>` через `getCityByIP(ip)` при старте сессии
(route.ts:150-161); `collectTrackingRawData` читает эти хэши за сегодня+вчера
(tracking-metrics.ts:351-352). Pipeline `site → relay → Prometheus → Grafana`
исправен — пустая панель вызвана исключительно несовпадением имени.

## 2. Решение (выбор пользователя)

**Переименовать метрику на сайте**: `business_visitor_geo_24h` → `business_geo_visitors_24h`.

Соответствует контракту `ЧТЗ_Централизованный_мониторинг.md` (мониторинг-стенд
уже настроен на это имя). ЧТЗ_Бизнес_Метрики_Клики_и_Гео обновить до того же имени.
