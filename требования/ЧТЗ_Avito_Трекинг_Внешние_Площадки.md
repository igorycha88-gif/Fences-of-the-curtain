## 1. Бизнес-контекст

Сайт **zabor-i-naves.ru** — производство и монтаж заборов/навесов. Необходимо:
1. Разместить объявления на Авито со ссылкой на калькулятор сайта
2. Создать трекинговую ссылку для Авито с учётом переходов в Grafana
3. Исследовать и интегрировать другие площадки для размещения объявлений
4. Вывести на сайте блок «Мы на площадках» в футере

## 2. Анализ Авито

### 2.1 Возможности размещения

**Категория:** Услуги → Ремонт и строительство → Заборы и ограждения
**Тип объявления:** «Услуги» (не «Товар»)

**Правила Авито по ссылкам:**
- Прямые внешние ссылки в описании объявления **разрешены** для категории «Услуги»
- Ссылки проходят модерацию — нельзя использовать сокращатели (bit.ly и т.д.), редиректы
- **Рекомендуется:** использовать прямую ссылку на свой сайт в формате `https://zabor-i-naves.ru/go/avito`
- Ссылку можно указать: в поле «Сайт», в описании объявления, в «Параметрах продавца»
- Авито добавляет `rel=nofollow` к внешним ссылкам (SEO-вес не передаётся, но трафик идёт)

**Требования к объявлению:**
- Реальные фото работ (из портфолио сайта)
- Чёткое описание: «Производство и монтаж заборов под ключ. Калькулятор на сайте — рассчитайте стоимость за 2 минуты.»
- Указать город/регион работы
- Цена «от» — можно указать «от 500 руб/п.м.»
- Положительные отзывы повышают ранжирование

### 2.2 Ссылка для Авито

**Трекинговая ссылка:** `https://zabor-i-naves.ru/go/avito`

При переходе:
1. Middleware фиксирует UTM-параметры (utm_source=avito, utm_medium=referral, utm_campaign=zabory_calc)
2. Редиректит на `/calculator/fence?utm_source=avito&utm_medium=referral&utm_campaign=zabory_calc`
3. Событие записывается в Redis → Prometheus → Grafana

## 4. Требования к реализации

### TASK-AT-001: Middleware — захват UTM-параметров (BCK)

**Файл:** `src/middleware.ts`

- При любом запросе проверять наличие UTM-параметров в query string: `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`
- Сохранять UTM-параметры в cookie `utm_data` (JSON, 30 дней)
- Передавать UTM-данные в заголовке `x-utm-source`
- Если UTM-параметров нет в URL, но есть в cookie — использовать cookie-значения

### TASK-AT-002: Redirect route /go/[source] (BCK)

**Файл:** `src/app/go/[source]/route.ts`

- Создать API route, обрабатывающий GET `/go/avito`, `/go/yula`, `/go/profi` и т.д.
- При запросе:
  1. Записать событие `external_redirect` в аналитику (Redis) с метками: `source`, `timestamp`
  2. Редирект 302 на `/calculator/fence?utm_source={source}&utm_medium=referral&utm_campaign=zabory_calc`
- Для `/go/avito` → редирект на калькулятор забора
- Источники: `avito`, `yula`, `profi`, `yandex-uslugi`, `2gis`
- Для неизвестного source → редирект на главную `/`

### TASK-AT-003: Аналитика внешних источников (BCK)

**Файлы:** `src/lib/prometheus.ts`, `src/app/api/analytics/events/route.ts`

- Добавить метрику Prometheus: `external_source_visits_total` с лейблами `source`
- При записи события `external_redirect` — инкрементировать счётчик
- Сохранять в Redis ключ `analytics:metrics:external_source:{source}` со счётчиком
- Добавить метрику: `external_source_daily_{date}` для ежедневной статистики по источникам

### TASK-AT-004: Раздел «Мы на площадках» в футере (FRT)

**Файлы:** Обновить Footer компонент

- Добавить в футер блок «Мы на площадках» с иконками/ссылками:
  - Авито (иконка Avito)
  - Юла (иконка Youla)
  - Профи.ру (иконка Profi)
  - Яндекс.Услуги (иконка Яндекс)
  - 2ГИС (иконка 2GIS)
- Каждая ссылка ведёт на внешний профиль компании на соответствующей площадке
- Иконки — SVG или Font Awesome / простые текстовые бейджи
- Дизайн: горизонтальный ряд иконок/бейджей в футере, между блоками «Контакты» и «Соцсети» (или отдельная колонка)

### TASK-AT-005: Grafana дашборд «Внешние источники трафика» (INF)

**Файл:** `grafana/provisioning/dashboards/imported/external-traffic-sources.json`

- Новый дашборд в Grafana с панелями:
  1. **Переходы по источникам** — график/таблица `external_source_visits_total` по `source`
  2. **Переходы по дням** — stacked graph по дням, разбивка по source
  3. **Конверсия из внешних источников** — доля посетителей с UTM, дошедших до калькулятора
  4. **Топ источников** — pie chart / bar chart
  5. **Переходы → Калькулятор → Заявка** — воронка для Avito-трафика
- Источник данных: Prometheus

### TASK-AT-006: Конфигурация площадок в админ-панели (BCK/FRT) — опционально

- Добавить в справочники админ-панели таблицу `ExternalPlatform` (Prisma):
  - `id`, `name`, `slug`, `url`, `iconSvg`, `isActive`, `order`, `createdAt`, `updatedAt`
- API для CRUD площадок
- Footer динамически подтягивает активные площадки
- **Приоритет:** средний, можно захардкодить 5 площадок на первом этапе
