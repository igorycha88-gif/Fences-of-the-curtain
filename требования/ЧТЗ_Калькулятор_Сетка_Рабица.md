# ЧТЗ: Калькулятор для типа забора «Сетка-рабица»

**Дата:** 2026-04-12  
**Статус:** Утверждён  
**Маршрут:** Маршрут 2 (Сложная задача — новая таблица БД, >5 файлов, новый API-контекст)  
**Исполнитель:** Разработчик (Fullstack)

---

## 1. Описание задачи

Добавить полноценную поддержку типа забора «Сетка-рабица» в калькулятор заборов, включая:
- Новый справочник «Сетка-рабица» (модель БД + админ-панель CRUD)
- Модификацию справочника «Столбы» (поле `forMesh`)
- Расчёт стоимости в калькуляторе
- UI-параметры для сетки-рабицы (размер ячейки, толщина прутка, покрытие)
- Интеграцию в заявки, сметы, мульти-расчёт
- Обработку «пустой заявки» при отсутствии номенклатуры

---

## 3. Детальные требования

### 3.1. Новая модель БД: `MeshType`

```
MeshType:
  id                   String    @id @default(cuid())
  name                 String                                        // Название (например "Сетка-рабица 1.5м яч.50×50 пруток 2.0мм оцинк.")
  description          String?                                       // Описание
  height               Float                                         // Высота сетки (мм)
  cellSize             Int                                           // Размер ячейки (мм) — квадратная ячейка
  wireThickness        Float                                         // Толщина прутка (мм)
  coating              String                                        // Тип покрытия: "Оцинковка" / "Полимерное"
  retailPricePerUnit   Float                                         // Розничная цена за погонный метр
  purchasePricePerUnit Float?                                        // Закупочная цена за погонный метр
  image                String?                                       // Изображение
  active               Boolean   @default(true)
  validFrom            DateTime?                                     // Начало действия цены
  validUntil           DateTime?                                     // Окончание действия цены
  priority             Int       @default(0)
  createdAt            DateTime  @default(now())
  updatedAt            DateTime  @updatedAt
```

**Индексы:** `[active]`, `[validUntil]`, `[coating]`, `[priority]`, `[height, cellSize, wireThickness, coating]`

### 3.2. Модификация модели `PostType`

Добавить поле:
```
forMesh               Boolean   @default(false)                       // true = столб для сетки-рабицы
```

**Индекс:** `[forMesh]`

### 3.3. Модификация модели `FenceEstimate`

Добавить поля (по аналогии с panel3d, picket):
```
meshId                String?                                       // ID подобранной сетки-рабицы
meshNomenclatureName  String?                                       // Название сетки
meshTotal             Float     @default(0)                          // Стоимость сетки
meshInstallationTotal Float     @default(0)                          // Стоимость монтажа сетки
```

**Индексы:** `[meshId]`

### 3.4. Калькулятор сетки-рабицы

**Параметры от пользователя:**
- `length` — длина забора (м)
- `height` — высота забора (м)
- `lagRows` — количество лаг (2 или 3) — как у Профнастиля
- `coating` — покрытие сетки: `GALVANIZED` / `POLYMER` (новый enum для mesh)
- `meshCellSize` — размер ячейки (мм): выбор из доступных в справочнике
- `meshWireThickness` — толщина прутка (мм): выбор из доступных в справочнике
- `hasGate`, `gateType`, `gateWidth` — как у других типов
- `hasWicket`, `wicketWidth` — как у других типов

**Логика расчёта:**

1. **Подбор сетки:**
   - Фильтр: `active=true`, `validUntil` не истёк, `coating` = выбранное покрытие
   - Фильтр: `height >= fenceHeightMm` (ближайшая больше)
   - Фильтр: `cellSize = meshCellSize`, `wireThickness = meshWireThickness`
   - Сортировка: `priority ASC`, `height ASC`
   - Если не найдена → ошибка `NO_MESH_FOUND`

2. **Количество сетки:**
   - `quantity = fenceLengthM` (в погонных метрах)
   - `totalPrice = quantity * retailPricePerUnit`
   - `unit = 'м.п.'`

3. **Столбы:**
   - Новая функция `calculatePostsForMesh(fenceLengthM, fenceHeightM, postSpacingM)`
   - Фильтр: `forMesh = true`, `active = true`
   - Требуемая высота столба: `fenceHeightMm + 1200мм` (под землёй)
   - Подбор: первый столб с `length >= requiredHeight`
   - Если не найден → ошибка `NO_POSTS_FOUND`
   - Количество столбов: `ceil(fenceLengthM / postSpacingM) + 2` (как у других типов)

4. **Лаги:**
   - `calculateLags(correctedLength, lagRows)` — та же функция, что и для Профнастиля

5. **Ворота и калитка:**
   - Та же логика, что и для других типов заборов
   - `gateLookup.findGateByTypeAndLength()`
   - `wicketLookup.findWicketByHeightAndWidth()`

6. **Монтажная фурнитура:**
   - `mountingHardwareCalculator` с параметром `meshId` и `meshCount`
   - Привязка через `MountingHardwareRelation` (referenceType = 'MESH', referenceId = meshId)

7. **Работы по монтажу:**
   - Работы привязаны к типу забора `MESH` через `WorkRelation`
   - Работы привязаны к номенклатуре сетки через `WorkRelation` (referenceType = 'MESH')
   - Аналогично panel3d: `workService.getWorksForCalculatorByReference('MESH', meshId)`

### 3.5. UI калькулятора (фронтенд)

При выборе типа забора «Сетка-рабица» показать блок параметров (аналогично блоку «Параметры евроштакетника»):

```
┌─ Параметры сетки-рабицы ─────────────────────────────────┐
│                                                            │
│  Покрытие:        [Оцинковка ▾]  /  [Полимерное ▾]        │
│  Размер ячейки:   [50 мм ▾]                               │
│  Толщина прутка:  [2.0 мм ▾]                              │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

- Покрытие: dropdown с вариантами «Оцинковка» и «Полимерное»
- Размер ячейки: dropdown с уникальными значениями из справочника MeshType (отфильтрованными по выбранному покрытию и высоте)
- Толщина прутка: dropdown с уникальными значениями из справочника MeshType (отфильтрованными по покрытию, высоте и размеру ячейки)
- **НЕ показывать** блок «Покрытие» для профнастила (существующий `coating` select) — для сетки-рабицы покрытие своё

**API для получения опций:**
- Новый endpoint: `GET /api/calculator/mesh-options?fenceTypeId=...&height=...` — возвращает доступные `cellSizes`, `wireThicknesses`, `coatings` из справочника MeshType, отфильтрованные по `active=true` и высоте

### 3.6. Админ-панель: справочник «Сетка-рабица»

- Страница: `/admin/references/mesh/`
- Стандартный CRUD по аналогии с `/admin/references/panel3d/`
- Поля формы: название, высота (мм), размер ячейки (мм), толщина прутка (мм), покрытие, розничная цена, закупочная цена, изображение, активность, приоритет, период действия
- Регистрация в `referenceRegistry` как тип `MESH`

### 3.7. Админ-панель: справочник «Столбы»

- Добавить колонку и поле формы «Для сетки-рабицы» (boolean/checkbox)
- При создании/редактировании столба можно отметить «Для сетки-рабицы»

### 3.8. ReferenceRegistry

Зарегистрировать новый тип:
```typescript
referenceRegistry.register({
  type: 'MESH',
  name: 'Сетка-рабица',
  modelName: 'MeshType',
});
```

Добавить case `MESH` в методы `getItems()`, `validate()`, `getItemName()`.

### 3.9. Валидаторы

Обновить `fenceEstimateSchema`:
```typescript
meshCellSize: z.number().optional(),          // Размер ячейки (мм)
meshWireThickness: z.number().optional(),     // Толщина прутка (мм)
meshCoating: z.enum(['GALVANIZED', 'POLYMER']).optional(), // Покрытие сетки
```

### 3.10. Мульти-расчёт

Сетка-рабица участвует в мульти-расчёте наравне с другими типами. Никаких изменений в `multiFenceEstimateService` не требуется — достаточно что `fenceEstimateService` будет обрабатывать тип «Сетка-рабица».

### 3.11. Заявка (Order)

- При отправке заявки параметры сетки-рабицы передаются в `parameters` (как у евроштакетника)
- В админке в деталях заявки отображаются параметры сетки: покрытие, ячейка, пруток
- Смета редактируемая (по аналогии с другими типами через EstimateEditor)

### 3.12. Пустая заявка (NomenclatureNotFoundModal)

- Добавить ошибку `NO_MESH_FOUND` в список обрабатываемых ошибок
- При отсутствии сетки-рабицы → показ модального окна для заполнения контактов и отправки пустой заявки

## 4. Критерии приёмки

1. ✅ В калькуляторе при выборе «Сетка-рабица» отображаются параметры: покрытие, размер ячейки, толщина прутка, длина, высота, количество лаг, ворота, калитка
2. ✅ Расчёт стоимости корректный: сетка (пог.м) + столбы (forMesh) + лаги + ворота/калитка + монтажная фурнитура + работы по монтажу
3. ✅ Сетка подбирается по высоте (ближайшая больше), покрытию, размеру ячейки и толщине прутка
4. ✅ Столбы подбираются с флагом `forMesh=true` и высотой >= забор + 1200мм
5. ✅ Если сетка/столбы не найдены → пустая заявка (модальное окно с контактами)
6. ✅ Справочник «Сетка-рабица» доступен в админ-панели с CRUD
7. ✅ В справочнике «Столбы» есть поле «Для сетки-рабицы»
8. ✅ Сетка-рабица участвует в мульти-расчёте с другими типами
9. ✅ Смета с сеткой-рабицей появляется в заявке и редактируется в админке
10. ✅ `npm test && npm run lint && npx tsc --noEmit` проходят без ошибок

## 8. Риски и ограничения

1. **Обратная совместимость:** FenceEstimate — новые поля с `@default(0)` / `@default(null)` не ломают существующие записи
2. **Кэширование:** При добавлении/изменении MeshType нужно инвалидировать кэш `MESH_ACTIVE`
3. **PostType.forMesh:** Существующие столбы получат `forMesh=false` (default), что не влияет на существующие расчёты
