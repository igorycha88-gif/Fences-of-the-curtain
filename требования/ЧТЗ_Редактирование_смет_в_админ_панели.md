## 1. Цели и задачи

### 1.1 Бизнес-цель
Дать администратору возможность полноценно редактировать сметы (расчеты) внутри заявки: изменять параметры забора, добавлять/удалять/корректировать номенклатуры, с автоматическим пересчетом и полным аудитом изменений.

### 1.2 Пользовательская ценность
Администратор может скорректировать расчет под реальные условия объекта, не создавая новый расчет вручную. Клиент получает точную смету.

### 1.3 Метрики успеха
- Админ может редактировать каждую смету в заявке отдельно
- При изменении параметров — автоматический пересчет номенклатур
- Все изменения логируются и отображаются с цветовой разметкой

## 3. Функциональные требования

### US-1: Редактирование отдельной сметы в мульти-расчете
**Given** заявка содержит мульти-расчет с несколькими сметами
**When** админ нажимает «Редактировать» на конкретной смете
**Then** открывается EstimateEditor для этой конкретной сметы

### US-2: Цветовая разметка изменений
**Given** есть исходная и скорректированная смета
**When** админ просматривает скорректированную смету
**Then** номенклатуры показаны с цветами:
- 🟢 Зелёный фон + бейдж «Добавлено» — новые номенклатуры
- 🔴 Красный фон + зачеркнутый текст + бейдж «Удалено» — удалённые номенклатуры
- 🟠 Оранжевый фон + бейдж «Изменено кол-во (авто: X → вручную: Y)» — скорректированное количество

### US-3: Пометка на странице «Расчеты»
**Given** админ открывает вкладку «Расчеты» (/admin/estimates)
**When** в списке есть отредактированный расчет (isEditedByAdmin=true)
**Then** он отображается с оранжевым бейджем «✏️ Корректировка»

### US-4: Обновление стоимости заказа
**Given** админ сохранил скорректированную смету
**When** заявка имеет adminEstimate
**Then** order.calculatedCost обновляется на grandTotal из adminEstimate

### US-5: Авто-пересчет при изменении параметров
**Given** админ редактирует параметры забора (длина, высота, покрытие, лаги, ворота, калитка)
**When** любое поле параметра изменено
**Then** номенклатуры пересчитываются автоматически с debounce 500ms, без необходимости нажимать кнопку

### US-6: Кнопка редактирования для единичной сметы
**Given** заявка содержит одну смету (не мульти)
**When** админ просматривает заявку
**Then** рядом с исходной сметой есть кнопка «Редактировать расчет» (если еще нет корректировки) или «Редактировать корректировку» (если есть)
