# ЧТЗ: Фикс удаления номенклатуры из сметы (404 ошибка)

## Описание проблемы

При удалении номенклатуры из сметы в калькуляторе админа возникает 404 ошибка:
```
/api/admin/calculator/estimate/estimate-{id}/items/{nomenclatureId} → 404 Not Found
```

## Маршрутизация

- **Маршрут:** Стандартный (Маршрут 1)
- **Исполнитель:** Разработчик

## Файлы для изменения

1. `src/app/api/admin/calculator/estimate/[id]/items/[nomenclatureId]/route.ts` — добавить диагностическое логирование
2. `src/app/(admin)/admin/calculator/page.tsx` — исправить handleRemoveItem

## Корневые причины

1. **Недостаточное логирование**: При 404 невозможно отличить ESTIMATE_NOT_FOUND от ITEM_NOT_FOUND без тела ответа
2. **Фронтенд не обновляет UI при ошибке**: `handleRemoveItem` в ветке `else` показывает toast, но не убирает «фантомный» item из состояния — пользователь может кликнуть удаление повторно
3. **Отсутствует оптимистичное обновление**: При DELETE запросе UI не обновляется до получения ответа, что может приводить к race conditions при быстрых кликах

## Критерии приёмки

1. DELETE-роут логирует `estimateId` и `nomenclatureId` при ошибках ESTIMATE_NOT_FOUND и ITEM_NOT_FOUND
2. Фронтенд при ошибке удаления получает информацию о причине (estimate не найден / item не найден)
3. Фронтенд корректно обрабатывает ошибку: убирает «фантомные» items или перезагружает данные
4. `npm test && npm run lint && npx tsc --noEmit` — без ошибок
