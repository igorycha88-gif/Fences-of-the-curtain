# ЧТЗ (упрощённое): Макеты редизайна блока кнопок расчёта на главной

**Дата:** 2026-10-11
**Маршрут:** Аналитик → Разработчик → Тестировщик (DevOps не требуется — статические макеты вне сборки приложения)

## 1. Задача

Проанализировать главную страницу (десктоп + мобильная) и подготовить **5 HTML-макетов** предложений по редизайну блока кнопок расчёта: Забор, Навес, Ворота, Калитка + **новая кнопка «Гараж»**. Каждый макет содержит **отдельно десктопную и отдельно мобильную версии**.

## 2. Контекст (текущее состояние)

- Hero главной: столбец CTA — звонок → «Рассчитать забор» (primary) → 2 glass-кнопки «Ворота и калитка», «Навес» (`src/app/page.tsx:141-168`)
- На мобильных все кнопки стекаются вертикально (5 кнопок = перегруз)
- Калькуляторы: `/calculator/fence`, `/calculator/canopy`, `/calculator/gates` (ворота + калитка вместе). Калькулятора гаража нет — в макетах помечать «Новый»
- Бренд: primary ≈ `hsl(25 95% 53%)` (#F97316), фон #F5F7FA, radius 12-16px, карточная стилистика уже используется на сайте

## 3. Требования к макетам

1. Папка: `макеты/knopki-rascheta/` + `index.html` (обзор и сравнение)
2. Каждый макет — самодостаточный HTML (без внешних зависимостей), содержит:
   - Описание концепта, плюсы/минусы
   - Артборд **Десктоп 1280px** (шапка + hero + блок кнопок)
   - Артборд **Мобильная 390px** (та же логика)
3. Стилизация в фирменных цветах сайта; иконки — inline SVG
4. 5 концептов:
   - №1 «Карточки в один ряд» (предложение заказчика) — 5 равных карточек
   - №2 «Bento-сетка» — гараж как акцентная большая карточка
   - №3 «Табы» — один блок, переключение типа расчёта
   - №4 «Компактные пилюли» — минимализм, вторичные кнопки-чипы
   - №5 «Каталог-карточки» — карточки с визуалом, на моб — карусель
5. Цены в макетах — плейсхолдеры («от …»), подписать в index

## 4. Критерии приёмки

- [ ] 5 файлов макетов + index.html созданы в `макеты/knopki-rascheta/`
- [ ] В каждом макете есть ДЕСКТОП и МОБИЛЬНАЯ версии
- [ ] Во всех 5 концептах присутствуют 5 типов: забор, навес, ворота, калитка, гараж
- [ ] Гараж помечен бейджем «Новый»
- [ ] Фирменные цвета сайта использованы
- [ ] HTML валиден, файлы открываются без внешних ресурсов

## 5. Не входит в задачу

- Изменение кода сайта (макеты — основа для согласования, реализация — отдельной задачей)
- Калькулятор гаража (бэкенд) — только UI-кнопка
- Правило 8 (логирование/автотесты) не применимо: статические файлы без JS-логики, вне `src/`
