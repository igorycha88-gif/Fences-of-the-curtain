# ЧТЗ: Фикс отступа заголовка «Калькулятор навеса» в мобильной версии

**Дата:** 2026-06-17
**Маршрут:** Стандартный (Аналитик → Разработчик → Тестировщик → DevOps)
**Тип задачи:** Bug-fix UI (малая задача)

---

## 1. Описание проблемы

В мобильной версии клиентского калькулятора навеса (`/calculator/canopy`) заголовок `<h1>Калькулятор навеса</h1>` наезжает на верхнюю часть экрана, перекрывая fixed-хедер с логотипом «Заборы и Навесы» и телефоном.

## 2. Причина

- `src/components/layout/Header.tsx` имеет класс `fixed top-0 left-0 right-0 z-50` и «выплывает» поверх контента.
- В `src/app/(public)/calculator/canopy/page.tsx` используется `<main className="container mx-auto px-4 py-10">` — НЕТ верхнего отступа под fixed-хедер.
- На всех остальных публичных страницах принят стандарт `pt-24` (96px) или `py-16` (например: `/calculator`, `/calculator/fence`, `/calculator/gates`, `/services`, `/contacts`, `/faq`, `/blog`, `/about`).

## 3. Критерии приёмки

1. На мобильных устройствах заголовок «Калькулятор навеса» НЕ перекрывает fixed-хедер (логотип + телефон).
2. На десктопе вёрстка остаётся корректной (без лишних пустых пространств).
3. Отступ соответствует принятому в проекте паттерну (`pt-24 pb-16`).
4. Исправление применяется к обоим `<main>` в файле (основное состояние + состояние загрузки).
5. `npm test && npm run lint && npx tsc --noEmit` проходят без ошибок.

## 4. Файлы для изменения

- `src/app/(public)/calculator/canopy/page.tsx` — заменить `py-10` на `pt-24 pb-16` в обоих `<main>`.

## 5. Декомпозиция

- **TASK-FRT-001:** Исправить верхний отступ `<main>` на странице `/calculator/canopy` (2 места).
- **TASK-TEST-001:** Добавить автотест, проверяющий наличие класса отступа / рендер заголовка без наезда.

## 6. Регрессия

Проверить, что:
- Калькулятор забора (`/calculator/fence`) — без изменений.
- Главная страница калькуляторов (`/calculator`) — без изменений.
- Состояние загрузки справочников также имеет корректный отступ.
