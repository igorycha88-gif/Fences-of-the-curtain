# ЧТЗ (упрощённое): Актуализация коммерческого блока главной страницы

**Дата:** 2026-08-19
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps
**Тип:** малая задача (2 файла, без БД/API/архитектуры)

## 1. Основание

Цена «от 2 800 ₽/м» на главной не соответствует актуальным данным прод БД.
Гарантия изменена бизнесом с 3 лет на 1 год. Условие бесплатного выезда на замер
уточнено: бесплатно только при заказе услуги.

## 2. Расчёт минимальной цены (данные ПРОД БД, 2026-08-19)

Dry-run расчёт через `calculateFenceEstimateCore` (реальные формулы калькулятора,
SSH-туннель к прод PostgreSQL, длина 100 м, без записи в БД):

| Тип забора | Конфигурация | ₽/м |
|---|---|---|
| Сетка-рабица | h=1.5, оцинк., ячейка 50, проволока 1.8 | 1 629 |
| Евроштакетник | h=1.5, М-образный, шаг 20 см, односторонний | 1 696 |
| 3D-панели | h=1.53 | 2 294 |
| **Профнастил** | **h=1.5, полимер одностороннее** | **2 631** |

**Решение пользователя:** показывать «от 2 600 ₽/м» (профнастил — главный продукт
главной страницы, H1 «Забор из профнастила»; 2631 округляется до 2 600).

## 4. Критерии приёмки

1. На главной (и /services) в блоке CommercialFactors отображается «от 2 600 ₽/м».
2. Гарантия в карточке — «1 год».
3. Карточка выезда: значение «Бесплатно», подпись «Замер при заказе услуги».
4. SEO title главной содержит «от 2600₽/м», description содержит «Гарантия 1 год».
5. В двух изменённых файлах не осталось вхождений «2 800», «2800₽», «3 года» (в контексте цены/гарантии).
6. Автотесты на компонент и константы проходят; `npm test && npm run lint && npx tsc --noEmit` — зелёные.
