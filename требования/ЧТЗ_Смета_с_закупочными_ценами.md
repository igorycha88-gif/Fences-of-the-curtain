## 1. Цели и задачи

### 1.1 Бизнес-цель
Предоставить администраторам расширенную смету с закупочными ценами и маржой для финансового анализа, контроля рентабельности и формирования бухгалтерских отчетов.

### 1.2 Пользовательская ценность
Администраторы смогут видеть реальную себестоимость материалов, рассчитывать маржинальность каждой позиции и принимать обоснованные решения по ценообразованию.

### 1.3 Ключевые метрики успеха
- Точность расчета маржи: 100%
- Время доступа к смете: < 500ms
- Покрытие всех номенклатур с закупочными ценами: 100%

## 3. Функциональные требования

### 3.1 User Stories

#### US-1: Просмотр расширенной сметы
**Как** администратор,  
**Я хочу** видеть в деталях расчета смету с закупочными ценами и маржой,  
**Чтобы** анализировать рентабельность и контролировать себестоимость.

**Acceptance Criteria**:
```
Given я авторизован как ADMIN
And нахожусь на странице "Расчеты"
When открываю детали расчета
Then вижу расширенную смету с колонками:
  - № п/п
  - Категория
  - Артикул
  - Наименование (полное)
  - Ед. изм.
  - Кол-во
  - Цена розн. за ед.
  - Сумма розн.
  - Цена закуп. за ед.
  - Сумма закуп.
  - Маржа (₽)
  - Маржа (%)
  - НДС (поле есть, без расчета)
And если закупочная цена отсутствует — прочерк в столбцах
And итого по смете:
  - Итого розничная стоимость
  - Итого закупочная стоимость
  - Итого маржа (₽)
  - Итого маржа (%)
```

#### US-2: Ограничение доступа к закупочным ценам
**Как** система,  
**Я хочу** скрывать закупочные цены от не-администраторов,  
**Чтобы** защитить коммерческую информацию.

**Acceptance Criteria**:
```
Given пользователь авторизован как MANAGER
When открывает детали расчета
Then видит базовую смету БЕЗ колонок:
  - Цена закуп. за ед.
  - Сумма закуп.
  - Маржа (₽)
  - Маржа (%)
  - Итого закупочная стоимость
  - Итого маржа
And видит только розничные цены
```

#### US-3: Расчет маржи по позиции
**Как** система,  
**Я хочу** автоматически рассчитывать маржу для каждой позиции,  
**Чтобы** администратор видел рентабельность.

**Acceptance Criteria**:
```
Given номенклатура имеет закупочную цену
When формируется смета
Then маржа (₽) = (retailPricePerUnit × quantity) - (purchasePricePerUnit × quantity)
And маржа (%) = (маржа_₽ / (retailPricePerUnit × quantity)) × 100
And округление до 2 знаков
```

#### US-4: Итоговые показатели сметы
**Как** администратор,  
**Я хочу** видеть итоговые суммы по всей смете,  
**Чтобы** понимать общую рентабельность заказа.

**Acceptance Criteria**:
```
Given смета содержит N позиций
When отображается таблица
Then внизу таблицы:
  - Итого розничная стоимость = Σ(сумма_розн по всем позициям)
  - Итого закупочная стоимость = Σ(сумма_закуп по позициям с ценой закупки)
  - Итого маржа (₽) = Σ(маржа_₽ по позициям с ценой закупки)
  - Итого маржа (%) = (Итого_маржа_₽ / Итого_розничная_стоимость) × 100
```

#### US-5: Экспорт сметы в Excel
**Как** администратор,  
**Я хочу** выгрузить расширенную смету в Excel,  
**Чтобы** использовать данные для отчетов и анализа.

**Acceptance Criteria**:
```
Given я нахожусь в деталях расчета
When нажимаю "Экспорт сметы"
Then скачивается XLSX файл
And файл содержит все колонки расширенной сметы
And заголовки на русском
And форматирование чисел (валюта, проценты)
```

### 5.4 Логика расчета

```typescript
// Сервис расчета расширенной сметы
function calculateExtendedItems(items: BasicItem[], userRole: Role): ExtendedItem[] {
  return items.map(item => {
    const purchasePrice = getPurchasePrice(item.category, item.nomenclatureId);
    
    if (userRole !== 'ADMIN' || purchasePrice === null) {
      return {
        ...item,
        purchasePricePerUnit: null,
        purchaseTotal: null,
        marginRub: null,
        marginPercent: null
      };
    }
    
    const purchaseTotal = purchasePrice * item.quantity;
    const marginRub = item.totalPrice - purchaseTotal;
    const marginPercent = (marginRub / item.totalPrice) * 100;
    
    return {
      ...item,
      purchasePricePerUnit: purchasePrice,
      purchaseTotal: roundToTwo(purchaseTotal),
      marginRub: roundToTwo(marginRub),
      marginPercent: roundToTwo(marginPercent)
    };
  });
}

function getPurchasePrice(category: string, id: string): number | null {
  switch (category) {
    case 'posts': return prisma.postType.findUnique({ where: { id } }).purchasePricePerUnit;
    case 'lags': return prisma.lagType.findUnique({ where: { id } }).purchasePricePerUnit;
    case 'profnastil': return prisma.profnastilType.findUnique({ where: { id } }).purchasePricePerUnit;
    case 'picket': return prisma.picketType.findUnique({ where: { id } }).purchasePricePerMeter;
    case 'gates': return prisma.gateType.findUnique({ where: { id } }).purchasePrice;
    case 'wickets': return prisma.wicketType.findUnique({ where: { id } }).purchasePrice;
    case 'mountingHardware': return prisma.mountingHardware.findUnique({ where: { id } }).purchasePrice;
    default: return null;
  }
}
```
