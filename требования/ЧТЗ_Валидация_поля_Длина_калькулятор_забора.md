## 1. Цели и задачи

### 1.1 Бизнес-цель
Заменить грубый `alert()` на интуитивно понятную инлайн-валидацию поля «Длина» в калькуляторе забора, чтобы пользователь сразу видел проблему и понимал, как её исправить.

### 1.2 Пользовательская ценность
- Пользователь видит ошибку **рядом с полем**, а не в модальном alert-окне
- Поле подсвечивается красной рамкой — визуально понятно, где именно ошибка
- Текст ошибки подсказывает допустимый диапазон значений
- Валидация срабатывает **при потере фокуса** — не нужно ждать нажатия кнопки

### 1.3 Метрики успеха
- Убраны все `alert()` в валидации поля Длина
- Введено состояние ошибки с инлайн-текстом и красной рамкой

## 2. Функциональные требования

### 2.1 User Story

**US-1:** Как пользователь калькулятора забора,
я хочу видеть подсказку об ошибке прямо под полем «Длина»,
чтобы сразу понять, что нужно исправить, без закрывающихся alert-окон.

**Acceptance Criteria (Given-When-Then):**

```
AC-1: Показ ошибки при потере фокуса
  GIVEN: Поле «Длина» пустое или содержит значение < 10 или > 1000
  WHEN:  Пользователь убирает фокус с поля (blur)
  THEN:  Поле подсвечивается красной рамкой
         Под полем появляется текст ошибки:
         - пустое: «Укажите длину забора в метрах»
         - < 10:  «Минимальная длина — 10 м»
         - > 1000: «Максимальная длина — 1 000 м»
         - NaN:   «Введите числовое значение»

AC-2: Показ ошибки при нажатии «Рассчитать»
  GIVEN: Поле «Длина» пустое или невалидное
  WHEN:  Пользователь нажимает «Рассчитать» или «Рассчитать все заборы»
  THEN:  Поле подсвечивается красной рамкой + инлайн-текст ошибки
         Расчёт НЕ отправляется на сервер

AC-3: Скрытие ошибки при корректном вводе
  GIVEN: Поле «Длина» содержит значение от 10 до 1000
  WHEN:  Пользователь изменяет значение (onChange)
  THEN:  Красная рамка и текст ошибки исчезают немедленно

AC-4: Скрытие ошибки при получении фокуса
  GIVEN: Поле «Длина» показывает ошибку
  WHEN:  Пользователь ставит курсор в поле (focus)
  THEN:  Текст ошибки остаётся, но рамка меняется на стандартную focus-рамку
```

#### 4.4.2 Функция валидации длины

```typescript
const validateLength = (length: number | ''): string | null => {
  if (length === '' || length === null || length === undefined) {
    return 'Укажите длину забора в метрах';
  }
  const num = Number(length);
  if (isNaN(num)) {
    return 'Введите числовое значение';
  }
  if (num < 10) {
    return 'Минимальная длина — 10 м';
  }
  if (num > 1000) {
    return 'Максимальная длина — 1 000 м';
  }
  return null;
};
```

#### 4.4.3 Обработчик blur
