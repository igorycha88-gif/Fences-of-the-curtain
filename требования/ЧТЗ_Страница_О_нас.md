# ЧТЗ: Страница «О нас»

## 1. Бизнес-задача
Создать публичную страницу «О нас» с описанием компании — полный цикл производства и монтаж. Страница должна содержать фотографии, которые можно менять через админ-панель. Вкладка в навигации располагается между «Портфолио» и «Контакты».

## 2. Контекст
Компания «Заборы и Навесы» — производитель и установщик заборов/навесов. Необходимо представить компанию на сайте: показать производство, монтаж, материалы, команду. Контент должен редактироваться через админ-панель (тексты + фото).

## 3. Решение

### 3.1. Публичная страница `/about`
**URL:** `/about`
**Структура контента (секции):**

1. **Hero-секция** — Заголовок «О компании», подзаголовок, фоновое фото
2. **О компании** — Текстовое описание: полный цикл от производства до монтажа
3. **Наши преимущества** — 4 карточки с иконками и описанием
4. **Этапы работы** — Визуальные шаги (от замера до сдачи объекта)
5. **Галерея фото** — 5 фотографий с подписями (производство, монтаж, материалы, цех, команда)
6. **CTA-секция** — Призыв к действию (рассчитать стоимость / связаться)

### 3.2. Админ-панель: управление контентом
- **Новый раздел** в сайдбаре: «О нас» (в группе справочников)
- **Страница:** `/admin/about`
- **Редактируемые поля:**
  - Заголовок hero
  - Подзаголовок hero
  - Текст «О компании»
  - Преимущества (4 шт: иконка, заголовок, описание)
  - Этапы работы (5 шт: номер, заголовок, описание)
  - Фотографии (5 шт: изображение + подпись) — загрузка через существующий API `/api/admin/portfolio/upload`
- **Хранение:** в модели `Setting` (ключи `about_*`) — без новой миграции

### 3.3. Навигация
- Добавить ссылку `{ href: '/about', label: 'О нас' }` между Портфолио и Контакты в Header.tsx

## 4. Данные — модель хранения

Используем существующую модель `Setting` (key-value):
- `about_hero_title` — заголовок hero
- `about_hero_subtitle` — подзаголовок hero  
- `about_hero_image` — фото hero
- `about_text` — текст о компании
- `about_advantages` — JSON: [{icon, title, description}] (4 шт)
- `about_steps` — JSON: [{number, title, description}] (5 шт)
- `about_photos` — JSON: [{image, caption}] (5 шт)

Значения по умолчанию (для первичного заполнения) задаются в API.

## 5. API

### 5.1. Публичный API
- `GET /api/about` — получить контент страницы

### 5.2. Админ API
- `GET /api/admin/about` — получить контент для редактирования
- `PUT /api/admin/about` — обновить контент (с загрузкой фото через существующий upload endpoint)

## 6. Критерии приёмки

| ID | Критерий | Приоритет |
|----|----------|-----------|
| AC-1 | Страница `/about` доступна и отображает контент в едином стиле с другими страницами | HIGH |
| AC-2 | Навигация: вкладка «О нас» расположена между «Портфолио» и «Контакты» (desktop + mobile) | HIGH |
| AC-3 | 5 фотографий отображаются в галерее с подписями | HIGH |
| AC-4 | Админ-панель: страница `/admin/about` позволяет редактировать все текстовые поля | HIGH |
| AC-5 | Админ-панель: фотографии загружаются через загрузчик и сохраняются | HIGH |
| AC-6 | Responsive: корректное отображение на мобильных устройствах | MEDIUM |
| AC-7 | SEO: мета-теги (title, description) для страницы «О нас» | MEDIUM |
| AC-8 | Анимации секций (AnimatedSection) как на других страницах | LOW |

### О компании
«Компания «Заборы и Навесы» — это команда профессионалов, которая выполняет полный цикл работ по производству и установке заборов, навесов и ограждений. Мы контролируем каждый этап: от закупки сертифицированных материалов до финального монтажа на объекте.

Собственное производство позволяет нам гарантировать качество и предлагать честные цены без посредников. Каждый проект — это индивидуальный подход, точный расчёт и соблюдение сроков.»

### Преимущества
1. Собственное производство — Контроль качества на каждом этапе
2. Полный цикл работ — От замера до сдачи объекта
3. Гарантия на работы — На все выполненные работы
4. Честные цены — Без скрытых платежей и наценок посредников

### Этапы работы
1. Замер и консультация — Бесплатный выезд специалиста, обсуждение задачи
2. Расчёт стоимости — Точный расчёт материалов и работ
3. Производство — Изготовление конструкций на собственном производстве
4. Доставка и монтаж — Профессиональная установка в оговорённые сроки
5. Сдача объекта — Приёмка работ и подписание акта
