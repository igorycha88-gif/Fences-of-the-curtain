## 1. Постановка задачи

## 5. Декомпозиция задач

### TASK-SEO-BCK-001: Исправить canonical баг в metadata.ts
**Файлы:** `src/lib/seo/metadata.ts`  
**Проблема:** Когда `path` передан, canonical формируется корректно, но если нет — fallback на BASE_URL (корень). Страница блога передаёт `path: '/blog'`, но из-за порядка в `generatePageMetadata` это может не работать корректно.  
**Решение:** Проверить и гарантировать что canonical всегда = `BASE_URL + path`

### TASK-SEO-BCK-002: Переделать /services в Server Component
**Файлы:** `src/app/(public)/services/page.tsx`  
**Проблема:** Страница `'use client'` — Яндексе хуже индексирует.  
**Решение:** Переписать как Server Component с прямым запросом к БД (prisma). Убрать `'use client'`, useState/useEffect. Контент статичный — не нужен клиентский рендеринг.

### TASK-SEO-BCK-003: Обогатить seed-данные для посадочных страниц
**Файлы:** `scripts/seed-service-pages.ts`  
**Проблема:** Текущий контент слишком короткий (2 секции по 2 предложения). Для SEO нужно 1500+ слов.  
**Решение:** Расширить content.sections до 6-8 полноценных секций для каждой из 6 страниц. Добавить FAQ-секции прямо в content.

### TASK-SEO-BCK-004: Создать дополнительные блог-статьи
