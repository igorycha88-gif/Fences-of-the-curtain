# ЧТЗ: Фикс номенклатуры в калькуляторе админа

## Проблема
При нажатии «Добавить номенклатуру» в калькуляторе заборов (админ) номенклатура справочников не отображается.

### Корневые причины
1. **API 400**: `category=mesh` не входит в `VALID_CATEGORIES` API `/api/admin/nomenclature/search`
2. **Несовпадение формата ответа**: страница читает `data.items`, а API возвращает `data.categories`

## Файлы для изменения
1. `src/app/api/admin/nomenclature/search/route.ts` — добавить `mesh`
2. `src/app/(admin)/admin/calculator/page.tsx` — исправить парсинг ответа

## Критерии приёмки
- [ ] Категория `mesh` (Сетка-рабица) валидна в API, возвращает данные из `prisma.meshType`
- [ ] Страница корректно отображает все категории номенклатуры (включая mesh)
- [ ] `npm test && npm run lint && npx tsc --noEmit` проходят
