## 2. Цели и задачи

### 2.1 Бизнес-цель
Добавить в калькулятор забора Профнастил возможность расчёта калитки с автоматическим подбором из справочника и учётом связанных номенклатур.

### 2.2 Пользовательская ценность
- Пользователь может добавить калитку в расчёт забора
- Автоматический подбор калитки по высоте забора и ширине калитки
- Автоматическое добавление связанных работ (монтаж калитки)
- Корректный расчёт количества столбов (вычитается ширина калитки из длины забора)

### 2.3 Ключевые метрики успеха
- 100% корректность подбора калитки из справочника
- Корректный расчёт столбов при наличии калитки
- Все связанные номенклатуры добавляются в смету

#### FR-2: Подбор калитки из справочника

**FR-2.1: Поиск калитки по высоте и ширине**
1. Получить высоту забора от пользователя (в метрах)
2. Получить ширину калитки от пользователя (в метрах)
3. Конвертировать в мм: 
   - `heightMm = height * 1000`
   - `widthMm = wicketWidth * 1000`
4. Найти все активные калитки с валидными сроками:
   - `active: true`
   - `validFrom IS NULL OR validFrom <= NOW()`
   - `expirationDate IS NULL OR expirationDate > NOW()`
5. **Этап 1 - Фильтр по ширине:** Найти калитки с `wicketLength >= widthMm`
   - Если есть точное совпадение по ширине - использовать их
   - Если точного совпадения нет - выбрать ближайшую большую ширину
6. **Этап 2 - Фильтр по высоте:** Из отобранных по ширине найти калитки с `wicketHeight >= heightMm`
   - Если есть точное совпадение по высоте - использовать его
   - Если точного совпадения нет - выбрать ближайшую большую высоту
7. Среди найденных выбрать с наивысшим приоритетом (`priority` минимальное значение)
8. Если калитки не найдены - вернуть ошибку

**FR-2.2: Логика выбора при отсутствии точного совпадения**
```
Пример 1 (точное совпадение по обоим параметрам):
- Пользователь: высота забора 2.0м (2000мм), ширина калитки 1.0м (1000мм)
- В справочнике: калитка 2000x1000мм
- Результат: выбрана калитка 2000x1000мм

Пример 2 (нет точного совпадения по ширине):
- Пользователь: высота 2.0м (2000мм), ширина 1.2м (1200мм)
- В справочнике: 2000x1000, 2000x1500
- Результат: выбрана калитка 2000x1500 (ближайшая большая ширина)

Пример 3 (нет точного совпадения по высоте):
- Пользователь: высота 2.2м (2200мм), ширина 1.0м (1000мм)
- В справочнике: 2000x1000, 2500x1000
- Результат: выбрана калитка 2500x1000 (ближайшая большая высота)

Пример 4 (нет точного совпадения по обоим параметрам):
- Пользователь: высота 2.2м (2200мм), ширина 1.2м (1200мм)
- В справочнике: 2000x1000, 2000x1500, 2500x1000, 2500x1500
- Этап 1 (ширина >= 1200): 2000x1500, 2500x1500
- Этап 2 (высота >= 2200): 2500x1500
- Результат: выбрана калитка 2500x1500
```

#### FR-3: Расчёт столбов при наличии калитки

**FR-3.1: Корректировка длины забора**
- При наличии калитки вычесть ширину калитки из общей длины забора
- Формула: `correctedLength = length - (wicketLength / 1000)`
- где `wicketLength` - ширина выбранной калитки в мм

**FR-3.2: Расчёт количества столбов**
- Использовать скорректированную длину для расчёта столбов
- Формула: `postCount = ceil(correctedLength / postSpacing) + 2`

**Примечание**: Аналогично реализовано для ворот (FR-3 в существующем ЧТЗ).

## 7. Примеры расчётов

### 7.1 Пример: Забор 50м с калиткой

**Входные данные:**
- Длина забора: 50 м
- Высота забора: 2.0 м (2000 мм)
- Ширина калитки: 1.0 м (1000 мм)
- Тип забора: Профнастил
- Калитка: да

**Расчёт:**

1. **Подбор калитки:**
   - Требуемая высота: 2000 мм
   - Требуемая ширина: 1000 мм
   - В справочнике есть калитки: 
     - 1800x800, 2000x1000, 2200x1200, 2500x1000
   - Этап 1 (ширина >= 1000): 2000x1000, 2200x1202, 2500x1000
   - Этап 2 (высота >= 2000): 2000x1000, 2500x1000
   - По приоритету выбрана: 2000x1000, цена 15000 ₽

2. **Корректировка длины:**
   - correctedLength = 50 - 1.0 = 49 м

3. **Расчёт столбов (на длине 49 м):**
   - postSpacing = 2.5 м
   - postCount = ceil(49 / 2.5) + 2 = 19.6 + 2 = 22 шт
   - Без калитки было бы: ceil(50 / 2.5) + 2 = 22 шт
   - **Разница: 0 столбов** (калитка шириной 1м не влияет при шаге 2.5м)

4. **Расчёт калитки:**
   - Стоимость калитки: 15000 ₽

5. **Монтаж калитки (из связанных работ):**
   - Найдена работа "Установка калитки" с ценой 3000 ₽

**Итоговая смета:**
- Столбы: ...
- Лаги: ...
- Профнастил: ...
- Калитка: 15000 ₽
- Монтаж калитки: 3000 ₽
- Монтаж забора: ...
- **Всего: ...**
