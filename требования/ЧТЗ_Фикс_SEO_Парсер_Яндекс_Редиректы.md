# ЧТЗ: Фикс SEO-парсера — Яндекс редиректы и карточки организаций

**Дата:** 2026-05-22  
**Маршрут:** Разработчик → Тестировщик  
**Исполнитель:** Разработчик  

---

## Проблема

SEO-мониторинг не находит сайт `zabor-i-naves.ru` для ключевого слова «заборы и навесы» в выдаче Яндекса, хотя сайт реально отображается на первой странице.

## Причины

### Причина 1: Фильтрация Яндекс-редиректов
В `src/services/seo/serpParser.ts:147`:
```javascript
if (!href || href.includes('yandex.') || href.includes('ya.ru')) continue;
```
Яндекс оборачивает ссылки в редиректы (`yandex.ru/clck/redir/...`). Эти ссылки фильтруются, хотя реальный URL ведёт на целевой сайт.

### Причина 2: Карточки организаций не парсятся
Для брендовых запросов Яндекс показывает карточку организации с CSS-классами, не подпадающими под селекторы `li.serp-item, [class*="serp-item"], div.Organic`.

## Решение

### TASK-FIX-001: Обработка Яндекс-редиректов
**Файл:** `src/services/seo/serpParser.ts`

1. Перед фильтрацией `href.includes('yandex.')` — извлекать реальный URL из параметра `url` редиректа
2. Если `href` содержит `/clck/` или `yandex.ru/clck` — распарсить query-параметр `url` и использовать его как реальный URL
3. Сохранить редирект-URL для логирования

### TASK-FIX-002: Расширенные селекторы Яндекс SERP
**Файл:** `src/services/seo/serpParser.ts`

1. Добавить селекторы для карточек организаций:
   - `[class*="Organic"]`, `[class*="organic"]`
   - `[class*="Card"]`, `[class*="card"]`  
   - `[class*="Business"]`, `[class*="business"]`
   - `[class*="Company"]`, `[class*="company"]`
   - `article`, `[data-log-node]`
2. Добавить фолбэк: если после основного парсинга 0 результатов — искать ВСЕ `<a>` с `href`, содержащим целевой домен (передавать домен в парсер)
3. Добавить селекторы ссылок: `a[href*="zabor-i-naves"]` как последний фолбэк

### TASK-FIX-003: Обновление тестов
**Файл:** `__tests__/services/seo/positionCollector.test.ts` (если нужно)

1. Добавить тест-кейс: Яндекс-редирект URL с реальным URL в параметре
2. Добавить тест-кейс: карточка организации с нестандартными селекторами

## Критерии приёмки

1. Парсер извлекает реальный URL из Яндекс-редиректов
2. Парсер находит результаты в карточках организаций
3. Фолбэк-механизм ищет домен во всех ссылках страницы
4. Существующие тесты проходят (`npm test`)
5. `npm run lint && npx tsc --noEmit` без ошибок
