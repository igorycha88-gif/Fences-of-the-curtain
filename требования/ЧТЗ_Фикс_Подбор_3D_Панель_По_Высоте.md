# ЧТЗ: Фикс подбора 3D-панели по высоте

## Описание проблемы
При указании высоты забора 1.5м для забора из 3D-панели калькулятор подбирает панель высотой 2030мм вместо 1530мм.

## Корневая причина
В `src/services/calculator/panel3DCalculator.ts:95-106` функция `findPanelByHeight()` при отсутствии точного совпадения высоты сортирует панели **по приоритету первым**, затем по высоте. Панель 2030мм с priority=0 выигрывает у панели 1530мм с priority=3.

## Маршрут: Разработчик (баг-фикс, <3 файлов)

## Изменяемые файлы
1. `src/services/calculator/panel3DCalculator.ts` — исправить сортировку в `findPanelByHeight()`
2. `__tests__/services/panel3DCalculator.test.ts` — обновить тесты

## Решение
Изменить сортировку fallback-панелей (строки 95-106): сортировать по **высоте (по возрастанию)** первым критерием, затем по **приоритету** как tiebreaker.

Логика: среди панелей >= требуемой высоты всегда выбираем ближайшую по высоте. Приоритет — только при одинаковой высоте.

## Критерии приёмки
1. При высоте 1.5м (1500мм) и наличии панелей 1530мм(p=3), 2030мм(p=0) → выбирается 1530мм
2. При точном совпадении высоты — работает как раньше (приоритет решает)
3. При наличии нескольких панелей одинаковой высоты — приоритет решает
4. Существующие тесты проходят (с обновлением логики)
