# ЧТЗ: SEO Парсер — Безопасная Стратегия + Telegram Отчёты

## 1. Контекст

Текущий SEO-парсер собирает позиции всех ~138 ключевых слов за один прогон с задержкой 3с между запросами. Это高风险-стратегия без прокси — Google/Yandex быстро блокируют IP. Также нет Telegram-отчётов с изменениями позиций.

## 2. Цель

1. Разбить сбор на 4 батча по ~35 ключевых слов
2. Увеличить задержку между запросами до 20с
3. Добавить паузу 2.5ч между батчами (~8 часов полный цикл)
4. Запуск по расписанию: 00:00 и 09:00 МСК
5. Telegram-отчёт в группу после каждого сбора

## 3. Маршрутизация

- **Маршрут:** 1 (Стандартная задача)
- **Исполнитель:** Разработчик
- **Сложность:** Средняя (затрагивает 4 файла, без изменений БД)

## 4. Детальные требования

### 4.1. Батчевая стратегия (positionCollector.ts)

**Текущее поведение:**
- Все ключевые слова собираются последовательно за один прогон
- Задержка: 3с (env `SEO_PARSER_DELAY`)

**Новое поведение:**
- Ключевые слова разбиваются на 4 батча по ~35 штук
- Задержка между запросами: 20с (env `SEO_PARSER_DELAY`, дефолт 20000мс)
- Пауза между батчами: 2.5ч (env `SEO_BATCH_PAUSE_MS`, дефолт 9000000мс = 2.5ч)
- Браузер открывается/закрывается для каждого батча (экономия ресурсов)
- Redis-ключ `seo:collection:session` хранит прогресс текущей сессии
- Поддержка возобновления после падения (продолжить с текущего батча)

**Метод `collectAll()` возвращает расширенный результат:**
```typescript
interface CollectionResult {
  checked: number;
  errors: number;
  skipped: number;
  blocked: number;
  totalBatches: number;
  completedBatches: number;
  currentBatch: number;
  totalKeywords: number;
  duration: number;
  batchResults: BatchResult[];
}

interface BatchResult {
  batchIndex: number;
  checked: number;
  errors: number;
  skipped: number;
  blocked: number;
  duration: number;
}
```

**Новый метод `startBatchSession()`:**
- Создаёт Redis-сессию `seo:collection:session` с TTL 12ч
- Возвращает session ID и список батчей

**Новый метод `resumeSession()`:**
- Проверяет есть ли активная сессия в Redis
- Если да — продолжает с текущего батча
- Если нет — начинает новую

### 4.2. Telegram отчёт об изменениях (seoChangeNotifier.ts)

**Новый сервис `SeoChangeNotifier`:**

После завершения сбора формирует HTML-сообщение для Telegram:

```
🔍 <b>SEO Мониторинг — 18.05.2026 09:00</b>

📊 <b>Общая статистика:</b>
✅ Проверено: 138 ключевых слов
❌ Не найдено: 12
🆕 Первые найденные: 3
⚠️ Ошибки: 0
🚫 Блокировки: 0
⏱ Длительность: 8ч 12м

🆕 <b>Первые найденные запросы:</b>
• «забор из профнастила» → позиция 5 (Google)
• «навес для машины цена» → позиция 12 (Яндекс)
• «калькулятор забора онлайн» → позиция 8 (Google)

📈 <b>Улучшения позиции (+):</b>
• «забор под ключ» 7→4 (+3) Google
• «навес из поликарбоната» 10→6 (+4) Яндекс

📉 <b>Ухудшения позиции (−):</b>
• «установка забора москва» 3→7 (−4) Google
• «забор недорого» 8→15 (−7) Яндекс
```

**Логика отчёта:**
- Сравнивает последнюю и предпоследнюю запись из `SeoPosition` для каждого ключевого слова
- `found=false` + нет предыдущих → «не найдено» (в общий подсчёт)
- `found=true` + нет предыдущих → «первый найденный» (с детализацией: название, позиция, ПС)
- `found=true` + есть предыдущий с `found=true` → «изменение позиции» (+/- разница, текущая позиция)
- `found=true` → `found=false` → «выпадение из выдачи» (отдельная категория)
- Сортировка: сначала улучшения (по убыванию дельты), затем ухудшения (по убыванию дельты)

### 4.3. Cron расписание (cron.ts)

**Текущее:** 03:00 МСК
**Новое:** 00:00 МСК и 09:00 МСК

При каждом срабатывании cron:
1. Запускает батчевый сбор (`startBatchSession()` / `resumeSession()`)
2. Сбор идёт ~8 часов (асинхронно, не блокирует сервер)
3. После завершения ВСЕХ батчей — автоматически формирует и отправляет Telegram отчёт

**Важно:** Сессия сбора НЕ должна блокировать cron-цикл. Сбор запускается в фоне.

### 4.4. Cron API endpoint (route.ts)

Обновить `POST /api/cron/seo-positions`:
- Поддерживает параметр `action`: `start` | `resume` | `status`
- `start` — начать новую сессию сбора
- `resume` — продолжить текущую
- `status` — получить статус текущей сессии
