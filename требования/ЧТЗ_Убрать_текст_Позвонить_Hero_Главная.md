# ЧТЗ (упрощённое): Убрать текст «Позвонить» из кнопки в hero главной

**Дата:** 2026-09-25
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps
**Тип:** Малая задача (UI-правка, 2 файла)

## Проблема

В hero-блоке главной страницы (мобильная версия) кнопка звонка отображает иконку телефона, слово «Позвонить» и номер телефона. Слово лишнее — нагромождает кнопку.

## Решение

Убрать слово «Позвонить» из кнопки. Оставить только иконку телефона (трубки) и номер телефона.

## Изменения

| Файл | Изменение |
|------|-----------|
| `src/components/layout/HeroCallButton.tsx` | Удалить `<span>Позвонить</span>` |
| `__tests__/components/layout/HeroCallButton.test.tsx` | Обновить тесты (проверять отсутствие слова «Позвонить» в тексте кнопки, наличие номера) |

## Критерии приёмки

1. На главной в мобильной версии кнопка показывает только иконку телефона и номер.
2. Слова «Позвонить» в видимом тексте кнопки нет.
3. `tel:`-ссылка и трекинг кликов (metrika + analytics) сохранены.
4. `title` / `aria-label` (доступность) сохранены — там слово «Позвонить» остаётся допустимо.
5. `npm test && npm run lint && npx tsc --noEmit` — зелёные.
