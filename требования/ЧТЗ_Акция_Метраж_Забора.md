## 1. Бизнес-требование

Добавить возможность указания диапазона метража забора (от и до) для акции. Скидка по акции применяется **только если длина забора попадает в указанный диапазон**. При этом баннер акции на главной странице отображается **всегда**, если акция активна — независимо от метража.

### Пример
- Акция: скидка 20% на забор из Профнастила, метраж **от 100 м**
- Клиент считает забор 80 м → акция **НЕ применяется**, скидки нет
- Клиент считает забор 100 м → акция **применяется**, скидка 20%
- Клиент считает забор 150 м → акция **применяется**, скидка 20%
- Баннер на главной отображается в любом случае (пока акция активна)

### Правила
- **minLength** (от, м) — необязательное, если указано — акция действует только при длине >= minLength
- **maxLength** (до, м) — необязательное, если указано — акция действует только при длине <= maxLength
- Оба поля пустые → акция применяется без ограничений по метражу (текущее поведение)
- Баннер на главной странице — **не фильтруется** по метражу, показывается всегда если акция активна

## 2. Изменения в БД (Prisma)

### Модель Promotion — добавить 2 поля:

```prisma
model Promotion {
  // ... существующие поля ...
  minLength  Float?    // Минимальный метраж забора (м), null = без ограничения
  maxLength  Float?    // Максимальный метраж забора (м), null = без ограничения
}
```

### Валидация:
- minLength >= 0, maxLength >= 0
- Если указаны оба: minLength <= maxLength

## 6. Риски и ограничения

- **Обратная совместимость:** Новые поля nullable — существующие акции продолжают работать без изменений
- **Кэш Redis:** При обновлении minLength/maxLength кэш инвалидируется через существующий механизм `invalidateCache`
- **Edge case:** minLength=0 эквивалентен null (без ограничения снизу)
