## 2. Цели и задачи

### 2.1 Бизнес-цель
Привести терминологию справочников Столбы и Профнастил в соответствие с бизнес-лексикой. Для данных материалов используется термин "высота", а не "длина", что более понятно пользователям.

### 2.2 Пользовательская ценность
- Понятная терминология для пользователей
- Консистентность с бизнес-терминологией
- Единообразие между справочниками

### 2.3 Ключевые метрики успеха
- Поля корректно отображаются как "Высота (мм)"
- Значения отображаются как целые числа

### TASK-FRT-002: Переименование поля в форме

**Направление:** Frontend  
**Приоритет:** Low  
**Оценка:** 20 минут  
**Зависимости:** Нет

**Описание:**
Переименовать label поля, добавить конвертацию при отображении и сохранении.

**Критерии приемки:**
- [ ] Label изменен на "Высота (мм)"
- [ ] Значение ×1000 при отображении
- [ ] Значение ÷1000 при сохранении
- [ ] Валидация обновлена (1500-6000, шаг 100)

**Технические детали:**
- Файл: `src/app/(admin)/admin/references/posts/page.tsx`
- Строки: ~495-506

```tsx
// До
<div>
  <label className="block text-sm font-medium mb-1">Длина (м) *</label>
  <input
    type="number"
    value={formValues.length || ''}
    onChange={(e) => handleFormChange('length', parseFloat(e.target.value))}
    className="w-full border rounded px-3 py-2"
    min={1.5}
    max={6.0}
    step={0.1}
    required
  />
</div>

// После
<div>
  <label className="block text-sm font-medium mb-1">Высота (мм) *</label>
  <input
    type="number"
    value={formValues.length ? Math.round(formValues.length * 1000) : ''}
    onChange={(e) => handleFormChange('length', parseFloat(e.target.value) / 1000)}
    className="w-full border rounded px-3 py-2"
    min={1500}
    max={6000}
    step={100}
    required
  />
</div>
```
