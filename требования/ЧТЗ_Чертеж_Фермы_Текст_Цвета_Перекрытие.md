# ЧТЗ: Чертёж фермы — читаемость текста, цвета, перекрытие легенды

## Проблема
1. Текст на чертеже пересекается с другими текстами и элементами чертежа (линии, узлы)
2. Цвет текста не всегда соответствует цвету отрезка, к которому он относится
3. В нижней правой части легенды текст (Масштаб) наезжает на фиолетовый кубик «Углы раскосов»

## Файл для изменения
- `src/services/truss/svgGenerator.ts`

## Задачи

### TASK-DRAW-01: Цвета текста = цвету отрезка
Текущие ошибки:
- α (углы ската): `#dc2626` (красный) → должно быть `#1e40af` (синий, цвет поясов)
- β (углы раскосов): `#7c3aed` (фиолетовый) → должно быть `#dc2626` (красный, цвет раскосов)
- «уклон=...»: `#6b7280` (серый) → должно быть `#1e40af` (синий, цвет верхнего пояса)

Уже корректно: γ (зелёный = стойки), НП/ВП (синий = пояса), С (зелёный = стойки), Р (красный = раскосы)

### TASK-DRAW-02: Защита текста от перекрытия с чертежом
Добавить «запретные зоны» (obstacles) в resolveOverlaps:
- Легенда (нижняя полоса SVG) — фиксированный прямоугольник
- Отрезки элементов (линии) — тонкие прямоугольники вдоль каждого отрезка

### TASK-DRAW-03: Исправить наезд текста на легенду
- Переместить текст «Масштаб» выше легенды или перестроить компоновку легенды
- Добавить область легенды как obstacle для меток чертежа

## Критерии приёмки
- [ ] Цвет α = синий (#1e40af), β = красный (#dc2626), уклон = синий (#1e40af)
- [ ] Текстовые метки не пересекаются с линиями чертежа
- [ ] Текстовые метки не пересекаются с легендой
- [ ] «Масштаб» не наезжает на фиолетовый кубик
- [ ] Существующие тесты проходят
