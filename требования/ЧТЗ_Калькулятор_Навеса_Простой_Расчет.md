# ЧТЗ: Простой расчёт стоимости навеса (Длина × Ширина × 8500 ₽)

**Дата:** 2026-06-17
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps
**Тип:** Малая задача (Frontend-only, 2 файла, без БД/API)

---

## 1. Постановка задачи

Временно заменить сложный расчёт стоимости навеса через API на простой:
- **Площадь** = Длина (м) × Ширина (м)
- **Стоимость** = Площадь × **8 500 ₽/м²**

Изменить UX:
- Кнопка **«Рассчитать стоимость»** — НЕ должна открывать всплывающее окно. Только показывает стоимость в правой панели «Оформить заявку».
- Всплывающее окно заявки открывается **ТОЛЬКО** по кнопке **«Оформить заявку»**.

---

## 2. Критерии приёмки

1. ✅ При нажатии «Рассчитать стоимость» стоимость вычисляется локально: `длина × ширина × 8500`.
2. ✅ Всплывающее окно НЕ открывается автоматически после расчёта.
3. ✅ Стоимость отображается в правой панели «Оформить заявку».
4. ✅ Всплывающее окно открывается только при нажатии кнопки «Оформить заявку».
5. ✅ Стоимость передаётся и отображается в модальном окне заявки.
6. ✅ Форматирование стоимости: `XX XXX руб.` (с разделением разрядов пробелом, без копеек).
7. ✅ Валидация: длина и ширина — положительные числа.
8. ✅ Аналитика (metrika/trackEvent) сохраняется.
