# ЧТЗ: Убрать стоимость из блока гаража на главной странице

**Тип задачи:** Малая (1 файл, без БД/API/архитектуры)
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps

## Постановка

На главной странице в блоке `GarageBanner` (баннер «Гараж из сендвич-панелей») отображается блок цены:
- зачёркнутая цена `от 1 450 000 ₽`
- текущая цена `от 1 250 000 ₽`
- подпись `Гараж 6×6`
- бейдж `Акция до конца июня 2026`

Заказчик просит убрать стоимость с «картинки» с гаражом.

## Решение

Убрать весь блок цены и заменить на текст **«Индивидуальный расчёт»**.

## Файлы для изменения

- `src/components/garage/GarageBanner.tsx` — удалить блок цены (строки 55-66), добавить текст «Индивидуальный расчёт»
- `__tests__/components/GarageBanner.test.tsx` — новый файл, автотесты на компонент

## Критерии приёмки

1. В DOM рендеринга `GarageBanner` отсутствуют строки: `от 1 450 000 ₽`, `от 1 250 000 ₽`, `Гараж 6×6`, `Акция до конца июня 2026`
2. Присутствует текст «Индивидуальный расчёт»
3. Кнопка «Оставать заявку» и преимущества (Гарантия/Утепление/Под ключ) сохранены
4. Модальное окно `GarageOrderModal` открывается по клику
5. `npm test && npm run lint && npx tsc --noEmit` проходят
