## 2. Цели и задачи

### 2.1 Бизнес-цель
Хранить данные о шаге столбов в миллиметрах (целые числа) для унификации с другими справочниками и исключения погрешностей float.

### 2.2 Пользовательская ценность
- Единообразие единиц измерения между справочниками
- Целочисленные значения без погрешностей float
- Консистентность с бизнес-лексикой (шаг указывается в мм)

### 2.3 Ключевые метрики успеха
- БД хранит postSpacing в мм (Int)
- UI отображает и принимает значения в мм без конвертации
- Существующие данные успешно мигрированы

**Миграция (raw SQL):**
```sql
-- Двухэтапная миграция для PostgreSQL
-- 1. Конвертировать данные
UPDATE "FenceType" SET "postSpacing" = ROUND("postSpacing" * 1000);

-- 2. Изменить тип колонки
ALTER TABLE "FenceType" ALTER COLUMN "postSpacing" TYPE INTEGER;
```
