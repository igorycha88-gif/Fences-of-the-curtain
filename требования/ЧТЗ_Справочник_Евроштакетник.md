## 2. Цели и задачи

### 2.1 Бизнес-цель
Создать справочник евроштакетника для централизованного управления номенклатурой с возможностью указания цен закупки и розничных цен, контроля сроков действия цен и автоматического расчета маржинальности.

### 2.2 Пользовательская ценность
- Централизованное управление номенклатурой евроштакетника
- Контроль актуальности цен по срокам действия
- Автоматический расчет цен за единицу и маржинальности
- Фильтрация по статусу активности и срокам действия
- Быстрый поиск нужной номенклатуры

### 2.3 Ключевые метрики успеха
- 100% новых номенклатур создаются корректно
- Корректный автоматический расчет цен за единицу и маржи
- Доступ к ценам закупки только у ADMIN роли
- Корректная фильтрация по срокам действия

#### 3.1.3 Автоматический расчет цен и маржи

**User Story 4: Автоматический расчет цен за единицу**
*Как администратор, я хочу видеть автоматически рассчитанные цены за единицу на основе метра погонного.*

**Формулы расчета:**

```
Цена закупки за ед. (₽) = (Ширина / 1000) × (Длина / 1000) × Цена за м.п. закупка
```

```
Розничная стоимость за ед. (₽) = (Ширина / 1000) × (Длина / 1000) × Розничная стоимость за м.п.
```

**Пример расчета:**
- Ширина: 125 мм = 0.125 м
- Длина: 2000 мм = 2.0 м
- Цена за м.п. закупка: 600 ₽
- Цена закупки за ед. = 0.125 × 2.0 × 600 = 150 ₽

**Acceptance Criteria:**
- Расчет происходит в реальном времени при изменении любого из полей
- Поля отображаются как readonly (серый фон)
- Формат: "150 ₽" с разделителем тысяч
- Если цена за м.п. закупка не указана - показывается "Не указана"
- Расчетные поля находятся под соответствующими полями ввода цен за м.п.

**User Story 5: Расчет и отображение маржи**
*Как администратор, я хочу видеть маржинальность номенклатуры для оценки прибыльности.*

**Формулы расчета маржи (полностью аналогично справочнику Лаги):**

```
Маржа за м.п. (%) = ((Розничная за м.п. - Закупка за м.п.) / Розничная за м.п.) × 100
```

```
Маржа за м.п. (₽) = Розничная за м.п. - Закупка за м.п.
```

```
Маржа за ед. (%) = ((Розничная за ед. - Закупка за ед.) / Розничная за ед.) × 100
```

```
Маржа за ед. (₽) = Розничная за ед. - Закупка за ед.
```

**Секция маржи (аналогично справочнику Лаги):**

```
┌─────────────────────────────────────────────────────────┐
│ Расчет маржи (только для ADMIN)                    ℹ️   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ За метр погонный:                                       │
│   Маржа: 28.6%  🟢                                      │
│   Абсолютная маржа: 200 ₽/м.п.                          │
│                                                         │
│ За единицу:                                             │
│   Маржа: 28.6%  🟢                                      │
│   Абсолютная маржа: 50 ₽/шт                             │
│                                                         │
│ ℹ️ 🟢 Маржа ≥ 30% | 🟡 10-30% | 🔴 < 10% | ⚪ Не указана │
└─────────────────────────────────────────────────────────┘
```

**Цветовая индикация маржи:**
- 🟢 Зеленый: ≥ 30%
- 🟡 Желтый: 10-30%
- 🔴 Красный: < 10%
- ⚪ Серый: цена закупки не указана

**Acceptance Criteria:**
- Секция маржи видна только для ADMIN
- Расчет происходит в реальном времени при изменении цен
- Цветовая индикация обновляется мгновенно
- Tooltip объясняет пороги маржи
- Если цена закупки не указана - показывается "Не указана" (серый цвет)

#### 4.2.1 Модель PicketType

```prisma
model PicketType {
  id                      String   @id @default(cuid())
  name                    String              // Название
  description             String?             // Описание
  metalThickness          Float               // Толщина металла (мм)
  width                   Int                 // Ширина (мм)
  length                  Int                 // Длина (мм)
  coating                 String              // Покрытие
  color                   String?             // Цвет
  purchasePricePerMeter   Float?              // Цена закупки за м.п. (₽)
  retailPricePerMeter     Float               // Розничная стоимость за м.п. (₽)
  validFrom               DateTime?           // Дата начала действия
  validUntil              DateTime?           // Срок действия (дата окончания)
  active                  Boolean  @default(true)
  image                   String?             // URL изображения
  sortOrder               Int      @default(0)
  createdAt               DateTime @default(now())
  updatedAt               DateTime @updatedAt
  
  @@index([active])
  @@index([validUntil])
  @@index([coating])
  @@index([name])
  @@unique([name, metalThickness, coating, color], name: "picket_unique_combination")
}
```

**Примечание:** Поля ширины и длины хранятся в мм (Int) для единообразия с другими справочниками.

### 6.3 Обработка ошибок

**Сценарий 1: Дублирующая комбинация**
- Валидация на сервере при создании/редактировании
- Error toast: "Номенклатура с такими параметрами уже существует"

- Валидация на клиенте: warning если purchasePricePerMeter ≥ retailPricePerMeter

- validFrom не может быть раньше сегодня (при создании)
- validUntil должен быть позднее validFrom
- Error: "Проверьте корректность дат"
