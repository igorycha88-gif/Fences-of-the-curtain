## 1. Цели и задачи

### 1.1 Бизнес-цель
Повысить качество проектной документации для производства навесов: обеспечить точные углы запила, читаемые чертежи и полную детализацию материалов в смете.

### 1.2 Пользовательская ценность
- Производство получает точные углы запила каждого элемента — сокращение брака
- Чертёж читается без наездов текста — нет путаницы на производстве
- Смета содержит полную информацию по каждому элементу: длина, углы запила с обеих сторон, профиль, толщина, количество
- Word-документ содержит все данные для передачи на производство

### 1.3 Метрики успеха
- Все вертикальные стойки на чертеже отображают углы запила
- Нет наезжающего текста ни при каких параметрах навеса
- В смете каждый элемент имеет длину, угол среза с обеих сторон, тип профиля, толщину
- Одинаковые элементы сгруппированы с указанием количества
- Для арочного пояса указана длина профиля для гибки

## 2. Функциональные требования

### 2.1 User Stories

**US-1: Углы запила вертикальных стоек на чертеже**
- **Given:** Пользователь рассчитал ферму любого типа
- **When:** Отображается чертёж фермы
- **Then:** Каждая вертикальная стойка имеет подпись с углами запила с обеих сторон: `γ₁=X° γ₂=Y°` (угол нижнего и верхнего среза)

**US-2: Обработка крайних раскосов**
- **Given:** Рассчитывается ферма с раскосами
- **When:** Последний раскос попадает на пояс фермы (параллелен поясу, угол < 5°)
- **Then:** Раскос исключается из расчёта
- **And:** Для типов DOUBLE_SLOPE и ARCH крайние раскосы ставятся симметрично: если раскос есть слева от конька, аналогичный ставится справа
- **When:** Раскос требует усиления (утилизация > 1.0) и при этом параллелен поясу
- **Then:** Раскос ставится под другим углом (шаг изменения 5°) пока не перестанет быть параллельным

**US-3: Читаемость текста на чертеже**
- **Given:** Чертёж фермы с размерами, углами и подписями
- **When:** Текстовые метки размещаются на SVG
- **Then:** Ни одна текстовая метка не пересекается с другой
- **And:** Текст не наезжает на элементы фермы (линии)
- **And:** Алгоритм автоматически сдвигает/переставляет метки при обнаружении коллизий

**US-4: Детальная смета материалов**
- **Given:** Расчёт фермы выполнен
- **When:** Отображается спецификация материалов
- **Then:** Под основной таблицей появляется секция «Детализация элементов фермы» с таблицей:
  - № элемента
  - Тип (вертикальная стойка / раскос / пояс)
  - Длина (мм)
  - Угол среза снизу (°)
  - Угол среза сверху (°)
  - Профиль (наименование + толщина)
  - Количество одинаковых (шт.)
- **And:** Одинаковые элементы (одинаковая длина ±1мм, одинаковые углы ±0.5°, одинаковый профиль) группируются в одну строку с количеством
- **And:** Для арочного пояса (тип ARCH / SINGLE_SLOPE_CURVED) указывается длина профиля, необходимого для гибки до заданного радиуса, на основе ширины навеса и высоты центральной стойки
- **And:** Вся детализация выгружается в Word-документ

### 3.3 Ключевые алгоритмы

#### 3.3.1 Расчёт углов запила стоек
Для каждой вертикальной стойки:
- **Нижний срез:** Угол между вертикалью и нижним поясом. Нижний пояс горизонтален → нижний срез = 90°
- **Верхний срез:** Угол между вертикалью и касательной к верхнему поясу в точке соединения
  - Для SINGLE_SLOPE: постоянный угол = 90° - slopeAngle
  - Для DOUBLE_SLOPE: зависит от положения (левый/правый скат)
  - Для ARCH: касательная к дуге в точке соединения

#### 3.3.2 Обработка крайних раскосов
1. После генерации всех раскосов проверить последний раскос в каждой панели
2. Если угол между раскосом и поясом < 5° → исключить раскос
3. Для DOUBLE_SLOPE и ARCH: после обработки левой половины — зеркально скопировать раскосы на правую
4. При необходимости усиления: изменить направление раскоса (шаг 5°) и пересчитать

#### 3.3.3 Анти-наезд текста (collision detection)
Алгоритм:
1. Собрать все текстовые метки с их bounding box (x, y, width, height)
2. Для каждой метки проверить пересечение со всеми остальными
3. При обнаружении коллизии — сдвинуть метку:
   - По приоритету: вверх → вниз → влево → вправо
   - Шаг сдвига: 12px
   - Максимум итераций: 20
4. Учитывать минимальные отступы от линий фермы (8px)

#### 3.3.4 Расчёт длины профиля для арочного пояса
Для типа ARCH:
- R = (halfSpan² + rise²) / (2 * rise) — радиус дуги
- ArcLength = 2 * R * arcsin(halfSpan / R) — точная длина дуги
- Это длина прямого профиля, который нужно согнуть для получения верхнего пояса

Для SINGLE_SLOPE_CURVED:
- Аналогично через интегральную длину кривой

#### 3.3.5 Группировка элементов
1. Собрать все элементы с их параметрами (длина, углы, профиль)
2. Отсортировать по типу, затем по длине
3. Сгруппировать элементы с одинаковыми:
   - длиной (±1мм)
   - углом среза снизу (±0.5°)
   - углом среза сверху (±0.5°)
   - профилем
4. Для каждой группы — указать количество
