# ЧТЗ: Реквизиты ИП и работа с юрлицами на странице «Контакты» и главной

**Дата:** 2026-10-09
**Статус:** Утверждено (варианты согласованы с пользователем)
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps (Маршрут 1)
**Тип:** Frontend-задача (без изменений БД/API/архитектуры)

---

## 1. Проблема

На сайте есть страница реквизитов `/rekvizity`, но на странице «Контакты» `/contacts`:
- нет реквизитов ИП (наименование, ИНН, ОГРНИП);
- нет юридического адреса и адреса производства;
- вместо карты — серая заглушка;
- нигде (кроме одной фразы на `/rekvizity`) не заявлено, что мы работаем с юридическими лицами (заключение договоров, счета, безнал).

Юрлица, заходящие на сайт, не видят, что исполнитель — ИП Балов Д.А. и что с ним можно работать по договору и счёту.

## 2. Цель

1. Полностью отображать реквизиты ИП (включая банковские и оба адреса) на странице «Контакты».
2. Заявить оффер «Работаем с юрлицами и ИП» на странице «Контакты» (карточка-оффер) и на главной (бейдж в hero).
3. Заменить заглушку карты на реальную Яндекс.карту с адресом производства.

## 3. Исходные данные

- Единственный источник реквизитов — `LEGAL_REQUISITES` в `src/lib/seo/constants.ts` (строки 49–62). **Хардкод реквизитов в компонентах ЗАПРЕЩЁН** — только импорт константы.
- Страница контактов: `src/app/(public)/contacts/page.tsx` (клиентский компонент, данные контактов из `useContactInfo()`).
- Главная: `src/app/page.tsx`, hero-бейджи — строки ~111–118 (паттерн: `inline-flex items-center gap-2 px-4 py-2 rounded-full bg-primary/10`).
- Страница-эталон отображения реквизитов: `src/app/(public)/rekvizity/page.tsx`.

## 4. Требования

### TASK-FRT-001. Блок «Реквизиты» на странице «Контакты»

Полный блок (все данные из `LEGAL_REQUISITES`):
- Полное наименование: `Индивидуальный предприниматель Балов Дмитрий Александрович`
- Краткое наименование: `ИП Балов Д.А.`
- Юридический адрес (полный, с индексом)
- Адрес производства (КП «Гжельские узоры», Раменский МО)
- ИНН, ОГРНИП
- Банковские реквизиты: банк, БИК, к/с, р/с
- Ссылка на страницу `/rekvizity` («Открыть страницу реквизитов»)
- Кнопка/ссылка «Скопировать реквизиты» (опционально, если не усложняет)

Разместить после карточки «Контактная информация», оформить в том же дизайн-стиле страницы (карточка, lucide-иконки).

### TASK-FRT-002. Карточка-оффер «Работаем с юридическими лицами»

Заметная карточка на странице «Контакты» (выше или рядом с реквизитами):
- Заголовок: «Работаем с юридическими лицами и ИП»
- Преимущества (списком с иконками):
  - Договор на монтаж забора/навеса
  - Счёт и безналичная оплата
  - Закрывающие документы (акты)
  - Подготовка договора и счёта — в течение 1 рабочего дня
- CTA: телефон (кликабельный, из `useContactInfo()`, с metrikaEvents как у существующих кнопок)

### TASK-FRT-003. Яндекс.карта вместо заглушки

- Убрать серую заглушку (строки ~109–118 в `contacts/page.tsx`)
- Встроить Яндекс.карту через iframe-виджет `https://yandex.ru/map-widget/v1/` (без API-ключа), поиск по адресу производства: `?text=` с текстом «КП Гжельские узоры, Раменский»
- Заголовок секции: «Мы на карте» / подпись с адресом производства
- iframe: `loading="lazy"`, `title` для a11y, адаптивная высота, className в стиле страницы
- Под картой — две строки: «Производство: …» и «Юридический адрес: …»

### TASK-FRT-004. Бейдж на главной странице

- В hero главной (`src/app/page.tsx`, блок бейджей ~111–118) добавить третий бейдж:
  - Иконка `Building2` (lucide-react)
  - Текст: «Работаем с юрлицами»
- Стиль — идентично существующим бейджам.

### TASK-TST-005. Автотесты

- Тесты рендера страницы контактов: наличие реквизитов (ИНН, ОГРНИП, наименование, оба адреса, банк, р/с), карточки «Работаем с юридическими лицами», iframe Яндекс.карты, ссылки на /rekvizity
- Тест главной: наличие бейджа «Работаем с юрлицами»
- Данные для тестов — импортировать из `LEGAL_REQUISITES` (не дублировать строки в тестах, кроме проверки конкретных значений)

## 5. Не входит в объём

- Изменение `/rekvizity`, футеров, SEO-констант, БД, API
- Реальная карта на других страницах

## 6. Критерии приёмки

1. На `/contacts` видны ВСЕ реквизиты из `LEGAL_REQUISITES`, включая банковские и оба адреса
2. Реквизиты не захардкожены в компоненте — импорт из `LEGAL_REQUISITES`
3. Карточка «Работаем с юридическими лицами и ИП» с 4 преимуществами и CTA-телефоном есть на `/contacts`
4. На главной в hero есть бейдж «Работаем с юрлицами»
5. Вместо заглушки — iframe Яндекс.карты (lazy, title, адаптив)
6. `npm test && npm run lint && npx tsc --noEmit` — все зелёные
7. Вёрстка адаптивна (мобильная/десктоп), стиль согласуется с существующим дизайном страниц

## 7. Риски

- Координаты/поиск КП «Гжельские узоры» на карте — если поиск по тексту неточный, согласовать с пользователем точку/координаты
- iframe Яндекса может не загрузиться в dev-контейнере (сеть) — допустим fallback: блок с текстовым адресом уже есть под картой
