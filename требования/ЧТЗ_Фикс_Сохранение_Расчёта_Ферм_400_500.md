# ЧТЗ: Фикс ошибок 400/500 при сохранении расчёта ферм

**Дата:** 2026-04-13  
**Маршрут:** Стандартный (Аналитик → Разработчик → Тестировщик → DevOps)  
**Приоритет:** HIGH  

## Описание проблемы

При работе калькулятора ферм возникают 2 ошибки:
1. **400 Bad Request** на `POST /api/admin/truss-calculations/calculate`
2. **500 Internal Server Error** на `POST /api/admin/truss-calculations` (сохранение)

## Корневые причины

### Баг 1: archProfileId = '' вызывает FK violation (500)

**Файл:** `src/app/api/admin/truss-calculations/route.ts:124`

Для типов навеса DOUBLE_SLOPE и SINGLE_SLOPE (без арки) форма отправляет `archProfileId: ''` (пустая строка). Zod-схема валидирует это корректно (`.or(z.literal(''))`), но при передаче в Prisma `create()` пустая строка `''` не равна `null` — Prisma пытается создать FK-связь с несуществующей записью `id = ''` → foreign key constraint violation → 500.

### Баг 2: wallHeight отправляется для всех типов навеса

**Файл:** `src/components/admin/TrussCalculator/TrussCalculatorForm.tsx`

Форма ВСЕГДА отправляет `wallHeight: 2500` (дефолт), даже для DOUBLE_SLOPE и ARCH, где поле скрыто. Это не вызывает 400 напрямую, но создаёт путаницу. Реальная причина 400 — Zod refine-проверка `wallHeight < ridgeHeight` для SINGLE_SLOPE/SINGLE_SLOPE_CURVED при некорректных значениях.

## Критерии приёмки

1. **500 исправлен:** Сохранение расчёта работает для ВСЕХ типов навеса (DOUBLE_SLOPE, ARCH, SINGLE_SLOPE, SINGLE_SLOPE_CURVED)
2. **400 исправлен:** Calculate endpoint не падает с 400 при корректных входных данных
3. **archProfileId:** Пустая строка `''` конвертируется в `null` перед Prisma create
4. **wallHeight:** Для DOUBLE_SLOPE и ARCH поле wallHeight не отправляется или корректно обрабатывается
5. **Регрессия:** Существующие расчёты SINGLE_SLOPE/SINGLE_SLOPE_CURVED не сломаны

## Файлы для изменения

1. `src/app/api/admin/truss-calculations/route.ts` — конвертация archProfileId '' → null
2. `src/components/admin/TrussCalculator/TrussCalculatorForm.tsx` — очистка wallHeight для ненужных типов
3. `src/app/api/admin/truss-calculations/[id]/route.ts` — проверка аналогичного бага при обновлении
