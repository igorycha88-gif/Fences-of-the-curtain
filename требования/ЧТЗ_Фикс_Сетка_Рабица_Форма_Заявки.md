# ЧТЗ: Фикс отображения параметров сетки-рабица в форме индивидуального расчёта

## Описание проблемы
При расчёте забора типа "Сетка-рабица", если не найдена номенклатура для расчёта, открывается модалка `NomenclatureNotFoundModal` для заполнения заявки. Однако параметры сетки (покрытие, размер ячейки, толщина прутка) не передаются в форму заявки, поэтому пользователь не видит полную информацию о своём выборе.

## Текущее поведение
- Пользователь выбирает параметры сетки-рабица (покрытие, размер ячейки, толщина прутка)
- При расчёте возникает ошибка `NO_MESH_FOUND`
- Открывается модалка для индивидуального расчёта
- Параметры сетки НЕ отображаются в модалке (показываются только базовые параметры)

## Желаемое поведение
- Пользователь выбирает параметры сетки-рабица
- При расчёте возникает ошибка `NO_MESH_FOUND`
- Открывается модалка для индивидуального расчёта
- В модалке отображаются ВСЕ параметры включая параметры сетки (покрытие, размер ячейки, толщина прутка)

## Критерии приёмки
1. В интерфейсе `FenceParameters` (NomenclatureNotFoundModal.tsx) добавлены поля:
   - `meshCoating?: string`
   - `meshCellSize?: number`
   - `meshWireThickness?: number`

2. В отображении параметров модалки добавлена секция для параметров сетки (строки ~300-336 в NomenclatureNotFoundModal.tsx)

3. В fence/page.tsx при передаче `fenceParameters` в модалку добавлены поля сетки:
   - `meshCoating`
   - `meshCellSize`
   - `meshWireThickness`

4. Параметры сетки корректно отображаются в модалке для типа забора "Сетка-рабица"
