## 1. Контекст

Калькулятор ферм разбивает нижний и верхний пояса на отрезки по панелям. На практике:
- **Нижний пояс** — это один цельный профиль на всю длину фермы
- **Верхний пояс** — зависит от типа крыши, но также состоит из цельных кусков
- Обозначения элементов (НП-1, ВП-1 и т.д.) не отображаются на SVG-схеме
- Нет вкладки для просмотра сохранённых расчётов

---

## 2. Требования

### 2.1. Нижний пояс — цельный кусок

**Текущее поведение:** Нижний пояс разбит на N отрезков (по количеству панелей), каждый отрезок отображается в Детализации как отдельный элемент `НП-1`, `НП-2`, ...

**Новое поведение:** Нижний пояс отображается как **один элемент** `НП-1` с длиной = полная ширина фермы (span). Запилы = 90° с обеих сторон (горизонтальный профиль).

**Правила:**
- В Детализации элементов: 1 строка `НП-1` с длиной = `span` мм
- В спецификации материалов: без изменений (уже считается как общая длина)
- Cut angles: bottomCutAngle = 90°, topCutAngle = 90°

### 2.2. Верхний пояс — цельные куски по типам крыши

**Текущее поведение:** Верхний пояс разбит на N отрезков по панелям.

**Новое поведение зависит от типа крыши:**

| Тип крыши | Количество цельных кусков | Описание |
|-----------|--------------------------|----------|
| SINGLE_SLOPE | 1 кусок `ВП-1` | От начала до конца верхнего пояса |
| SINGLE_SLOPE_CURVED | 1 кусок `ВП-1` | От начала до конца (длина = arcLength) |
| DOUBLE_SLOPE | 2 куска `ВП-1`, `ВП-2` | Левый скат (до конька) + Правый скат (от конька) |
| ARCH | 1 кусок `ВП-1` | От начала до верхней точки центральной стойки (длина = arcLength до центра) |

**Углы запилов для верхнего пояса:**

| Тип крыши | Элемент | Запил снизу (начало) | Запил сверху (конец) |
|-----------|---------|---------------------|---------------------|
| SINGLE_SLOPE | ВП-1 | edgeAngles.leftAngle | edgeAngles.rightAngle (или 90° если вырожденный) |
| SINGLE_SLOPE_CURVED | ВП-1 | 90° (касательная в начале = 0°) | 90° (касательная в конце ≈ угол наклона) |
| DOUBLE_SLOPE | ВП-1 (левый) | edgeAngles.leftAngle | 90° (в коньке перегиб) |
| DOUBLE_SLOPE | ВП-2 (правый) | 90° (в коньке перегиб) | edgeAngles.rightAngle |
| ARCH | ВП-1 | 90° (касательная в начале горизонтальна) | 90° (касательная в верхней точке горизонтальна) |

### 2.3. Метки элементов на SVG-схеме

**Текущее поведение:** На схеме отображаются только углы раскосов (β₁, β₂), углы стоек (γ₁, γ₂), размерные линии, углы скатов, легенда.

**Новое поведение:** На каждый элемент фермы наносится текстовая метка (обозначение из Детализации):
- `НП-1` — на нижний пояс (по центру)
- `ВП-1`, `ВП-2` — на верхний пояс (по центру каждого цельного куска)
- `Стойка-1`, `Стойка-2`, ... — рядом с вертикальными стойками
- `Раскос-1`, `Раскос-2`, ... — рядом с раскосами

**Требования к меткам:**
- Цвет метки должен соответствовать типу элемента (пояса — синий, стойки — зелёный, раскосы — красный)
- Шрифт: 8px, bold
- Метки НЕ должны наезжать на другие надписи (использовать существующий механизм `resolveOverlaps`)
- Метки стоек и раскосов размещаются рядом с серединой элемента

### 2.4. Углы запилов верхнего пояса в Детализации

**Текущее поведение:** Верхний пояс имеет cutAngles = {90, 90}.

**Новое поведение:** Для каждого цельного куска верхнего пояса отображаются реальные углы запилов на концах профиля (см. таблицу в п. 2.2).

### 2.5. Вкладка «Расчёты ферм»

**Текущее поведение:** Страница `/admin/truss-calculator` содержит только калькулятор.

**Новое поведение:** Добавить вкладку-переключатель вверху страницы:
- **Вкладка 1:** «Калькулятор» (текущий интерфейс расчёта)
- **Вкладка 2:** «Расчёты» (список сохранённых расчётов)

**Вкладка «Расчёты»:**
- Таблица со списком сохранённых расчётов: №, Название, Тип навеса, Ширина, Дата создания, Автор, Действия
- Действия: «Просмотр» (загружает расчёт в калькулятор), «Удалить» (с подтверждением)
- При просмотре: отображается полная информация расчёта (схема, нагрузки, спецификация, детализация)
- API уже существует: GET /api/admin/truss-calculations, GET /api/admin/truss-calculations/[id], DELETE /api/admin/truss-calculations/[id]

## 3. Критерии приёмки

1. ✅ Нижний пояс отображается как 1 элемент `НП-1` с длиной = span во всех типах крыши
2. ✅ Верхний пояс SINGLE_SLOPE — 1 элемент ВП-1 с полной длиной и правильными углами запилов
3. ✅ Верхний пояс SINGLE_SLOPE_CURVED — 1 элемент ВП-1 с длиной arcLength и углами запилов
4. ✅ Верхний пояс DOUBLE_SLOPE — 2 элемента ВП-1 (левый скат) и ВП-2 (правый скат) с углами запилов
5. ✅ Верхний пояс ARCH — 1 элемент ВП-1 с длиной arcLength/2 (от начала до центра) и углами запилов
6. ✅ На SVG-схеме отображаются метки всех элементов (НП-1, ВП-1, Стойки, Раскосы)
7. ✅ Метки не наезжают на другие надписи на схеме
8. ✅ Углы запилов верхнего пояса корректно отображаются в Детализации элементов
9. ✅ Вкладка «Расчёты» показывает список сохранённых расчётов
10. ✅ Можно просмотреть сохранённый расчёт (полная информация)
11. ✅ Можно удалить сохранённый расчёт (с подтверждением)
