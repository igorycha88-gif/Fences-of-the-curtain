# ЧТЗ: Модальное окно «Индивидуальный запрос» при отсутствии номенклатуры в калькуляторе

## Версия: 1.0
## Дата: 2026-03-31
## Автор: AI-аналитик
## Приоритет: High
## Статус: Draft

---

## 1. Цели и задачи

### 1.1 Бизнес-цель
Не терять клиентов, у которых не получилось рассчитать забор в калькуляторе из-за отсутствия нужной номенклатуры в справочнике. Превратить негативный опыт (ошибка расчёта) в лид — заявку на индивидуальный расчёт, которую менеджер обработает вручную.

### 1.2 Пользовательская ценность
Клиент не уходит с сайта при ошибке расчёта, а оставляет контактные данные. Менеджер получает заявку с параметрами забора, которые клиент хотел рассчитать, и может предложить альтернативу или индивидуальный расчёт.

### 1.3 Метрики успеха
- Конверсия из ошибки расчёта в заявку: >30%
- Время заполнения формы: < 60 секунд
- Все заявки отображаются во вкладке «Заявки» без нарушения текущей логики

## 3. Функциональные требования

### 3.1 User Stories

#### US-1: Клиент видит дружелюбное модальное окно при ошибке расчёта

**Как** клиент,  
**Я хочу** получить понятное объяснение, почему расчёт не выполнен, и возможность оставить заявку на индивидуальный расчёт,  
**Чтобы** не уйти с сайта и получить помощь менеджера.

**Acceptance Criteria**:
```
Given я заполнил параметры забора в калькуляторе
When нажимаю «Рассчитать стоимость»
And сервер возвращает ошибку, связанную с отсутствием номенклатуры
Then вместо alert() показывается модальное окно
And окно содержит дружелюбное сообщение с объяснением ситуации
And окно содержит форму для ввода контактных данных
And окно содержит кнопку «Отправить заявку»
And фон затемнён, окно центрировано
And есть кнопка закрытия окна (крестик)
```

#### US-2: Клиент заполняет контактную форму

**Как** клиент,  
**Я хочу** быстро оставить свои контактные данные,  
**Чтобы** менеджер связался со мной для индивидуального расчёта.

**Acceptance Criteria**:
```
Given модальное окно открыто
When я заполняю обязательные поля (Имя, Телефон)
And нажимаю «Отправить заявку»
Then данные валидируются на клиенте
And при успешной отправке показывается сообщение «Заявка отправлена!»
And окно закрывается через 2 секунды
And при ошибке валидации подсвечиваются проблемные поля
And при ошибке сервера показывается понятное сообщение
```

#### US-3: Пустая заявка создаётся и отображается во вкладке «Заявки»

**Как** менеджер,  
**Я хочу** видеть заявки от клиентов, у которых не получился расчёт,  
**Чтобы** связаться с ними и предложить индивидуальный расчёт.

**Acceptance Criteria**:
```
Given клиент отправил форму из модального окна
When заявка создана
Then она появляется во вкладке «Заявки» (/admin/orders)
And calculatedCost = 0
And estimateId = null (нет привязки к смете)
And в колонке «Сумма» отображается «Индивидуальный расчёт» или «0 ₽»
And в колонке «Смета» отображается «—» (нет ссылки)
And параметры забора сохранены в поле parameters
And статус заявки = NEW
```

#### US-4: Менеджер видит параметры забора в деталях заявки

**Как** менеджер,  
**Я хочу** видеть параметры забора, которые клиент хотел рассчитать,  
**Чтобы** подобрать подходящую номенклатуру и подготовить индивидуальный расчёт.

**Acceptance Criteria**:
```
Given я открыл детали пустой заявки
When просматриваю заявку
Then вижу контактные данные клиента (имя, телефон, email, комментарий)
And вижу параметры забора: тип забора, длина, высота
And вижу дополнительные параметры (ворота, калитка, покрытие и т.д.)
And вижу пометку «Индивидуальный расчёт»
```

### 5.1 Изменения в БД

**Не требуются.** Существующая модель `Order` уже поддерживает:

### 5.2 API спецификация

#### POST /api/orders (расширение существующего endpoint)

**Новый сценарий** — создание пустой заявки при отсутствии номенклатуры:

**Request**:
```json
{
  "clientName": "Иван Петров",
  "phone": "+7 (900) 123-45-67",
  "email": "ivan@example.com",
  "message": "Нужен забор из профнастила с коричневым покрытием",
  "isIndividualRequest": true,
  "fenceParameters": {
    "fenceTypeId": "clm123...",
    "fenceTypeName": "Профнастил",
    "length": 50,
    "height": 2.0,
    "coating": "POLYMER_SINGLE",
    "hasGate": true,
    "gateType": "SWING",
    "gateWidth": 4.0,
    "hasWicket": false,
    "soilType": "normal",
    "lagRows": 2
  }
}
```

**Response (201)**:
```json
{
  "id": "clt789xyz",
  "status": "NEW",
  "statusLabel": "Новая",
  "calculatedCost": 0,
  "isIndividualRequest": true,
  "createdAt": "2026-03-31T10:30:00Z"
}
```

**Response (400)**:
```json
{
  "error": "VALIDATION_ERROR",
  "message": "Ошибка валидации",
  "details": ["phone is required"]
}
```

**Response (429)**:
```json
{
  "error": "RATE_LIMIT_EXCEEDED",
  "message": "Слишком много запросов. Попробуйте позже."
}
```

export const individualOrderSchema = z.object({
