## 1. Описание задачи

Корректировка геометрии калькулятора ферм: изменение минимальной высоты конька, устранение подъёма по краям (стропила начинаются с перекладины), изменение направления диагональных раскосов на чередующееся, расчёт и отображение углов на чертеже.

## 2. Требования

### 2.1. Минимальная высота в коньке — 500 мм (TASK-GEO-001)

**Файлы:** `src/lib/validators/trussCalculator.ts`, `src/components/admin/TrussCalculator/TrussCalculatorForm.tsx`

- Изменить минимальное значение `ridgeHeight` с 1500 мм на **500 мм** в:
  - Zod-схеме `trussCalculationRequestSchema` (поле `ridgeHeight: z.number().min(500).max(6000)`)
  - Zod-схеме `saveTrussCalculationSchema` (аналогично)
  - HTML-атрибуте `min={500}` в форме `TrussCalculatorForm.tsx` (поле «Высота в коньке/центре»)
- Также изменить минимальное значение `wallHeight` с 1500 мм на **500 мм** в:
  - Обеих Zod-схемах
  - HTML-атрибуте `min={500}` в форме

### 2.2. Геометрия без подъёма по краям — стропила начинаются с перекладины (TASK-GEO-002)

**Файлы:** `src/services/truss/trussGeometry.ts`, `src/services/truss/loadCalculator.ts`, `src/services/truss/svgGenerator.ts`, `src/services/truss/types.ts`

#### Общее правило
Верхний пояс (стропила) по краям фермы начинается **на уровне нижнего пояса (перекладины)**, т.е. y=0. Подъём отсутствует. Образуется острый угол между верхним и нижним поясом.

#### DOUBLE_SLOPE (двухскатная)
- Оба края верхнего пояса начинаются на уровне y=0 (нижний пояс)
- Текущее значение `eaveHeight = ridgeHeight * 0.35` — **заменить на 0**
- Стропила поднимаются от y=0 (края) до y=ridgeHeight (конёк в центре)
- Два острых угла по краям — рассчитываются и отображаются на схеме
- Формула угла: `α = arctan(ridgeHeight / (width/2))` (в градусах)

#### SINGLE_SLOPE (односкатная)
- Один край (левый — низкая стена): верхний пояс на уровне y=0 (без подъёма, острый угол)
- Другой край (правый): верхний пояс на уровне y=wallHeight (регулируется полем «Высота у узкой стены»)
- Высота в коньке (ridgeHeight) остаётся максимальной высотой
- wallHeight может быть 0 (без подъёма) или любым значением ≥ 0

**Уточнение:** Для SINGLE_SLOPE:
- Левый край: верхний пояс y=0 (острый угол с нижним поясом)
- Правый край: верхний пояс y=ridgeHeight
- wallHeight определяет высоту правого (высокого) края и может не использоваться в геометрии напрямую, если ridgeHeight уже задаёт максимальную высоту

#### SINGLE_SLOPE_CURVED (односкатная в дуге)
- Левый край дуги начинается с y=0 (без подъёма, с перекладины)
- Правый край — на уровне y=ridgeHeight
- Дуга (sin-кривая) строится от y=0 до y=ridgeHeight без дополнительного подъёма

#### ARCH (арочная)
- Оба края дуги начинаются с y=0 (без подъёма, с перекладины)
- Дуга поднимается от y=0 (края) до y=ridgeHeight (центр)
- Текущее значение `bottomH = ridgeHeight * 0.3` — **заменить на 0**
- Два острых угла по краям — рассчитываются и отображаются

#### Расчёт углов для всех типов

Для острых углов по краям (где верхний пояс встречает нижний):
- **DOUBLE_SLOPE / ARCH:** `α = arctan(ridgeHeight / (width/2))` — угол в градусах с округлением до 1 знака
- **SINGLE_SLOPE / SINGLE_SLOPE_CURVED:** левый угол = `arctan(ridgeHeight / width)`, правый — угол схода

Для арочной фермы: угол в точке касания арки к нижнему поясу:
- Рассчитать как производную в точке x=0: `α = arctan(halfSpan / R)` где R — радиус арки
- При new geometry: R = (halfSpan² + ridgeHeight²) / (2 * ridgeHeight)

#### Новое поле в типах
Добавить в `TrussGeometryResult` (types.ts):
```ts
edgeAngles?: {
  leftAngle: number;   // градус острого угла у левого края
  rightAngle?: number;  // градус острого угла у правого края (для симметричных — равен leftAngle)
};
```

### 2.3. Чередующиеся диагональные раскосы (TASK-GEO-003)

**Файлы:** `src/services/truss/trussGeometry.ts`

#### Текущее поведение
Все диагональные раскосы направлены в одну сторону (например, от нижнего узла к следующему верхнему).

#### Новое поведение
Диагональные раскосы чередуются по направлению — образуют V-образный / домообразный паттерн:
- Начиная от конька (центра фермы), раскосы расходятся в разные стороны
- В центре — вертикальная стойка (как «крыша домика»)
- От конька к краям: раскосы идут в виде «ёлочки» (V-паттерн), чередуя направление
- Внешний вид: как треугольники, соединённые вершинами — /\ /\ /\

**Для DOUBLE_SLOPE:**
- Центральная панель: вертикальная стойка от нижнего пояса до конька
- От центра к краям: диагонали чередуются — одна идёт вверх-вправо, следующая вверх-влево
- Паттерн: в каждой панели — один диагональный раскос, направление чередуется через панель

**Для SINGLE_SLOPE / SINGLE_SLOPE_CURVED:**
- Аналогичный V-паттерн от одного края до другого
- Направление чередуется через панель

**Для ARCH:**
- Аналогичный V-паттерн с центральной вертикальной стойкой

#### Реализация
В функциях `buildSingleSlope`, `buildDoubleSlope`, `buildArch`, `buildSingleSlopeCurved`:
- Заменить диагональные раскосы на чередующиеся
- Для чётных панелей: раскос от нижнего узла к следующему верхнему
- Для нечётных панелей: раскос от верхнего узла к следующему нижнему
- Это создаст V-образный паттерн

### 2.4. Углы прилегания раскосов к стропиле и перекладине (TASK-GEO-004)

**Файлы:** `src/services/truss/trussGeometry.ts`, `src/services/truss/svgGenerator.ts`, `src/services/truss/types.ts`

#### Требование
Для каждого диагонального раскоса рассчитать и отобразить на чертеже:
1. Угол между раскосом и нижним поясом (перекладиной)
2. Угол между раскосом и верхним поясом (стропилой)

#### Добавить в TrussMember (types.ts):
```ts
diagonalAngles?: {
  angleToBottomChord: number; // градус между раскосом и нижним поясом
  angleToTopChord: number;    // градус между раскосом и верхним поясом
};
```

#### Расчёт
- `angleToBottomChord` = угол между вектором раскоса и горизонталью (нижний пояс горизонтальный)
  - Для раскоса от (x1,0) к (x2,y2): `arctan(|y2| / |x2-x1|)` в градусах
- `angleToTopChord` = угол между вектором раскоса и вектором верхнего пояса в точке соединения
  - Рассчитать как разницу между углом раскоса и углом верхнего пояса в данной точке

#### Отображение на SVG
- Для каждого диагонального раскоса вывести два угла:
  - Угол у нижнего пояса (возле точки соединения с нижним поясом)
  - Угол у верхнего пояса (возле точки соединения с верхним поясом)
- Формат: `β₁=XX.X°` (к нижнему поясу), `β₂=XX.X°` (к верхнему поясу)
- Шрифт: 9px, цвет: #7c3aed (фиолетовый), чтобы отличать от других аннотаций

## 3. Критерии приёмки

1. **TASK-GEO-001:** Минимальная высота в коньке = 500 мм (валидация Zod + форма HTML)

   - DOUBLE_SLOPE: eaveHeight = 0
   - ARCH: bottomH = 0
   - SINGLE_SLOPE: левый край y=0
   - SINGLE_SLOPE_CURVED: левый край y=0

6. Нагрузки пересчитаны корректно с учётом новой геометрии
