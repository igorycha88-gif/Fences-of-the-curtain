## 1. Цели и задачи

### 1.1 Бизнес-цель
Упростить и автоматизировать расчёт закупочной цены за единицу профнастила на основе базовой цены за метр погонный, что позволит:
- Унифицировать подход к ценообразованию
- Снизить количество ошибок при вводе цен
- Ускорить процесс добавления новых номенклатур

### 1.2 Пользовательская ценность
Менеджеры и администраторы смогут вводить цену за метр погонный, а система автоматически рассчитает цену за единицу (лист) на основе длины листа.

### 1.3 Метрики успеха
- 100% автоматический расчёт purchasePricePerUnit при наличии purchasePricePerLinearMeter
- Время сохранения карточки: < 500ms
- Отсутствие ошибок в расчётах

## 2. Функциональные требования

### 2.1 User Stories

#### US-1: Ввод стоимости за метр погонный
**Как** администратор/менеджер,  
**Я хочу** вводить стоимость закупки за метр погонный,  
**Чтобы** система автоматически рассчитала цену за единицу.

**Acceptance Criteria**:
```
Given я нахожусь в форме создания/редактирования профнастила
When ввожу значение в поле "Стоимость закупки за м.п. (₽)"
And ввожу длину листа (высоту)
Then вижу автоматически рассчитанное значение в поле "Цена закупки за ед. (₽)"
And поле "Цена закупки за ед. (₽)" отображается как readonly (только чтение)
And расчёт: Цена закупки за ед. = Стоимость за м.п. × (Длина листа / 1000)
```

#### US-2: Автоматический расчёт при изменении параметров
**Как** администратор/менеджер,  
**Я хочу** видеть пересчёт цены при изменении длины листа или стоимости за м.п.,  
**Чтобы** контролировать корректность расчёта в реальном времени.

**Acceptance Criteria**:
```
Given в форме заполнены поля "Стоимость за м.п." и "Длина листа"
When изменяю любое из этих значений
Then поле "Цена закупки за ед." автоматически обновляется
And отображается индикатор "Автоматически рассчитано"
```

#### US-3: Отображение в таблице справочника
**Как** администратор,  
**Я хочу** видеть стоимость за метр погонный в таблице справочника,  
**Чтобы** сравнивать цены между номенклатурами.

**Acceptance Criteria**:
```
Given я нахожусь на странице справочника профнастила
And моя роль ADMIN
When смотрю на колонки таблицы
Then вижу колонку "Закупка за м.п. (₽)"
And вижу колонку "Закупка за ед. (₽)"
And обе колонки отображают корректные значения
```

#### US-4: Ограничение доступа для не-администраторов
**Как** система,  
**Я хочу** скрывать закупочные цены от роли MANAGER,  
**Чтобы** защитить коммерческую информацию.

**Acceptance Criteria**:
```
Given пользователь авторизован как MANAGER
When открывает форму создания/редактирования профнастила
Then НЕ видит поле "Стоимость закупки за м.п. (₽)"
And НЕ видит поле "Цена закупки за ед. (₽)"
And НЕ видит эти колонки в таблице
```

### 4.6 Логика расчёта

**Файл**: `src/services/admin/profnastilTypeService.ts`

```typescript
async create(data: ProfnastilTypeInput, userId: string) {
  // Автоматический расчёт purchasePricePerUnit
  let purchasePricePerUnit = data.purchasePricePerUnit;
  
  if (data.purchasePricePerLinearMeter !== null && 
      data.purchasePricePerLinearMeter !== undefined &&
      data.length) {
    // Формула: цена за м.п. × длина листа в метрах
    purchasePricePerUnit = roundToTwo(
      data.purchasePricePerLinearMeter * (data.length / 1000)
    );
  }
  
  const profnastil = await prisma.profnastilType.create({
    data: {
      // ... существующие поля ...
      purchasePricePerLinearMeter: data.purchasePricePerLinearMeter,
      purchasePricePerUnit,  // Рассчитанное значение
      // ...
    },
  });
  
  // ...
}

async update(id: string, data: ProfnastilTypeUpdate, userId: string) {
  // При обновлении purchasePricePerLinearMeter или length - пересчитать purchasePricePerUnit
  if (data.purchasePricePerLinearMeter !== undefined || data.length !== undefined) {
    const existing = await prisma.profnastilType.findUnique({ where: { id } });
    
    const pricePerMeter = data.purchasePricePerLinearMeter ?? existing?.purchasePricePerLinearMeter;
    const length = data.length ?? existing?.length;
    
    if (pricePerMeter !== null && pricePerMeter !== undefined && length) {
      data.purchasePricePerUnit = roundToTwo(pricePerMeter * (length / 1000));
    }
  }
  
  // ...
}

// Вспомогательная функция округления
function roundToTwo(num: number): number {
  return Math.round(num * 100) / 100;
}
```
