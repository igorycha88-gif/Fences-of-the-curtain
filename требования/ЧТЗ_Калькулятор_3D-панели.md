## 1. Цели и задачи

### 1.1 Бизнес-цель
Создать отдельный сервис-калькулятор для забора из 3D-панелей с автоматическим подбором 3D-панелей по высоте забора и расчётом всех необходимых материалов и работ.

### 1.2 Пользовательская ценность
- Пользователь может рассчитать стоимость забора из 3D-панелей
- Автоматический подбор 3D-панели по высоте забора
- Автоматический расчёт количества панелей, столбов, лаг, фурнитуры и работ
- Возможность добавить ворота и калитку к забору из 3D-панелей
- Корректная смета с учётом всех позиций

### 1.3 Ключевые метрики успеха
- 100% корректность подбора 3D-панели из справочника
- Корректный расчёт количества панелей (стык в стык)
- Корректный расчёт столбов с учётом +1200 мм к высоте забора
- Все связанные номенклатуры (фурнитура, работы) добавляются в смету

### 3.2 Калькулятор 3D-панелей

#### FR-4: Подбор 3D-панели по высоте

**FR-4.1: Логика поиска**
1. Получить высоту забора от пользователя (в метрах)
2. Конвертировать в мм: `requiredHeightMm = height * 1000`
3. Найти все активные 3D-панели с валидными сроками:
   - `active: true`
   - `validFrom IS NULL OR validFrom <= NOW()`
   - `validUntil IS NULL OR validUntil > NOW()`
4. Найти панели с `height >= requiredHeightMm`
5. Из найденных выбрать:
   - Сначала по минимальному `priority` (меньшее значение = выше приоритет)
   - Если одинаковый priority - выбрать с наименьшей высотой
6. Если панели не найдены - вернуть ошибку

**FR-4.2: Примеры подбора**
```
Пример 1 (точное совпадение):
- Требуемая высота: 2000 мм
- В справочнике: панель 2000x2500 (priority 0), панель 2500x2500 (priority 0)
- Результат: выбрана панель 2000x2500

Пример 2 (нет точного совпадения):
- Требуемая высота: 2200 мм
- В справочнике: панель 2000x2500 (priority 0), панель 2500x2500 (priority 0)
- Результат: выбрана панель 2500x2500 (ближайшая большая высота)
```

---

#### FR-5: Расчёт количества 3D-панелей

**FR-5.1: Формула расчёта**
- Конвертировать длину забора в мм: `fenceLengthMm = length * 1000`
- Получить ширину панели из справочника: `panelWidthMm`
- Количество панелей: `panelsCount = roundUp(fenceLengthMm / panelWidthMm)`
- Монтаж стык в стык без нахлёста

**FR-5.2: Пример расчёта**
```
Длина забора: 50 м (50000 мм)
Ширина панели: 2500 мм
Количество: roundUp(50000 / 2500) = 20 шт
```

---

#### FR-6: Расчёт столбов

**FR-6.1: Формула расчёта высоты столба**
- Требуемая высота столба = `fenceHeightMm + 1200 мм`
- Пример: забор 2.0 м → столбы 3200 мм высотой

**FR-6.2: Формула расчёта количества**
- Использовать существующий сервис `postCalculator.calculatePosts`
- Шаг столбов: `postSpacing` из `FenceType` (для типа забора "3D-панели")
- Формула: `postCount = ceil(correctedLength / postSpacing) + 2`

**FR-6.3: Подбор столбов**
- Использовать существующий сервис `postCalculator`
- Подбор столбов по рассчитанной высоте (аналогично профнастилу)

---

#### FR-7: Расчёт лаг

**FR-7.1: Количество рядов лаг**
- Пользователь выбирает: 2 или 3 ряда
- По умолчанию: 2 ряда

**FR-7.2: Формула расчёта**
- Использовать существующий сервис `lagCalculator.calculateLags`
- Принять от пользователя: `lagRows` (2 или 3)

---

#### FR-8: Ворота и калитка

**FR-8.1: Логика работы**
- Ворота и калитка работают аналогично профнастилу
- Использовать существующие сервисы: `gateLookup`, `wicketLookup`
- Корректировка длины забора при наличии ворот/калитки

**FR-8.2: Корректировка длины**
```
correctedLength = length - gateLength - wicketLength
```

---

#### FR-9: Фурнитура для 3D-панелей

**FR-9.1: Расчёт фурнитуры**
- Использовать существующий сервис `mountingHardwareCalculator`
- Передать параметры:
  - `panel3dId` - ID выбранной 3D-панели
  - `fenceLengthM` - длина забора
  - `fenceHeightM` - высота забора
  - `postsCount` - количество столбов
  - `lagsCount` - количество лаг

**FR-9.2: Привязка фурнитуры**
- Использовать таблицу `MountingHardwareRelation`
- `referenceType = 'PANEL_3D'`
- Получать фурнитуру через `mountingHardwareCalculator`

---

#### FR-10: Работы по монтажу

**FR-10.1: Логика подбора работ**
1. Сначала ищем работы, привязанные к конкретной 3D-панели:
   - `referenceType = 'PANEL_3D'`
   - `referenceId = panel3D.id`
   - `useInCalculator = true`

2. Если нет работ для панели - используем работы для типа забора:
   - `fenceType = '3D-панели'`
   - `useInCalculator = true`

3. Если есть ворота/калитка - добавляем работы для них:
   - Ворота: `referenceType = 'GATE'`, `referenceId = gateId`
   - Калитка: `referenceType = 'WICKET'`, `referenceId = wicketId`

**FR-10.2: Категории работ**
- Монтаж 3D-панелей
- Установка столбов
- Установка лаг
- Монтаж ворот/калитки

### 4.3 Структура panel3DLookup.ts

```typescript
import { prisma } from '@/lib/prisma';
import { cache } from '@/lib/cache';
import { CACHE_KEYS, CACHE_TTL } from '@/lib/cache-keys';

export interface Panel3DLookupResult {
  id: string;
  name: string;
  height: number;
  width: number;
  rodDiameter: number;
  cellWidth: number;
  cellHeight: number;
  retailPricePerUnit: number;
}

export interface Panel3DLookupError {
  error: 'NO_PANEL_3D_FOUND';
  message: string;
  details: {
    requiredHeight: number;
    suggestion: string;
  };
}

async function getActivePanel3D() {
  return cache.getOrSet(
    CACHE_KEYS.PANEL_3D_ACTIVE,
    async () => {
      const now = new Date();
      return prisma.panel3D.findMany({
        where: {
          active: true,
          OR: [
            { validFrom: null },
            { validFrom: { lte: now } },
          ],
          AND: {
            OR: [
              { validUntil: null },
              { validUntil: { gt: now } },
            ],
          },
        },
        orderBy: [
          { priority: 'asc' },
          { height: 'asc' },
        ],
      });
    },
    CACHE_TTL.REFERENCE_DATA
  );
}

export async function findPanel3DByHeight(
  requiredHeightMm: number
): Promise<Panel3DLookupResult> {
  const panels = await getActivePanel3D();

  const matchingPanels = panels.filter(
    p => p.height >= requiredHeightMm
  );

  if (matchingPanels.length === 0) {
    const error: Panel3DLookupError = {
      error: 'NO_PANEL_3D_FOUND',
      message: 'Не найдена 3D-панель с указанной высотой',
      details: {
        requiredHeight: requiredHeightMm,
        suggestion: 'Попробуйте выбрать другую высоту или свяжитесь с нами',
      },
    };
    throw error;
  }

  const selectedPanel = matchingPanels[0];

  return {
    id: selectedPanel.id,
    name: selectedPanel.name,
    height: selectedPanel.height,
    width: selectedPanel.width,
    rodDiameter: selectedPanel.rodDiameter,
    cellWidth: selectedPanel.cellWidth,
    cellHeight: selectedPanel.cellHeight,
    retailPricePerUnit: selectedPanel.retailPricePerUnit,
  };
}
```

### 4.4 Структура panel3DCalculator.ts

```typescript
import { findPanel3DByHeight, Panel3DLookupResult } from './panel3DLookup';
import { roundUp } from '@/lib/utils/roundUp';

export interface Panel3DCalculationResult {
  category: 'panels3d';
  nomenclatureId: string;
  nomenclatureName: string;
  quantity: number;
  unit: 'шт';
  pricePerUnit: number;
  totalPrice: number;
  specifications: {
    height: number;
    width: number;
    rodDiameter: number;
    cellWidth: number;
    cellHeight: number;
  };
}

export async function calculatePanel3D(
  fenceLengthM: number,
  fenceHeightM: number
): Promise<Panel3DCalculationResult> {
  const fenceHeightMm = Math.round(fenceHeightM * 1000);
  
  const selectedPanel = await findPanel3DByHeight(fenceHeightMm);
  
  const fenceLengthMm = fenceLengthM * 1000;
  const panelWidthMm = selectedPanel.width;
  
  const panelsCount = roundUp(fenceLengthMm / panelWidthMm);
  const pricePerUnit = selectedPanel.retailPricePerUnit;
  const totalPrice = panelsCount * pricePerUnit;

  return {
    category: 'panels3d',
    nomenclatureId: selectedPanel.id,
    nomenclatureName: selectedPanel.name,
    quantity: panelsCount,
    unit: 'шт',
    pricePerUnit,
    totalPrice,
    specifications: {
      height: selectedPanel.height,
      width: selectedPanel.width,
      rodDiameter: selectedPanel.rodDiameter,
      cellWidth: selectedPanel.cellWidth,
      cellHeight: selectedPanel.cellHeight,
    },
  };
}
```

## 7. Примеры расчётов

### 7.1 Пример: Забор 50м из 3D-панелей

**Входные данные:**
- Длина забора: 50 м
- Высота забора: 2.0 м (2000 мм)
- Тип забора: 3D-панели
- Лаги: 2 ряда
- Ворота: распашные, 3.5 м
- Калитка: да, 1.0 м

**Расчёт:**

1. **Подбор 3D-панели:**
   - Требуемая высота: 2000 мм
   - В справочнике: панель 2000x2500 (priority 0), цена 5000 ₽/шт
   - Результат: выбрана панель 2000x2500

2. **Корректировка длины:**
   - correctedLength = 50 - 3.5 - 1.0 = 45.5 м

3. **Расчёт панелей:**
   - fenceLengthMm = 45500 мм
   - panelWidthMm = 2500 мм
   - panelsCount = roundUp(45500 / 2500) = 19 шт
   - Стоимость: 19 × 5000 = 95 000 ₽

4. **Расчёт столбов:**
   - Требуемая высота столба: 2000 + 1200 = 3200 мм
   - postSpacing = 2.5 м
   - postCount = ceil(45.5 / 2.5) + 2 = 21 шт

5. **Расчёт лаг:**
   - Длина 45.5 м × 2 ряда = 91 пог. м

6. **Фурнитура:**
   - Из справочника: крепёж для 3D-панели (1 шт на панель × 19 = 19 шт)

7. **Работы:**
   - Монтаж 3D-панели: привязано к панели, 200 ₽/шт
   - Установка столбов: привязано к типу забора, 500 ₽/шт
   - Установка лаг: привязано к типу забора, 150 ₽/м.пог.
   - Монтаж ворот: привязано к воротам, 5000 ₽
   - Монтаж калитки: привязано к калитке, 3000 ₽

**Итоговая смета:**
- 3D-панели: 95 000 ₽
- Столбы: 21 × 1500 = 31 500 ₽
- Лаги: 91 × 80 = 7 280 ₽
- Фурнитура: 19 × 50 = 950 ₽
- Монтаж 3D-панели: 19 × 200 = 3 800 ₽
- Установка столбов: 21 × 500 = 10 500 ₽
- Установка лаг: 91 × 150 = 13 650 ₽
- Монтаж ворот: 5 000 ₽
- Монтаж калитки: 3 000 ₽
- **Всего материалов: 134 730 ₽**
- **Всего работ: 35 950 ₽**
- **ИТОГО: 170 680 ₽**
