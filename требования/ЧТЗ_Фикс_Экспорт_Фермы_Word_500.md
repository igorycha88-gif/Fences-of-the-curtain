# ЧТЗ: Фикс экспорта расчёта ферм в Word (500 ошибка)

## Описание проблемы
При экспорте расчёта фермы в Word (GET `/api/admin/truss-calculations/[id]/export`) сервер возвращает 500 ошибку.

**Корневая причина:** Заголовок `Content-Disposition` содержит кириллические символы (название файла `ТЗ_Навес_Односкатный_...docx`), которые недопустимы в HTTP-заголовках (ByteString ограничен символами 0-255).

**Ошибка в логах:**
```
TypeError: Cannot convert argument to a ByteString because the character at index 22 has a value of 1058 which is greater than 255.
```

## Маршрут
Маршрут 1: Стандартная задача (баг-фикс)
Аналитик → Разработчик → Тестировщик → DevOps

## Файлы для изменения
- `src/app/api/admin/truss-calculations/[id]/export/route.ts` — строка 79

## Решение
Заменить строку 79 — использовать RFC 5987 `filename*=UTF-8''...` для кодирования кириллицы:
```
Content-Disposition: attachment; filename="truss_calculation.docx"; filename*=UTF-8''%D0%A2%D0%97_...
```

Также проверить другие маршруты экспорта на аналогичную проблему.

## Критерии приёмки
1. Экспорт расчёта фермы в Word возвращает 200 с корректным .docx файлом
2. Имя файла в браузере отображается на русском языке
3. Нет 500 ошибок при экспорте
4. Аналогичная проблема проверена и исправлена во всех маршрутах экспорта Word
