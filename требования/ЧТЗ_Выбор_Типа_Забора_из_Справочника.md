## 2. Цели и задачи

### 2.1 Бизнес-цель
Обеспечить синхронизацию типов заборов между Админ-панелью и Калькулятором, чтобы менеджеры могли управлять доступными типами заборов через админку без участия разработчиков, а пользователи видели только актуальные варианты.

### 2.2 Пользовательская ценность
- Пользователи калькулятора получают актуальный список типов заборов, который можно гибко настраивать в админке
- Менеджеры могут оперативно добавлять/скрывать типы заборов без изменения кода
- Исключается возможность расхождения данных между админкой и калькулятором

### 2.3 Ключевые метрики успеха
- Актуальность типов заборов в калькуляторе = 100% (загружается из БД)
- Время загрузки списка типов заборов < 500 мс
- Время обновления типов забора в админке и отображения в калькуляторе < 1 минуты (с учётом кеширования)

## 4. Требования к продукту

### 4.1 Функциональные требования

#### F1: Публичный API для получения типов заборов

**User Story:**
*Как разработчик фронтенда, я хочу получить список типов заборов через API, чтобы отобразить их в калькуляторе.*

**Acceptance Criteria:**
- Создать публичный endpoint `GET /api/calculator/fence-types` (без авторизации)
- Endpoint возвращает только активные типы заборов (`active: true`)
- Типы заборов отсортированы по полю `sortOrder` (ASC)
- Кеширование результатов в Redis с TTL 5 минут
- Валидация query параметров

**Технические детали:**

#### F2: Загрузка типов заборов в калькулятор

**User Story:**
*Как пользователь калькулятора, я хочу выбирать тип забора из актуального списка, чтобы рассчитать стоимость для нужного варианта.*

**Acceptance Criteria:**
- При загрузке страницы калькулятора выполняется запрос к `/api/calculator/fence-types`
- Типы заборов отображаются в виде визуальных карточек (изображение, название, описание)
- Количество карточек соответствует количеству активных типов в БД
- При клике на карточку происходит выбор типа забора
- Выбранный тип подсвечивается визуально
- Если список пуст, показывается сообщение "Типы заборов временно недоступны"

**Технические детали:**

#### F3: Фильтрация типов заборов по наличию материалов

**User Story:**
*Как пользователь калькулятора, я хочу видеть только те типы заборов, для которых есть доступные материалы, чтобы не выбирать пустые категории.*

**Acceptance Criteria:**
- По умолчанию API возвращает только типы заборов с активными материалами (`onlyWithMaterials: true`)
- Для каждого типа возвращается поле `materialsCount` - количество активных материалов
- Типы заборов с `materialsCount = 0` не отображаются
- Опциональный query параметр `onlyWithMaterials=false` для получения всех активных типов

**Технические детали:**
```typescript
// В FenceTypeService добавить метод
async getActiveWithMaterials() {
  return prisma.fenceType.findMany({
    where: {
      active: true,
      materials: {
        some: {
          active: true
        }
      }
    },
    include: {
      _count: {
        select: { materials: { where: { active: true } } }
      }
    },
    orderBy: { sortOrder: 'asc' }
  });
}
```

#### F4: Обновление калькулятора при выборе типа забора

**User Story:**
*Как пользователь калькулятора, я хочу чтобы при выборе типа забора автоматически применялись его параметры и фильтровались материалы.*

**Acceptance Criteria:**
- При выборе типа забора автоматически устанавливаются:
  - `difficultyCoef` - коэффициент сложности (используется в расчетах)
  - `postSpacing` - расстояние между столбами
  - `defaultLagRows` - количество рядов лаг (по умолчанию)
- Автоматически фильтруются материалы по выбранному типу забора (через связь fenceTypeId)
- Если для выбранного типа нет материалов, показывается сообщение с предложением выбрать другой тип
- Параметры выбранного типа отправляются в API расчета

**Технические детали:**
```typescript
// При выборе типа забора
const handleFenceTypeSelect = (fenceType: FenceType) => {
  setFormData(prev => ({
    ...prev,
    fenceType: fenceType.id,
    // Автоматически применяем параметры из типа
    postSpacing: fenceType.postSpacing,
    lagRows: fenceType.defaultLagRows.toString() as '2' | '3',
    difficultyCoef: fenceType.difficultyCoef
  }));

  // Загружаем материалы только для этого типа
  fetchMaterials(fenceType.id);
};
```

#### F5: Обработка ошибок загрузки

**User Story:**
*Как пользователь калькулятора, я хочу видеть понятное сообщение при ошибке загрузки типов заборов.*

**Acceptance Criteria:**
- При ошибке загрузки типов заборов показывается сообщение "Не удалось загрузить типы заборов. Попробуйте обновить страницу."
- Есть кнопка "Повторить попытку"
- Логирование ошибок на сервере
- Graceful degradation - калькулятор продолжает работать с fallback типами (если это возможно)

## Приложение А: Примеры использования

### А.1 Пример запроса к API

```bash
# Получить только типы заборов с материалами
curl "https://domain.com/api/calculator/fence-types"

# Получить все активные типы (даже без материалов)
curl "https://domain.com/api/calculator/fence-types?onlyWithMaterials=false"
```

### А.2 Пример ответа API

```json
{
  "types": [
    {
      "id": "clmabc123",
      "name": "Профнастил",
      "description": "Надежный забор из профлиста с высоким сроком службы",
      "image": "/uploads/fence-types/profnastil.jpg",
      "difficultyCoef": 1.0,
      "postSpacing": 2.5,
      "defaultLagRows": 2,
      "materialsCount": 5
    }
  ]
}
```

### А.3 Пример интеграции в React компонент

```typescript
import { useState, useEffect } from 'react';

interface FenceType {
  id: string;
  name: string;
  description?: string;
  image?: string;
  difficultyCoef: number;
  postSpacing: number;
  defaultLagRows: number;
  materialsCount: number;
}

export function FenceTypeSelector() {
  const [types, setTypes] = useState<FenceType[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    fetch('/api/calculator/fence-types')
      .then(res => res.json())
      .then(data => setTypes(data.types))
      .catch(err => setError(err.message))
      .finally(() => setLoading(false));
  }, []);

  if (loading) return <SkeletonLoader />;
  if (error) return <ErrorDisplay message={error} onRetry={() => window.location.reload()} />;

  return (
    <div className="fence-types-grid">
      {types.map(type => (
        <FenceTypeCard key={type.id} type={type} onSelect={handleSelect} />
      ))}
    </div>
  );
}
```
