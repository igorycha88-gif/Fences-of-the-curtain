# ЧТЗ (упрощённое): Кнопка «Позвонить» на главной (мобильная версия)

**Дата:** 2026-09-15
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps
**Тип:** Малая задача (2 файла кода + тесты, без изменений БД/API/архитектуры)

## 1. Постановка

В мобильной версии сайта на главной странице, в hero-блоке, ПЕРЕД основной кнопкой «Рассчитать забор» должна появляться кнопка «Позвонить» с номером телефона сайта. Тап по кнопке инициирует звонок (`tel:`-ссылка).

## 2. Функциональные требования

### ФТ-1. Компонент HeroCallButton
- Новый клиентский компонент `src/components/layout/HeroCallButton.tsx`.
- Телефон берётся из `useContactInfo()` (провайдер с дефолтом сайта `+74993901595`; данные из БД через `/api/contact-info`).
- Ссылка `tel:` только из цифр номера (`replace(/\D/g, '')`).
- Формат отображения: `+7 (499) 390-15-95`.
- На кнопке: иконка Phone, текст «Позвонить» и номер телефона.
- Клик трекается: `metrikaEvents.phoneClick()` + `trackEvent(EVENT_NAMES.PHONE_CLICK)` (единообразие с остальными публичными tel:-ссылками, см. ЧТЗ_Бизнес_Метрики_Клики_и_Гео).
- Если телефон пуст — компонент не рендерится.

### ФТ-2. Отображение только в мобильной версии
- Кнопка видна только на экранах < md (класс `md:hidden`), на десктопе скрыта.

### ФТ-3. Размещение на главной
- `src/app/page.tsx`: кнопка вставляется ПЕРВЫМ элементом в контейнер CTA hero-блока (`flex flex-col items-center gap-4`), т.е. визуально выше кнопки «Рассчитать забор».

## 3. Критерии приёмки

1. В мобильной версии (viewport < 768px) на главной выше кнопки «Рассчитать забор» видна кнопка «Позвонить» с номером телефона сайта.
2. Тап по кнопке открывает приложение звонилок с номером (`href="tel:74993901595"` для дефолтного номера).
3. На десктопе (≥ md) кнопка не отображается.
4. Клик отправляет событие `phone_click` во внутренний трекинг и Яндекс.Метрику.
5. Автотесты компонента: отображение номера, tel:-href, мобильные классы, трекинг клика, скрытие при отсутствии телефона.
6. Quality Gate: `npm test && npm run lint && npx tsc --noEmit` — все зелёные.

## 5. Правка после деплоя (2026-09-15, выбор пользователя)

Кнопка была зелёной (bg-green-600) — вне цветовой схемы сайта. По согласованному решению:
- Стиль: glass-белый как вторичные кнопки hero («Ворота и калитка»/«Навес»), но крупнее (`text-lg px-10 py-4`); иконка наследует цвет кнопки (как DoorOpen/Warehouse), hover — `bg-primary text-white`.
- Критерии приёмки ФТ-1/ФТ-2/ФТ-3 и автотесты — без изменений (тесты цвет не проверяют).
