# ЧТЗ: Расчёт материала покрытия для ворот и калитки

**Дата:** 2026-04-30
**Маршрут:** Стандартная задача (Маршрут 1)
**Исполнитель:** Разработчик

---

## 1. Описание проблемы

При добавлении ворот и/или калитки в калькулятор забора длина забора корректно уменьшается на размер ворот/калитки (столбы и лаги считаются по уменьшенной длине). **Но** покрывающий материал (профнастил, евроштакетник, 3D-панели) сейчас рассчитывается по уменьшенной длине, а должен — по **полной длине забора**, потому что ворота и калитка тоже зашиваются тем же материалом.

## 2. Текущее поведение (НЕВЕРНОЕ)

```
correctedLength = totalLength - gateLength - wicketLength

Материал (профнастил/евроштакетник/3D-панели) = рассчитывается от correctedLength
```

**Пример:** Длина забора 50 м, ворота 4 м, калитка 1 м.
- correctedLength = 50 - 4 - 1 = 45 м
- Профнастил считается на 45 м + 2 листа ← **НЕВЕРНО**, должно быть на 50 м + 2 листа

## 3. Ожидаемое поведение (ВЕРНОЕ)

```
correctedLength = totalLength - gateLength - wicketLength  (для столбов, лаг, фурнитуры)
materialLength  = totalLength                               (для покрывающего материала)

Материал (профнастил)     = рассчитывается от materialLength + 2 листа
Материал (евроштакетник)  = рассчитывается от materialLength + 3%
Материал (3D-панели)      = рассчитывается от materialLength + 2 штуки
```

**Тот же пример:** Длина 50 м, ворота 4 м, калитка 1 м.
- correctedLength = 45 м (для столбов, лаг)
- Профнастил = 50 м + 2 листа ← **ВЕРНО**

## 4. Дополнительная проблема: 3D-панели без резерва

В коде `panel3DCalculator.ts:135` количество панелей рассчитывается как `ceil(length/width)` **без +2 штуки резерва**. Профнастил имеет +2 листа, евроштакетник +3%, но 3D-панели — без резерва. По бизнес-логике требуется +2 штуки.

## 5. Файлы для изменения

| Файл | Изменение |

| `src/services/calculator/fenceEstimateService.ts` | Передавать `length` (полная длина) вместо `correctedLength` в калькуляторы материалов (профнастил, евроштакетник, 3D-панели) |
| `src/services/calculator/panel3DCalculator.ts` | Добавить +2 штуки резерва к количеству панелей |

## 6. Критерии приёмки

1. **Профнастил:** при наличии ворот/калитки количество листов рассчитывается на ПОЛНУЮ длину забора + 2 листа
2. **Евроштакетник:** при наличии ворот/калитки количество штакетин рассчитывается на ПОЛНУЮ длину забора + 3%
3. **3D-панели:** при наличии ворот/калитки количество панелей рассчитывается на ПОЛНУЮ длину забора + 2 штуки
4. **Столбы, лаги, фурнитура:** по-прежнему рассчитываются по correctedLength (уменьшенная длина)
5. **Без ворот/калитки:** поведение НЕ меняется (материал = полная длина + резерв)
6. **Сетка-рабица:** НЕ затрагивается (сетка не зашивает ворота/калитку)
