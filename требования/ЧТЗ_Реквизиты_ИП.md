**Дата:** 2026-09-21
**Маршрут:** Маршрут 1 (стандартная) — Аналитик → Разработчик → Тестировщик → DevOps
**Исполнитель:** Разработчик
**Архитектор:** не привлекается (нет изменений БД, API, архитектуры — только статический контент и SEO-константы)

## 1. Цель

Разместить на сайте юридические реквизиты ИП для соответствия ЗоЗПП (ст. 9 — продавец услуг обязан публиковать наименование, адрес, ИНН/ОГРНИП) и удобства оплаты юрлицами по счёту.

## 3. Требования

### 3.1 Единый источник данных (TASK-BCK-01)

- В `src/lib/seo/constants.ts` добавить экспорт `LEGAL_REQUISITES` со всеми полями из раздела 2.
- В `PAGE_METADATA` добавить `rekvizity` (title, path, description, keywords, ogImage).
- В `SITEMAP_CONFIG.pages` добавить `/rekvizity` (priority 0.3, changefreq yearly).

### 3.2 JSON-LD (TASK-BCK-01)

- В `generateOrganizationJsonLd()` (`src/lib/seo/jsonld.ts`) добавить `legalName` (полное наименование ИП) и `taxID` (ИНН).
- В `src/lib/seo/types.ts` (`JsonLdOrganization`) добавить опциональные поля `legalName?`, `taxID?`.

### 3.3 Страница /rekvizity (TASK-FRT-01)

- Новый server component `src/app/(public)/rekvizity/page.tsx` (metadata + Header + Breadcrumbs по образцу /about, без 'use client').
- Таблица/список всех реквизитов из раздела 2, сгруппированные: «Общие реквизиты» (наименование, адреса, ИНН, ОГРНИП) и «Банковские реквизиты» (банк, БИК, к/с, р/с).
- Контент берётся из `LEGAL_REQUISITES` (никаких хардкод-дублей в JSX-значениях).

### 3.4 Футеры (TASK-FRT-02)

- `Footer.tsx`: под строкой копирайта добавить строку «ИП Балов Д.А. · ИНН 504014078142» со ссылкой «Реквизиты» → `/rekvizity`.
- `HomeFooter.tsx`: в колонке «Информация» добавить ссылку «Реквизиты» → `/rekvizity`; в нижнем баре рядом с копирайтом — «ИП Балов Д.А. · ИНН 504014078142».

### 3.5 Автотесты (TASK-TST-01)

Новый файл `__tests__/rekvizity.test.tsx`:
- Валидация форматов: ИНН 12 цифр, ОГРНИП 15 цифр, БИК 9 цифр, р/с 20 цифр, к/с 20 цифр, корсчёт начинается с 301.
- Страница рендерит все значения реквизитов (smoke-тест).
- Footer и HomeFooter содержат «ИП Балов Д.А.», ИНН и ссылку `/rekvizity`.
- JSON-LD содержит taxID = ИНН и legalName.
- Sitemap-конфиг содержит `/rekvizity`.

## 4. Логирование

API routes/services не затрагиваются, catch-блоков нет — логирование по Правилу 8 не требуется.

## 5. Критерии приёмки

1. Страница `/rekvizity` открывается и содержит ВСЕ реквизиты из раздела 2 (включая фактический адрес производства).
2. Оба футера содержат краткую юр. строку и рабочую ссылку на `/rekvizity`.
3. `/rekvizity` присутствует в sitemap, у страницы заданы title/description.
4. JSON-LD Organization содержит `taxID` и `legalName`.
5. `npm test && npm run lint && npx tsc --noEmit` — все зелёные.
