## 1. Цели и задачи

### 1.1 Бизнес-цель
Ворота и калитка для типа забора «Сетка-рабица» также зашиваются сеткой-рабицей. Соответственно, длина сетки-рабицы должна включать не только пролёты забора, но и длину ворот и калитки.

### 1.2 Текущее поведение
- Формула: `meshLength = length - gateLength - wicketLength` (только пролёты забора)
- Файл: `src/services/calculator/fenceEstimateService.ts:300-306`
- Передаётся `correctedLength` в `calculateMesh()`

### 1.3 Требуемое поведение
- Формула: `meshLength = length + gateLength + wicketLength`
  - `length` — полная длина забора
  - `gateLength` — длина ворот (в м), если ворота добавлены
  - `wicketLength` — длина калитки (в м), если калитка добавлена
- Ворота и калитка также закрываются сеткой-рабицей, поэтому их размеры ДОБАВЛЯЮТСЯ к длине сетки

---

## 2. Критерии приёмки

- [ ] При типе «Сетка-рабица» без ворот и калитки: `meshLength = length` (без изменений)
- [ ] При типе «Сетка-рабица» с воротами (3.5м): `meshLength = length + 3.5`
- [ ] При типе «Сетка-рабица» с калиткой (1.0м): `meshLength = length + 1.0`
- [ ] При типе «Сетка-рабица» с воротами + калиткой: `meshLength = length + gateLength + wicketLength`
- [ ] Другие типы забора (Профнастил, 3D-панели, Евроштакетник) НЕ затрагиваются
- [ ] Существующие тесты проходят без изменений
