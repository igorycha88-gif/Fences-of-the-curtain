> **Исполнитель:** Разработчик → Тестировщик → DevOps

---

## 1. Постановка задачи

Проведён анализ поисковых подсказок Yandex (Wordstat-эквивалент) по тематике «заборы и навесы» в регионе Москва (213). Выявлены высокочастотные запросы, которые **не покрыты** текущим SEO-контентом сайта zabor-i-naves.ru. Необходимо обновить метаданные, добавить недостающий JSON-LD, расширить FAQ и создать новые блог-статьи под выявленные запросы.

## 4. Декомпозиция задач

### TASK-WS-BCK-001: Обновить SEO-константы (PAGE_METADATA)
**Файл:** `src/lib/seo/constants.ts`
**Действие:** Обновить keywords во всех PAGE_METADATA на основе Wordstat-данных:
- home: добавить «забор под ключ», «забор на дачу», «навес для дачи», «забор недорого»
- services: добавить «забор под ключ московская область», «установка забора москва»
- calculatorFence: добавить «калькулятор забора из штакетника», «калькулятор забора из профнастила онлайн»
- calculatorCanopy: добавить «калькулятор навеса из поликарбоната», «навес для машины рассчитать»
- portfolio: добавить «забор из евроштакетника фото»
- blog: добавить «навесы из металлопрофиля», «забор из профнастила горизонтальный»
- faq: добавить «сколько стоит забор под ключ», «какой забор на дачу выбрать»

### TASK-WS-BCK-002: Добавить AggregateRating + Review JSON-LD на главную
**Файл:** `src/app/page.tsx`
**Действие:**
