> **Приоритет:** HIGH

> **Исполнитель:** Разработчик
> **Дата:** 2026-04-15
> **Источники:** Полное функциональное тестирование master2

---

## 1. Описание проблемы

При тестировании калькулятора заборов обнаружено, что расчёт для типа **«Сетка-рабица»** возвращает ошибку:

```
ERROR: NO_POSTS_FOUND — Не найдены столбы для сетки-рабицы подходящей высоты
```

**Запрос:**
```json
{
  "fenceTypeId": "cmmkk6z9q000i13wt4y25v8sj",
  "length": 30,
  "height": 2,
  "lagRows": 2,
  "meshCoating": "GALVANIZED",
  "meshCellSize": 50,
  "meshWireThickness": 1.8
}
```

Остальные 3 типа заборов (Профнастил, Евроштакетник, 3D-панели) рассчитываются корректно.

---

## 2. Анализ

Сервис `src/services/calculator/postCalculator.ts` ищет столбы с параметрами:
- `forMesh: true` (столбы для сетки)
- Длина столба >= высота забора + припуск (заглубление)

Если в таблице `PostType` нет записей с `forMesh = true` или подходящей длины — расчёт падает.

**См. также:** `src/services/calculator/meshCalculator.ts` — работает корректно, ошибка именно в подборе столбов.

## 4. Критерии приёмки

- [ ] `POST /api/calculator/fence/estimate` с типом «Сетка-рабица» и длиной 30m возвращает успешный расчёт
- [ ] В ответе присутствуют столбы (PostType с `forMesh: true`)
- [ ] `grandTotal` содержит ненулевое значение
- [ ] Расчёт работает для высот: 1.5m, 2.0m, 2.5m, 3.0m
- [ ] Остальные 3 типа заборов по-прежнему работают (регрессия)
