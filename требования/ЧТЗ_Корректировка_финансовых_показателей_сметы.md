## 1. Цели и задачи

### 1.1 Бизнес-цель
Упростить структуру финансовых показателей сметы во вкладке "Расчеты" для более понятного отображения итоговой стоимости и маржинальности для администраторов.

### 1.2 Пользовательская ценность
Администраторы получат清晰ую структуру сметы с понятными наименованиями столбцов и корректными итоговыми показателями.

### 1.3 Ключевые метрики успеха
- Корректность расчета "Общая стоимость сметы": 100%
- Соответствие переименованных столбцов ТЗ: 100%

## 3. Функциональные требования

### 3.1 User Stories

#### US-1: Корректировка блока "Финансовые показатели сметы"
**Как** администратор,  
**Я хочу** видеть обновленную структуру финансовых показателей,  
**Чтобы** понимать итоговую стоимость сметы и маржинальность материалов.

**Acceptance Criteria**:
```
Given я авторизован как ADMIN
And нахожусь в деталях расчета
When просматриваю блок "Финансовые показатели сметы"
Then вижу следующие строки:
  - Розничная стоимость материалов: [сумма] ₽
  - Маржа за материал: [сумма] ₽ ([процент]%) — только для ADMIN
  - Стоимость работ: [сумма] ₽
  - Общая стоимость сметы: [сумма] ₽
And НЕ вижу строку "Закупочная стоимость"
And "Общая стоимость сметы" = Розничная стоимость материалов + Стоимость работ
And "Маржа за материал" = Розничная стоимость материалов - Закупочная стоимость материалов
And "Маржа за материал (%)" = (Маржа за материал / Розничная стоимость материалов) × 100
```

#### US-2: Переименование столбцов раздела "Смета работ"
**Как** пользователь (ADMIN/MANAGER),  
**Я хочу** видеть понятные названия столбцов в смете работ,  
**Чтобы** однозначно понимать структуру стоимости.

**Acceptance Criteria**:
```
Given я нахожусь в деталях расчета
When просматриваю раздел "Смета работ"
Then столбец "Цена розн." называется "Стоимость за ед."
And столбец "Сумма розн." называется "Стоимость итого"
And данные в столбцах остаются без изменений
```

#### US-3: Ограничение видимости "Маржа за материал"
**Как** система,  
**Я хочу** скрывать строку "Маржа за материал" от не-администраторов,  
**Чтобы** защитить коммерческую информацию.

**Acceptance Criteria**:
```
Given пользователь авторизован как MANAGER
When просматривает блок "Финансовые показатели сметы"
Then НЕ видит строку "Маржа за материал"
And видит:
  - Розничная стоимость материалов
  - Стоимость работ
  - Общая стоимость сметы
```

## 5. Техническая архитектура

### 5.1 Изменения в схеме БД
**НЕ требуются**. Используются существующие расчеты.

### 5.2 Логика расчета

```typescript
interface FinancialSummary {
  retailMaterialsTotal: number;      // Розничная стоимость материалов
  purchaseMaterialsTotal: number;    // Закупочная стоимость материалов (для расчета)
  materialMarginRub: number;         // Маржа за материал (₽)
  materialMarginPercent: number;     // Маржа за материал (%)
  worksTotal: number;                // Стоимость работ
  grandTotal: number;                // Общая стоимость сметы
}

function calculateFinancialSummary(items: EstimateItem[]): FinancialSummary {
  const materialsItems = items.filter(item => item.category !== 'works');
  const worksItems = items.filter(item => item.category === 'works');
  
  const retailMaterialsTotal = materialsItems.reduce((sum, item) => sum + item.totalPrice, 0);
  const purchaseMaterialsTotal = materialsItems.reduce((sum, item) => sum + (item.purchaseTotal || 0), 0);
  const worksTotal = worksItems.reduce((sum, item) => sum + item.totalPrice, 0);
  
  const materialMarginRub = retailMaterialsTotal - purchaseMaterialsTotal;
  const materialMarginPercent = retailMaterialsTotal > 0 
    ? (materialMarginRub / retailMaterialsTotal) * 100 
    : 0;
  
  return {
    retailMaterialsTotal,
    purchaseMaterialsTotal,
    materialMarginRub,
    materialMarginPercent,
    worksTotal,
    grandTotal: retailMaterialsTotal + worksTotal
  };
}
```

```typescript
describe('Financial Summary', () => {
  it('should calculate grand total correctly', () => {
    const items = [
      { category: 'posts', totalPrice: 30000, purchaseTotal: 20000 },
      { category: 'works', totalPrice: 15000, purchaseTotal: null }
    ];
    const summary = calculateFinancialSummary(items);
    
    expect(summary.retailMaterialsTotal).toBe(30000);
    expect(summary.worksTotal).toBe(15000);
    expect(summary.grandTotal).toBe(45000);
    expect(summary.materialMarginRub).toBe(10000);
    expect(summary.materialMarginPercent).toBe(33.33);
  });
});
```
