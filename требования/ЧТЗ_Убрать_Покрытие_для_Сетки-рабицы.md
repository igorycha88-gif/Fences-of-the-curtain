# ЧТЗ: Убрать поле "Покрытие" для сетки-рабицы при формировании заявки

## Версия: 1.0
## Дата: 2026-04-13
## Автор: AI-аналитик
## Приоритет: High
## Статус: Согласовано

---

## 1. Цели и задачи

### 1.1 Бизнес-цель
Убрать отображение поля "Покрытие" для типа забора "Сетка-рабица" при формировании заявки на индивидуальный расчет, так как этот параметр не относится к данному типу забора.

### 1.2 Пользовательская ценность
Клиенты и менеджеры видят корректный набор параметров для сетки-рабицы без избыточной информации.

### 1.3 Ключевые метрики успеха
- Поле "Покрытие" не отображается для сетки-рабицы
- Поле "Покрытие сетки" продолжает отображаться для сетки-рабицы
- Для других типов заборов поле "Покрытие" отображается как раньше

## 2. Функциональные требования

### 2.1 User Stories

#### US-1: Формирование заявки из калькулятора (сетка-рабица)
**Как** клиент,
**Я хочу** видеть корректные параметры сетки-рабицы при формировании заявки,
**Чтобы** не путался в избыточной информации.

**Acceptance Criteria**:
```
Given я выбираю тип забора "Сетка-рабица"
And выполняю расчет в калькуляторе
When открывается модальное окно с параметрами
Then НЕ показывается поле "Покрытие"
And показывается поле "Покрытие сетки"
```

#### US-2: Просмотр заявки в админ-панели (сетка-рабица)
**Как** менеджер,
**Я хочу** видеть корректные параметры сетки-рабицы в заявке,
**Чтобы** правильно интерпретировать информацию.

**Acceptance Criteria**:
```
Given я открываю заявку с типом забора "Сетка-рабица"
Then НЕ показывается блок "Покрытие"
And показываются другие параметры (длина, высота, лаги и т.д.)
```

#### US-3: Просмотр заявки в админ-панели (профнастил)
**Как** менеджер,
**Я хочу** видеть все параметры для профнастила,
**Чтобы** иметь полную информацию.

**Acceptance Criteria**:
```
Given я открываю заявку с типом забора "Профнастил"
Then показывается блок "Покрытие"
And отображается значение покрытия (оцинковка, полимер и т.д.)
```
