# ЧТЗ (упрощённое): Метка на Яндекс.карте страницы «Контакты»

**Дата:** 2026-10-09
**Причина:** постдеплойный баг — точка производства не отображается на карте
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps

## Проблема

iframe `map-widget/v1?text=...` не проставляет метку: параметр `text` — поисковый запрос, а КП «Гжельские узоры» не резолвится поиском Яндекса в точку. Карта показывает область без метки.

## Решение

Использовать географические параметры виджета с координатами КП «Гжельские узоры» (найдено в OSM, way 760063890, Раменский г.о.):
- `ll=38.4463482,55.5937114` (центр, порядок lon,lat)
- `pt=38.4463482,55.5937114` (метка производства)
- `z=15` (масштаб, при котором виден посёлок)

Координаты вынести в константы рядом с `MAP_QUERY` в `src/app/(public)/contacts/page.tsx`.

## Файлы

- `src/app/(public)/contacts/page.tsx` — MAP_SRC
- `__tests__/app/contacts-requisites.test.tsx` — обновить проверку src iframe (pt с координатами)

## Критерии приёмки

1. iframe src содержит `map-widget/v1`, `pt=38.4463482,55.5937114`, `ll=`, `z=15`
2. На карте видна метка на КП «Гжельские узоры» (визуально после деплоя)
3. Подписи адресов под картой не изменились
4. Gate: test/lint/tsc зелёные (кроме pre-existing)
