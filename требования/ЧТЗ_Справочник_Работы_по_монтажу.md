## 2. Цели и задачи

### 2.1 Бизнес-цель
Создать централизованный справочник работ (Монтаж, Доставка, Дополнительные работы по монтажу свай, Замер, Монтаж укосов и т.д.) с возможностью привязки к номенклатуре и использования в расчёте калькулятора.

### 2.2 Пользовательская ценность
- Централизованное управление всеми видами работ бригад
- Ручная привязка работ к конкретным типам заборов в карточке работы
- Автоматический расчёт стоимости работ в калькуляторе
- Гибкая настройка единиц измерения для разных типов работ

### 2.3 Ключевые метрики успеха
- Справочник работ создан и доступен в админ-панели
- CRUD операции работают корректно
- Работы привязываются к номенклатуре вручную
- Работы используются в расчёте калькулятора

## 3. Требования к продукту

### 3.1 Функциональные требования

#### 3.1.1 Структура справочника (таблица)

**User Story 1: Просмотр каталога работ**

*Как администратор, я хочу видеть таблицу всех работ с ключевыми полями.*

**Acceptance Criteria:**
- Таблица отображает столбцы:
  - **Название** - наименование работы
  - **Категория** - Монтаж, Доставка, Доп.работы, Замер
  - **Единица** - единица измерения (м, км, шт, фикс., м²)
  - **Стоимость** - стоимость за единицу
  - **Привязка к типам** - связанные типы заборов (через запятую)
  - **В калькуляторе** - используется в расчёте (да/нет)
  - **Активен** - статус (да/нет)
  - **Действия** - кнопки редактирования/удаления
- Сортировка по всем столбцам
- Фильтрация по категории, статусу активности, использованию в калькуляторе
- Поиск по названию

---

#### 3.1.2 Карточка работы

**User Story 2: Создание работы**

*Как администратор, я хочу создать новую работу с указанием всех необходимых параметров.*

**Acceptance Criteria:**
- Форма создания содержит поля:

  **Основные поля:**
  - **Название** (обязательное) - текст, 2-200 символов
  - **Описание** (опциональное) - многострочный текст, свободное описание

  **Категория и параметры:**
  - **Категория** (обязательное) - выбор из списка:
    - Монтаж
    - Доставка
    - Доп.работы
    - Замер
  - **Единица измерения** (обязательное) - выбор из списка:
    - м (погонные метры)
    - км (километры)
    - шт (штуки)
    - фикс. (фиксированная сумма)
    - м² (квадратные метры)
  - **Стоимость за единицу (₽)** (обязательное) - число ≥ 0

  **Настройка калькулятора:**
  - **[✓] Использовать в калькуляторе** - чекбокс, по умолчанию false

  **Привязка к типам заборов:**
  - **Привязка к типам заборов** - множественный выбор типов из справочников:
    - Профнастил
    - Евроштакетник
    - Ворота
    - Калитки
    - (будущие типы заборов)
  - **Важно:** Привязка устанавливается вручную в карточке работы
  - Работы могут быть без привязки (например, Замер, Монтаж сваи)

  **Статус:**
  - **[✓] Активен** - чекбокс, по умолчанию true

#### 4.2.1 Новая модель Work

```prisma
model Work {
  id                String   @id @default(cuid())
  name              String
  description       String?
  category          String   // 'MOUNTING', 'DELIVERY', 'ADDITIONAL', 'MEASUREMENT'
  unit              String   // 'M', 'KM', 'PCS', 'FIXED', 'M2'
  price             Float
  useInCalculator   Boolean  @default(false)
  sortOrder         Int      @default(0)
  active            Boolean  @default(true)
  createdAt         DateTime @default(now())
  updatedAt         DateTime @updatedAt

  // Связи с типами заборов
  relations         WorkRelation[]

  @@index([active])
  @@index([useInCalculator])
  @@index([category])
  @@index([sortOrder])
}

// Промежуточная таблица для связей работ с типами заборов
model WorkRelation {
  id                    String   @id @default(cuid())
  workId                String
  fenceType             String   // 'PROFNASTIL', 'PICKET', 'GATE', 'WICKET', ...
  createdAt             DateTime @default(now())

  work                  Work @relation(fields: [workId], references: [id], onDelete: Cascade)

  @@unique([workId, fenceType])
  @@index([fenceType])
}
```

## 5. API спецификация

### 5.1 GET /api/admin/works

**Описание:** Получить список работ

**Query Parameters:**
- `search` - поиск по названию
- `category` - фильтр по категории
- `active` - фильтр по статусу (true/false)
- `useInCalculator` - фильтр по использованию в калькуляторе
- `fenceType` - фильтр по типу забора (для получения связанных работ)

**Response 200:**
```json
{
  "items": [
    {
      "id": "work-1",
      "name": "Монтаж забора (базовый)",
      "description": "Стандартный монтаж забора из профнастила",
      "category": "MOUNTING",
      "unit": "M",
      "price": 500.00,
      "useInCalculator": true,
      "active": true,
      "relations": [
        {
          "fenceType": "PROFNASTIL",
          "fenceTypeName": "Профнастил"
        }
      ]
    }
  ],
  "total": 1
}
```

### 5.2 POST /api/admin/works

**Описание:** Создать новую работу

**Request:**
```json
{
  "name": "Монтаж забора (базовый)",
  "description": "Стандартный монтаж забора из профнастила",
  "category": "MOUNTING",
  "unit": "M",
  "price": 500.00,
  "useInCalculator": true,
  "active": true,
  "relations": [
    { "fenceType": "PROFNASTIL" }
  ]
}
```

**Validation:**
```typescript
const workSchema = z.object({
  name: z.string().min(2).max(200),
  description: z.string().max(1000).optional(),
  category: z.enum(['MOUNTING', 'DELIVERY', 'ADDITIONAL', 'MEASUREMENT']),
  unit: z.enum(['M', 'KM', 'PCS', 'FIXED', 'M2']),
  price: z.number().min(0),
  useInCalculator: z.boolean().default(false),
  sortOrder: z.number().default(0),
  active: z.boolean().default(true),
  relations: z.array(z.object({
    fenceType: z.string()
  })).optional()
});
```

### 5.3 PUT /api/admin/works/:id

**Описание:** Обновить работу

### 5.4 DELETE /api/admin/works/:id

**Описание:** Удалить работу

### 5.5 GET /api/admin/works/by-fence-type

**Описание:** Получить связанные работы по типу забора (для карточки номенклатуры)

**Query Parameters:**
- `fenceType` - тип забора (PROFNASTIL, PICKET, GATE, WICKET)

**Response 200:**

      "unit": "M",

## 10. Риски и зависимости

### Риск 1: Сложность множественных связей
**Category:** Technical
**Probability:** Medium
**Impact:** Medium

**Mitigation:**
- Использовать промежуточную таблицу WorkRelation
- Каскадное удаление связей при удалении работы

### Риск 2: Производительность при большом количестве связей
**Category:** Technical
**Probability:** Low
**Impact:** Medium

**Mitigation:**
- Индексы на fenceType
- Пагинация для больших списков

### Риск 3: Конфликт типов заборов с монтажной фурнитурой
**Category:** Technical
**Probability:** Medium
**Impact:** Low

**Mitigation:**
- Переиспользовать существующие константы типов заборов
- Единый реестр типов заборов

## 11. Решённые вопросы

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | Какие единицы измерения нужны? | м, км, шт, фикс., м² |
| 2 | Как связывать работы с номенклатурой? | Связь с типом забора вручную в карточке работы |
| 3 | Варианты работ на тип забора? | Несколько работ на один тип (базовый, премиум) |
| 4 | Категории работ? | Монтаж, Доставка, Доп.работы, Замер |
| 5 | Как рассчитывать монтаж? | Длина забора (м) × стоимость |
| 6 | Как учитывать монтаж свай? | Отдельная работа без привязки |
| 7 | Как рассчитывать доставку? | км × стоимость, привязка вручную |
| 8 | Как рассчитывать замер? | Фиксированная сумма |
| 9 | Какие доп. работы нужны? | Монтаж укосов, Бетонирование, Покраска + свободное добавление |
| 10 | Показывать в карточке номенклатуры? | Да, как у монтажной фурнитуры |
| 11 | Привязка в карточке? | Все работы привязываются вручную |
