## 1. Описание задачи

## 3. Структура справочников (UI)

### 3.1. Справочники 2-5 (Столбы, Перекладины, Перемычки, Арочная дуга)

Форма добавления/редактирования — **аналогична справочнику «Столбы»** (PostType):

**Основные поля формы:**

| Поле | Тип ввода | Описание |
|------|-----------|----------|
| Название | text | Название профиля (например «80×80×2») |
| Описание | textarea | Текстовое описание |
| Ширина сечения (мм) | number | sectionWidth |
| Высота сечения (мм) | number | sectionHeight |
| Толщина стенки (мм) | number | wallThickness |
| Длина (мм) | number | length (ввод в мм, сохранение в метрах) |
| Розничная стоимость за ед. (₽) | number | retailPricePerUnit |
| Закупочная цена за ед. (₽) | number (только ADMIN) | purchasePricePerUnit |
| Период действия | date × 2 | validFrom / expirationDate |
| Активен | checkbox | isActive |

**Инженерные поля (автоматический расчёт, скрытая секция «Расчётные характеристики»):**

При вводе sectionWidth, sectionHeight, wallThickness — **автоматически рассчитываются** (для прямоугольных труб по ГОСТ 30245-2012):

| Поле | Единица | Формула |
|------|---------|---------|
| sectionArea | см² | `2 × (W + H - 2×t) × t / 100` |
| momentOfInertiaX | см⁴ | `(H³×W - (H-2t)³×(W-2t)) / 12 / 10000` |
| momentOfInertiaY | см⁴ | `(W³×H - (W-2t)³×(H-2t)) / 12 / 10000` |
| sectionModulusX | см³ | `momentOfInertiaX / (H/200)` |
| sectionModulusY | см³ | `momentOfInertiaY / (W/200)` |
| radiusOfGyrationX | см | `sqrt(momentOfInertiaX / sectionArea)` |
| radiusOfGyrationY | см | `sqrt(momentOfInertiaY / sectionArea)` |
| weightPerMeter | кг/м | `sectionArea × 100 × 7.85 / 100` |

Секция «Расчётные характеристики» отображается как сворачиваемый блок (по умолчанию раскрыт) с **read-only** полями. Пользователь видит автоматически рассчитанные значения. При необходимости можно вручную переопределить любое значение.

**Таблица списка (столбцы):**

| Столбец | Поле |
|---------|------|
| Название | name |
| Сечение (мм) | sectionWidth × sectionHeight |
| Толщина металла (мм) | wallThickness |
| Длина (мм) | length × 1000 |
| Вес (кг/м) | weightPerMeter |
| Розничная стоимость за ед. (₽) | retailPricePerUnit |
| Дата начала | validFrom |
| Срок действия | expirationDate |
| Закупка (₽) | purchasePricePerUnit (только ADMIN) |
| Приоритет | priority |
| Активен | isActive |

**Функциональность таблицы:**
- Пагинация (20 записей)
- Поиск по названию
- Фильтр по периоду действия (все / активные / истёк срок / истекает скоро)
- Сортировка по приоритету (перетаскивание)
- Переключатель активен/неактивен
- CRUD: создание, редактирование, удаление
- Проверка дубликатов (sectionWidth + sectionHeight + wallThickness + category)

## 4. API Endpoints

### 4.1. Профили (TrussProfileType)

Существующие маршруты расширить и добавить недостающие:

| Method | Path | Описание |
|--------|------|----------|
| GET | `/api/admin/truss-profiles?category=POST&page=1&pageSize=20&search=&validityFilter=all` | Список с пагинацией, поиском, фильтром |
| POST | `/api/admin/truss-profiles` | Создать профиль |
| GET | `/api/admin/truss-profiles/[id]` | Получить профиль |
| PUT | `/api/admin/truss-profiles/[id]` | Обновить профиль |
| DELETE | `/api/admin/truss-profiles/[id]` | Удалить профиль |
| PATCH | `/api/admin/truss-profiles/[id]` | Переключить isActive |
| PATCH | `/api/admin/truss-profiles/reorder` | Изменить приоритет |

**GET-параметры:**
- `category` (обязательный) — POST / CROSSBEAM / STRUT / ARCH
- `page` (default 1)
- `pageSize` (default 20)
- `search` — поиск по name
- `validityFilter` — all / active / expired / expiring_soon
- `active` — true/false

## 6. Интеграция с калькулятором

После создания справочников данные автоматически станут доступны в калькуляторе ферм, т.к. `TrussCalculatorForm` уже загружает данные из:
- `/api/admin/truss-profiles` → фильтрует по категории (POST, CROSSBEAM, STRUT, ARCH)
- `/api/admin/truss-roof-coverings` → все активные покрытия

Никаких изменений в калькуляторе не требуется — он уже ожидает эти данные.

trussProfileCreateSchema = z.object({
  name: z.string().min(1).max(100),

  sectionArea: z.number().positive(),
