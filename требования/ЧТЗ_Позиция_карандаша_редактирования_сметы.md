# ЧТЗ: Позиция карандаша редактирования сметы (единственная смета без корректировки)

## Описание проблемы
В заявке с одной сметой (без корректировки администратора) кнопка-карандаш редактирования отображается **внизу** блока сметы. При нескольких сметах карандаш отображается **вверху** карточки (в заголовке). Нужно привести к единообразию — карандаш всегда наверху.

## Маршрутизация
- **Маршрут:** Стандартный (Аналитик → Разработчик → Тестировщик → DevOps)
- **Исполнитель:** Разработчик
- **Сложность:** Малая (< 3 файлов, без БД/API/архитектуры)

## Файлы для изменения
1. `src/components/admin/Orders/EstimateSection.tsx` — добавить опциональный prop `onEdit` и рендерить карандаш в заголовке
2. `src/components/admin/Orders/OrderDetailPage.tsx` — передать `onEdit` в EstimateSection для единственной сметы, убрать карандаш снизу

## Критерии приёмки
1. В заявке с одной сметой без корректировки карандаш редактирования отображается вверху блока сметы (в заголовке рядом с «Открыть в Расчетах»)
2. В заявке с несколькими сметами поведение не изменилось
3. В заявке с одной сметой и корректировкой администратора поведение не изменилось
4. Клик по карандашу открывает редактор сметы (как раньше)
