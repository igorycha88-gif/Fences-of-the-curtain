## 1. Общая информация

## 2. Цели и задачи

### 2.1 Бизнес-цель
Улучшить пользовательский опыт навигации по сайту, устранив дублирование элементов интерфейса и сделав вход в административную панель более заметным и удобным.

### 2.2 Пользовательская ценность
Пользователи получают чистый и логичный интерфейс навигации без повторяющихся элементов, а администраторы - быстрый доступ к входу через выделенную кнопку в хедере.

### 2.3 Ключевые метрики успеха
- Устранение дублирования элементов навигации (100%)
- Размещение кнопки "Войти" в хедере (100%)
- Визуальное выделение кнопки "Войти" цветом (100%)
- Консистентность хедера на всех страницах (100%)

## 3. Требования к продукту

### 3.1 Функциональные требования

#### 3.1.1 Анализ текущих проблем

**Проблема 1: Дублирование навигации на главной странице**

*Файл:* `src/app/page.tsx`
*Строки:* 10-39

**Описание:**
Навигационные ссылки дублируются дважды:
- Первый блок (строки 10-24): Калькулятор забора, Калькулятор навеса, Услуги, Портфолио, Контакты
- Второй блок (строки 25-39): те же ссылки повторяются

**Влияние:**
- Ухудшение UX (пользователи видят повторяющиеся элементы)
- Увеличение размера DOM
- Отрицательное влияние на SEO (дублирование контента)

**Проблема 2: Кнопка "Войти" в футере**

*Файл:* `src/app/page.tsx`
*Строки:* 99-104

**Описание:**
Кнопка "Войти" расположена в футере, что неочевидно для администраторов.

**Влияние:**
- Сложность доступа к административной панели
- Несоответствие общепринятым практикам (вход обычно в хедере)

**Проблема 3: Неконсистентный хедер на разных страницах**

*Файлы:*
- `src/app/page.tsx` - навигация: Калькуляторы, Услуги, Портфолио, Контакты
- `src/app/(public)/contacts/page.tsx` - навигация: Главная, Услуги, Портфолио, Контакты
- `src/app/(public)/calculator/fence/page.tsx` - навигация: Главная, Калькуляторы

**Влияние:**
- Пользователи путаются в навигации
- Нет единого стиля

### 4.3 Компонент Header

**Props:**
```typescript
interface HeaderProps {
  activePath?: string;  // Текущий путь для подсветки активной страницы
}
```

**State (Client Component):**
```typescript
const [isMenuOpen, setIsMenuOpen] = useState(false);
```

**Примечание:** Компонент должен быть Client Component из-за использования useState для hamburger menu.

**Структура компонента:**
```tsx
<header className="bg-white shadow-sm border-b">
  <div className="container mx-auto px-4 py-4 flex justify-between items-center">
    <Link href="/" className="text-2xl font-bold text-primary">
      Заборы и Навесы
    </Link>
    
    {/* Desktop Navigation */}
    <nav className="hidden md:flex gap-6 items-center">
      <Link href="/" className={activePath === '/' ? 'text-primary font-semibold' : 'text-gray-600 hover:text-primary'}>
        Главная
      </Link>
      <Link href="/calculator" className={activePath?.startsWith('/calculator') ? 'text-primary font-semibold' : 'text-gray-600 hover:text-primary'}>
        Калькулятор
      </Link>
      <Link href="/services" className={activePath === '/services' ? 'text-primary font-semibold' : 'text-gray-600 hover:text-primary'}>
        Услуги
      </Link>
      <Link href="/portfolio" className={activePath === '/portfolio' ? 'text-primary font-semibold' : 'text-gray-600 hover:text-primary'}>
        Портфолио
      </Link>
      <Link href="/contacts" className={activePath === '/contacts' ? 'text-primary font-semibold' : 'text-gray-600 hover:text-primary'}>
        Контакты
      </Link>
      
      <Link
        href="/admin/login"
        className="ml-4 bg-primary text-white px-6 py-2 rounded-lg font-semibold hover:bg-primary/90 transition-colors"
      >
        Войти
      </Link>
    </nav>
    
    {/* Mobile Hamburger Menu Button */}
    <button
      className="md:hidden p-2"
      onClick={() => setIsMenuOpen(!isMenuOpen)}
      aria-label="Toggle menu"
    >
      {isMenuOpen ? <X className="w-6 h-6" /> : <Menu className="w-6 h-6" />}
    </button>
  </div>
  
  {/* Mobile Menu */}
  {isMenuOpen && (
    <nav className="md:hidden bg-white border-t">
      <div className="container mx-auto px-4 py-4 flex flex-col gap-4">
        <Link href="/" className="text-gray-600 hover:text-primary">Главная</Link>
        <Link href="/calculator" className="text-gray-600 hover:text-primary">Калькулятор</Link>
        <Link href="/services" className="text-gray-600 hover:text-primary">Услуги</Link>
        <Link href="/portfolio" className="text-gray-600 hover:text-primary">Портфолио</Link>
        <Link href="/contacts" className="text-gray-600 hover:text-primary">Контакты</Link>
        <Link
          href="/admin/login"
          className="bg-primary text-white px-6 py-2 rounded-lg font-semibold text-center hover:bg-primary/90"
        >
          Войти
        </Link>
      </div>
    </nav>
  )}
</header>
```

### 4.4 Лучшие практики

Согласно существующей архитектуре и best practices Next.js 14:

1. **Server Components:**
   - Header может быть Server Component (не требует клиентского состояния)
   - Использовать `usePathname()` для определения активной страницы (если Client Component)

2. **Reusable Component:**
   - Создать один компонент Header
   - Использовать на всех публичных страницах
   - DRY principle (Don't Repeat Yourself)

3. **Semantic HTML:**
   - Использовать `<header>`, `<nav>`, `<ul>`, `<li>`
   - Улучшает SEO и доступность

4. **Active Link Highlighting:**
   - Подсвечивать текущую страницу в навигации
   - Улучшает UX

## 6. UI/UX требования

### 6.1 Дизайн кнопки "Войти"

**Стили:**
```css
/* Основные стили */
background-color: var(--primary);
color: white;
padding: 0.5rem 1.5rem;  /* py-2 px-6 */
border-radius: 0.5rem;    /* rounded-lg */
font-weight: 600;         /* font-semibold */
margin-left: 1rem;        /* ml-4 */

/* Hover эффект */
&:hover {
  background-color: rgba(var(--primary), 0.9);
}

/* Transition */
transition: all 0.2s;
```

### 6.2 Навигация

**Стили ссылок:**
```css
/* Обычная ссылка */
color: #4B5563;           /* text-gray-600 */
&:hover {
  color: var(--primary);
}
transition: color 0.2s;

/* Активная ссылка */
color: var(--primary);
font-weight: 600;         /* font-semibold */
```

### 6.3 Адаптивность
