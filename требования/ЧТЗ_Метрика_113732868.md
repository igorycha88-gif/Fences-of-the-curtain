# ЧТЗ: Подключение счётчика Яндекс.Метрики №113732868

**Дата:** 2026-10-22
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps
**Тип:** малая задача (упрощённое ЧТЗ)

## 1. Постановка

Пользователь предоставил стандартный сниппет Яндекс.Метрики со счётчиком **113732868**:

```html
ym(113732868, 'init', {ssr:true, webvisor:true, clickmap:true, ecommerce:"dataLayer",
  referrer: document.referrer, url: location.href, accurateTrackBounce:true, trackLinks:true});
```

## 2. Анализ текущего состояния

Интеграция Метрики в проекте **уже реализована полностью**:

- `src/components/seo/YandexMetrika.tsx` — базовый счётчик (Script afterInteractive + noscript)
- `src/components/cookie-consent/CookieConsentProvider.tsx` — consent-режим (загрузка только после同意 куков аналитики, кроме /admin)
- `src/lib/seo/metrika.ts` — цели reachGoal (calculator_start/complete, phone_click, order_form_submit и др.)
- CSP в `src/middleware.ts` — mc.yandex.ru уже разрешён (script-src, connect-src)

Переданный сниппет **побайтово совпадает** с реализованным (все опции init идентичны).
Отличие единственное — **ID счётчика**.

Текущий ID `108488683` задан в:
1. `.env` (локальный, в gitignore) — dev + docker dev
2. `.github/workflows/deploy-production.yml:90` — дефолт build-arg при сборке прод-образа в CI (`secrets.NEXT_PUBLIC_YANDEX_METRIKA_ID || '108488683'`)
3. `.env` на VPS (runtime для SSR-чтения в `src/app/layout.tsx:19`) — проверить при прод-деплое

**Решение (дефолт):** заменить старый ID на новый везде. Сниппет пользователя содержит один счётчик — второй параллельный не требуется.

## 3. Изменения

| # | Файл | Изменение |
|---|------|-----------|
| 1 | `.env` | `NEXT_PUBLIC_YANDEX_METRIKA_ID=113732868` |
| 2 | `.github/workflows/deploy-production.yml` | дефолт `'108488683'` → `'113732868'` |

Код-изменения НЕ требуются (интеграция идентична сниппету).

## 4. Критерии приёмки

1. Счётчик 113732868 инициализируется на всех публичных страницах dev-сборки (после согласия на куки аналитики).
2. `reachGoal`-цели (`src/lib/seo/metrika.ts`) шлются в счётчик 113732868.
3. CI-сборка прода инлайнит новый ID в клиентский бандл.
4. `npm test && npm run lint && npx tsc --noEmit` — зелёные.
5. После пересборки: на странице сайта в HTML/бандле присутствует `mc.yandex.ru/metrika/tag.js?id=113732868`.

## 5. Организационные меры (SEO-скилл §10)

- После деплоя на прод: проверить в интерфейсе Метрики 113732868 получение данных (Отчёты → Посещаемость), включить вебвизор.
- Старый счётчик 108488683 (если актуален) — владелец может снять с него данные до удаления.
