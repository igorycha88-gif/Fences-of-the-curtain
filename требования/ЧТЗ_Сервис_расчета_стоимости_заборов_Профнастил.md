## 2. Цели и задачи

### 2.1 Бизнес-цель
Создать автоматизированный сервис расчета стоимости заборов из профнастила, который на основании данных из справочников (Столбы, Лаги, Профнастил, Типы заборов) рассчитывает точную стоимость материалов и работ, формирует смету и сохраняет её в БД для последующего анализа и использования.

### 2.2 Пользовательская ценность
- Пользователь получает точный расчет стоимости забора с детализацией по материалам
- Автоматический подбор оптимальных материалов из справочников
- Учет всех необходимых компонентов (столбы, лаги, профнастил, монтаж)
- Прозрачное ценообразование с разбивкой по позициям
- Возможность повторного просмотра сметы

### 2.3 Ключевые метрики успеха
- 100% корректность расчетов (покрытие тестами)
- Время расчета < 500 мс
- Все расчеты сохраняются в БД с уникальным идентификатором
- Успешный подбор материалов из справочников в 100% случаев

## 4. Функциональные требования

### 4.1 Расчет столбов (FR-1)

**FR-1.1: Конвертация единиц**
```
Длина забора в мм = Длина забора в м × 1000
```

**FR-1.2: Расчет количества столбов**
```
Количество столбов = ceil(Длина забора в м / Шаг столбов) + 2
```
где:
- Шаг столбов берется из поля `postSpacing` выбранного типа забора (FenceType)
- +2 столба добавляются на риски (запас)

**FR-1.3: Расчет требуемой высоты столба**
```
Требуемая высота столба (мм) = (Высота забора в м × 1000) + 1200
```
где 1200 мм - заглубление в землю

**FR-1.4: Подбор столба из справочника**
1. Найти все активные столбы (`active: true`) с валидными сроками:
   - `validFrom IS NULL OR validFrom <= NOW()`
   - `expirationDate IS NULL OR expirationDate > NOW()`
2. Отфильтровать по длине: найти столбы с `length >= Требуемая высота столба`
3. Если точного совпадения нет - выбрать ближайшую большую длину
4. Среди найденных выбрать столб с наивысшим приоритетом (`priority` - минимальное значение)
5. Если столбы не найдены - ошибка расчета

**FR-1.5: Расчет стоимости столбов**
```
Стоимость столбов = Количество столбов × Розничная стоимость столба (pricePerMeter × length)
```

**FR-1.6: Сохранение в смету**
```json
{
  "category": "posts",
  "nomenclatureId": "clm123...",
  "nomenclatureName": "Профиль 60x60x2.5",
  "quantity": 22,
  "unit": "шт",
  "pricePerUnit": 750,
  "totalPrice": 16500
}
```

---

### 4.2 Расчет лаг (FR-2)

**FR-2.1: Подбор лаги из справочника**
1. Найти все активные лаги с валидными сроками
2. Выбрать лагу с наивысшим приоритетом (`priority = 1` или минимальное значение)
3. Если лаги не найдены - ошибка расчета

**FR-2.2: Расчет количества лаг**
```
Количество лаг на один ряд = ceil(Длина забора в мм / Длина лаги в мм) + 2
```
где:
- Длина забора в мм = Длина в м × 1000
- Длина лаги в мм берется из поля `length` справочника LagType
- +2 лаги добавляются на риски (запас)

**FR-2.3: Учет рядов лаг**
```
Общее количество лаг = Количество лаг на один ряд × Количество рядов (lagRows)
```

**FR-2.4: Расчет стоимости лаг**
```
Стоимость лаг = Общее количество лаг × Розничная стоимость за м.п. × Длина лаги в м
```
где:
- Розничная стоимость за м.п. = `basePricePerMeter`
- Длина лаги в м = `length / 1000`

**FR-2.5: Сохранение в смету**
```json
{
  "category": "lags",
  "nomenclatureId": "clm456...",
  "nomenclatureName": "Профиль 40x20x2.0",
  "quantity": 36,
  "unit": "шт",
  "pricePerUnit": 375,
  "totalPrice": 13500
}
```

---

### 4.3 Расчет профнастила (FR-3)

**FR-3.1: Подбор профнастила из справочника**
1. Найти все активные профнастилы с валидными сроками
2. Отфильтровать по высоте: найти профнастил с `length = Высота забора в мм` (округленно)
3. Если точного совпадения нет - выбрать ближайшую по высоте
4. Среди найденных выбрать профнастил с наивысшим приоритетом
5. Если профнастил не найден - ошибка расчета

**FR-3.2: Расчет количества листов**
```
Количество листов = ceil(Длина забора в мм / Полезная ширина) + 2
```
где:
- Длина забора в мм = Длина в м × 1000
- Полезная ширина = `usefulWidth` из справочника ProfnastilType
- +2 листа добавляются на риски (запас)

**FR-3.3: Расчет стоимости профнастила**
```
Стоимость профнастила = Количество листов × Розничная стоимость за м.п. × (Длина листа в мм / 1000)
```
где:
- Розничная стоимость за м.п. = `retailPricePerMeter`
- Длина листа в мм = `length` из справочника

**FR-3.4: Сохранение в смету**
```json
{
  "category": "profnastil",
  "nomenclatureId": "clm789...",
  "nomenclatureName": "Профнастил С8 0.5мм 2000мм",
  "quantity": 26,
  "unit": "шт",
  "pricePerUnit": 1100,
  "totalPrice": 28600
}
```

## 8. Примеры расчетов

### 8.1 Пример 1: Забор 50м, высота 2м, 2 ряда лаг

**Входные данные:**
- Длина: 50 м
- Высота: 2 м
- Ряды лаг: 2
- Тип забора: Профнастил (postSpacing = 2.5)

**Расчет столбов:**
1. Количество столбов = ceil(50 / 2.5) + 2 = 20 + 2 = 22 шт
2. Требуемая высота = 2000 + 1200 = 3200 мм
3. Выбран столб: Профиль 60x60x2.5, длина 3.5м (3500 мм), приоритет 1
4. Стоимость = 22 × 750 ₽ = 16 500 ₽

**Расчет лаг:**
1. Выбрана лага: Профиль 40x20x2.0, длина 3000 мм, приоритет 1
2. Количество на ряд = ceil(50000 / 3000) + 2 = 17 + 2 = 19 шт
3. Общее количество = 19 × 2 = 38 шт
4. Стоимость = 38 × 125 ₽/м × 3м = 14 250 ₽

**Расчет профнастила:**
1. Выбран профнастил: С8 0.5мм, высота 2000 мм, полезная ширина 1150 мм
2. Количество листов = ceil(50000 / 1150) + 2 = 44 + 2 = 46 шт
3. Стоимость = 46 × 550 ₽/м × 2м = 50 600 ₽

**Расчет монтажа:**
1. Стоимость = 50 × 1200 = 60 000 ₽

**Итого:**
- Материалы: 81 350 ₽
- Монтаж: 60 000 ₽
- **Всего: 141 350 ₽**

**Статус:** ✅ РЕШЕНО

**Статус:** ✅ РЕШЕНО

**Решение:** Использовать 1200 ₽/м.п. как указано в начале описания.

### Вопрос 3: История расчетов
**Статус:** ✅ РЕШЕНО

**Решение:** Сохранять все расчеты в БД. В будущем сделать отображение в админ-панели.

### Вопрос 4: Отсутствие подходящей номенклатуры
**Статус:** ✅ РЕШЕНО

**Решение:** Выбирать ближайшую номенклатуру. Если совсем нет - возвращать ошибку.
