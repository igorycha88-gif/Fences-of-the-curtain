# ЧТЗ: Удаление справочников и вкладки Материалы

## 1. Общая информация
- **Название проекта**: Удаление неиспользуемых справочников и вкладки Материалы
- **Версия документа**: 1.0
- **Дата создания**: 2026-03-10
- **Ответственные**: инициатор - заказчик, аналитик - AI, техлид - TBD
- **Приоритет**: Medium

## 2. Цели и задачи

### Бизнес-цель
Упрощение архитектуры Админ-панели путем удаления неиспользуемых функциональностей: справочников "Тип покрытия", "Высоты материалов" и вкладки "Материалы". Это снизит сложность поддержки и уберет дублирующий функционал.

### Пользовательская ценность
Администраторы получат более простую и понятную структуру меню, без лишних разделов, которые дублируют функции других справочников.

### Ключевые метрики успеха
- Удалено 3 раздела из UI админ-панели
- Удалено ~15 файлов frontend/backend
- Размер кодовой базы уменьшен без потери функциональности калькулятора

## 3. Требования к продукту

### 3.1 Функциональные требования

#### User Story 1: Удаление справочника "Тип покрытия"

**As a** администратор системы,
**I want to** не видеть справочник "Тип покрытия" в меню,
**So that** интерфейс был проще и не содержал неиспользуемый функционал.

**Acceptance Criteria:**
- **Given** я нахожусь в админ-панели
- **When** смотрю на раздел "Справочники"
- **Then** пункт "Типы покрытия" отсутствует в меню
- **And** страница `/admin/references/coatings` возвращает 404
- **And** API `/api/admin/coating-types/*` удалены

**Priority**: High

## 6. Риски и зависимости

### Риск 1: Использование CoatingType в других частях системы
**Category**: Technical
**Probability**: Medium
**Impact**: Medium

**Description**:
Поле `coating` в `ProfnastilType` использует enum-значения, которые могли заполняться из CoatingType.

**Mitigation Strategies**:
1. **Prevent**: Проверить использование CoatingType через grep перед удалением
2. **Mitigate**: Оставить поле coating в ProfnastilType как строку (уже согласовано)

---

### Риск 2: Зависимость калькулятора от availableHeights
**Category**: Technical
**Probability**: Low
**Impact**: High

**Description**:
Калькулятор может использовать данные из availableHeights.

**Mitigation Strategies**:
1. **Accept**: Поле availableHeights остается в БД (согласовано)
