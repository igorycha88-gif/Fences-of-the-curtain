# ЧТЗ: Удорожание материалов по длине забора

**Дата:** 2026-05-23
**Статус:** Approved
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps

---

## 1. Бизнес-требование

Администратор должен иметь возможность управлять процентом надбавки к стоимости материалов в зависимости от длины забора. Малые заборы (до 30-40 м) невыгодны для установки, поэтому нужно удорожание в % соотношении, управляемое из админ-панели.

## 2. Функциональные требования

### 2.1. Правила удорожания (FenceLengthMarkup)

- Каждый тип забора (FenceType) имеет свой набор правил удорожания
- Правило задаётся интервалом длины (minLength, maxLength в метрах) и процентом надбавки (markupPercent)
- Пример: для «Профнастил» — от 10 до 30 м → +20%, от 31 до 40 м → +10%
- Несколько правил на один тип забора
- Интервалы не должны пересекаться
- Правила можно активировать/деактивировать

### 2.2. Применение удорожания

- Удорожание применяется ТОЛЬКО к материалам (category !== 'installation')
- Применяется множитель: `pricePerUnit * (1 + markupPercent / 100)`
- Материалы попадают в заявку и смету уже с увеличенной стоимостью
- Применяется в калькуляторе (публичном) и при перерасчёте сметы
- Сохраняется применённый % в смете для аудита

### 2.3. Управление из админ-панели

- На странице справочника «Типы заборов» — секция «Правила удорожания по длине»
- CRUD для правил: minLength, maxLength, markupPercent, active
- Переключатель markupEnabled на уровне типа забора
- При редактировании сметы — чекбокс «Отключить удорожание»
- При отключении: материалы добавляются по цене из справочника

### 2.4. Редактирование сметы

- При добавлении материала в смету: цена берётся с учётом удорожания (если активно)
- Админ может отключить удорожание по конкретному забору (markupDisabled)
- При отключении материалы пересчитываются по базовым ценам из справочников

## 3. Критерии приёмки

1. В админ-панели на странице типа забора есть секция с правилами удорожания
2. Можно создать/изменить/удалить правило (интервал + %)
3. При расчёте забора длиной 25 м с правилом «10-30 м → +20%» — стоимость материалов увеличивается на 20%
4. Стоимость монтажа (installation) НЕ увеличивается
5. Применённый % виден в смете
6. Админ может отключить удорожание для конкретной сметы
7. При отключении материалы пересчитываются по базовым ценам
8. Интервалы валидируются на пересечение
9. `npm test && npm run lint && npx tsc --noEmit` проходят

## 4. Техническая реализация

### 4.1. БД (prisma/schema.prisma)

```prisma
model FenceLengthMarkup {
  id            String    @id @default(cuid())
  fenceTypeId   String
  minLength     Float
  maxLength     Float
  markupPercent Float
  active        Boolean   @default(true)
  priority      Int       @default(0)
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
  fenceType     FenceType @relation(fields: [fenceTypeId], references: [id], onDelete: Cascade)
  @@index([fenceTypeId])
  @@index([active])
  @@index([minLength, maxLength])
}
```

+ FenceType: `markupEnabled Boolean @default(true)`, `lengthMarkups FenceLengthMarkup[]`
+ FenceEstimate: `markupDisabled Boolean @default(false)`, `markupPercent Float @default(0)`
