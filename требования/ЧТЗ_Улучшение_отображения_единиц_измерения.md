## 2. Цели и задачи

### 2.1 Бизнес-цель
Улучшить читаемость таблиц справочников, вынеся единицы измерения в заголовки столбцов. Это сделает таблицы более чистыми и профессиональными, а данные - более легко воспринимаемыми.

### 2.2 Пользовательская ценность
- Упрощение визуального восприятия данных
- Более чистый и профессиональный вид таблиц
- Улучшенная читаемость при быстром сканировании данных
- Консистентность отображения во всех числовых полях
- Подсказки (tooltips) для заголовков столбцов

### 2.3 Ключевые метрики успеха
- Время поиска нужной информации в таблице сокращается на 20%
- Удовлетворенность пользователей UX ≥ 4.5/5
- Количество вопросов по единицам измерения снижается на 30%

## 3. Требования к продукту

### 3.1 Функциональные требования

#### 3.1.1 Изменение отображения в таблицах справочников

**User Story 1: Обновление заголовков столбцов с единицами измерения**
*Как администратор, я хочу видеть единицы измерения в заголовках столбцов, чтобы таблица выглядела чисто и профессионально.*

**Acceptance Criteria:**
- Все числовые поля в заголовках содержат единицы измерения в скобках
- Заголовки остаются читаемыми и не слишком длинными
- Сортировка по столбцам работает корректно
- Tooltips для заголовков поясняют единицы измерения

**User Story 2: Удаление единиц измерения из данных**
*Как администратор, я хочу видеть только числовые значения в ячейках таблицы, без единиц измерения.*

**Acceptance Criteria:**
- Все числовые данные отображаются без единиц измерения
- Форматирование чисел (десятичные знаки) сохранено
- Для null значений показывается "-"
- Визуально таблица становится более чистой

**User Story 3: Добавление tooltips для заголовков столбцов**
*Как администратор, я хочу видеть подсказки при наведении на заголовки столбцов с единицами измерения.*

**Acceptance Criteria:**
- При наведении на заголовок столбца появляется tooltip
- Tooltip содержит подробное описание поля и единицы измерения
- Tooltip появляется с задержкой 500мс
- Tooltip имеет понятный и читаемый дизайн

## 6. UI/UX требования

### 6.1 Общий компонент таблицы

**Создать переиспользуемый компонент ColumnHeaderWithTooltip:**

```typescript
interface ColumnHeaderWithTooltipProps {
  title: string;              // Заголовок столбца с единицей измерения
  tooltip: string;            // Текст подсказки
  sortable?: boolean;         // Возможность сортировки
  sorted?: 'asc' | 'desc';    // Текущее направление сортировки
}

// Пример использования
<ColumnHeaderWithTooltip 
  title="Сечение (мм)" 
  tooltip="Размеры поперечного сечения профиля в миллиметрах"
  sortable={true}
/>
```

**Дизайн tooltip:**
- Фон: темно-серый (#333)
- Текст: белый
- Шрифт: 12px
- Максимальная ширина: 250px
- Появление: 500мс задержка
- Позиция: сверху или снизу (автоматически)

### 6.2 Форматирование данных

**Правила форматирования:**
- Сечение: "{width}x{height}" (без единиц)
- Толщина: "{thickness}" (1 знак после запятой)
- Длина/Высота: "{length}" (1 знак после запятой)
- Цена: "{price}" (целое число или 2 знака после запятой)
- Null значения: "-"

## 9. Риски и зависимости

### 9.1 Технические риски

**Risk 1: Путаница у пользователей при изменении формата**

**Category:** Business  
**Probability:** Low  
**Impact:** Low

**Description:**
Пользователи привыкли видеть единицы измерения в ячейках и могут сначала не заметить их в заголовках.

**Mitigation Strategies:**
1. **Prevent:** Четкие заголовки с единицами измерения
2. **Mitigate:** Tooltips с пояснениями при наведении
3. **Accept:** Временный период адаптации (1-2 недели)
