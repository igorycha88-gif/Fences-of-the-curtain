# ЧТЗ: Фикс — Восстановление прогресса сбора SEO-позиций при навигации

## Проблема

При нажатии «Собрать сейчас» и уходе на другую страницу (навигация внутри админки), а затем возврате на страницу SEO-мониторинга:
- Прогресс сбора не отображается — кнопка снова выглядит доступной
- Парсер на сервере продолжает работать (Redis-сессия живёт 12 часов)
- Пользователь не видит прогресс, пока снова не нажмёт «Собрать сейчас» (что вызовет 409 и восстановит поллинг)

## Решение

Добавить начальную проверку активной сессии в Redis при монтировании компонента страницы.

## Критерии приёмки

1. При загрузке/возврате на страницу SEO-мониторинга автоматически вызывается `GET /api/admin/seo-monitoring/collect/session`
2. Если сессия активна (`data.active === true`) — устанавливается `collecting = true`, `collectProgress` заполняется из ответа, запускается поллинг
3. Если сессия завершена (`data.completed === true`) — отображается результат, данные обновляются
4. Если сессии нет (`data.active === false`) — ничего не делается, кнопка доступна
5. Проверка не блокирует загрузку остального контента (ключевые слова, сводка)
6. Ошибка проверки сессии не ломает страницу
