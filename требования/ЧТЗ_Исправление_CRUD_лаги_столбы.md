## 2. Цели и задачи

### 2.1 Бизнес-цель
Обеспечить корректную работу справочников Лаги и Столбы: администраторы должны иметь возможность создавать новые номенклатуры, редактировать существующие и видеть изменения в UI сразу после сохранения.

### 2.2 Пользовательская ценность
Администраторы получают возможность:
- Создавать новые номенклатуры лаг и столбов
- Редактировать параметры существующих номенклатур
- Видеть сохраненные изменения в таблице справочника
- Получать уведомления об успешном сохранении или ошибке

### 2.3 Ключевые метрики успеха
- 100% успешных операций создания номенклатуры
- 100% успешных операций редактирования номенклатуры
- Отображение изменений в UI сразу после сохранения (без перезагрузки страницы)
- Время отклика < 500 мс

*Как администратор, я хочу создать новую лагу, чтобы она появилась в справочнике.*

**Текущее поведение (BUG):**
- При нажатии на кнопку "Создать" открывается модальное окно
- После заполнения полей и нажатия кнопки "Создать" в модальном окне:

### 3.2 Корневая причина проблемы

**Технический анализ:**

В текущей реализации используется **недопустимая структура вложенных форм (nested forms)**:

```
src/app/(admin)/admin/references/lags/page.tsx:353
└── <form onSubmit={handleFormSubmit}>
    └── <ReferenceForm onSubmit={handleFormSubmit}>
        └── <form onSubmit={onSubmit}>  ← ВЛОЖЕННАЯ ФОРМА (недопустимо в HTML5)
```

**Результат:** HTML5 не допускает вложенные `<form>` элементы, что приводит к непредсказуемому поведению при отправке формы - события могут не срабатывать, данные могут не отправляться.

### 4.2 Изменения в ReferenceForm.tsx

**Файл:** `src/components/admin/References/ReferenceForm.tsx`

**Добавить проп renderForm:**

```typescript
interface ReferenceFormProps {
  fields: Field[];
  values: Record<string, any>;
  onChange: (name: string, value: any) => void;
  onSubmit: (e: React.FormEvent) => void;
  onCancel: () => void;
  isLoading?: boolean;
  submitLabel?: string;
  renderForm?: boolean;  // НОВОЕ: true = рендерить <form>, false = только поля
```

**Логика:**
- `renderForm={true}` (default) - рендерит `<form>` обертку (обратная совместимость)

## 5. API спецификация

### 5.1 POST /api/admin/lag-types

**Auth:** Required (ADMIN)

**Request:**
```json
{
  "name": "Профиль 40x20x2.0",
  "description": "Описание",
  "width": 40,
  "height": 20,
  "metalThickness": 2.0,
  "basePricePerMeter": 150,
  "availableLengths": [
    { "length": 2.5, "priceCoef": 1.0 }
  ],
  "purchasePrices": [
    { "length": 2.5, "purchasePrice": 120 }
  ],
  "active": true,
  "sortOrder": 0
}
```

**Response 201:**
```json
{
  "id": "new-lag-id"
}
```

**Response 400 (validation error):**
```json
{
  "error": "Validation error",
  "details": [...]
}
```

### 5.2 PUT /api/admin/lag-types/:id

**Auth:** Required (ADMIN)

**Request:** То же что при POST
