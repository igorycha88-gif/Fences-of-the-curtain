**Дата:** 2026-11-03
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps
**Тип:** малая задача (<3 файлов, без БД/API/архитектуры)

## 1. Проблема

В Word-смете (`src/services/word/estimateWordGenerator.ts`):
- В шапке захардкожено `ООО "Заборы и Навесы"`, тогда как юридически компания — **ИП Балов Д.А.** (реквизиты на сайте: `/rekvizity`, `src/lib/seo/constants.ts → LEGAL_REQUISITES`).

2. **Подвал**: после блока подписей добавить блок реквизитов кратким набором (мелкий шрифт):
   - Полное наименование: ИП Балов Дмитрий Александрович
   - ИНН: 504014078142
   - ОГРНИП: 326508100430753
   - Телефон: +7 (499) 390-15-95
   - Email: zabori-naves@yandex.ru
3. **Источник данных** — только `LEGAL_REQUISITES` и `BUSINESS_INFO` из `src/lib/seo/constants.ts` (единый источник, без дублирования значений в генераторе).

## 4. Критерии приёмки

1. [ ] В шапке сметы — `ИП Балов Д.А.`, упоминание ООО отсутствует.
2. [ ] После подписей — блок реквизитов: полное ФИО ИП, ИНН, ОГРНИП, телефон, email.
3. [ ] Значения берутся из `LEGAL_REQUISITES` / `BUSINESS_INFO` (изменение констант отражается в смете).

5. [ ] `npm test && npm run lint && npx tsc --noEmit` — зелёные.
