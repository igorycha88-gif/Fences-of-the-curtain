# ЧТЗ: Фикс подбора откатных ворот по высоте

## Описание проблемы
При добавлении откатных ворот в калькуляторе с высотой забора >= 2.0м выкидывает ошибку `NO_GATE_FOUND` и перенаправляет в индивидуальный расчёт. Распашные ворота работают корректно.

## Корневая причина
`gateLookup.ts:77` — фильтр `gateHeight >= fenceHeightMm` слишком строгий. Доступные откатные ворота имеют максимальную высоту **1950мм**, а дефолтная высота забора — **2000мм**. Для любой высоты забора > 1950мм откатные ворота не находятся.

**Данные откатных ворот (из БД):**
| gateLength | gateHeight | Цена |
|-----------|-----------|------|
| 3000 | 1750 | 32 000 |
| 3000 | 1950 | 46 000 |
| 3500 | 1750 | 46 000 |
| 3500 | 1950 | 48 000 |
| 4000 | 1750 | 48 000 |
| 4000 | 1950 | 50 000 |
| 5000 | 1750 | 54 000 |
| 5000 | 1950 | 60 000 |

**Данные распашных ворот (из БД):**
gateHeight: 1500, 1800, 2000, 2200, 2500 — покрывают все стандартные высоты.

## Решение
Если нет ворот с `gateHeight >= fenceHeightMm`, вместо ошибки `NO_GATE_FOUND` — **выбрать самые высокие** ворота из подходящих по ширине (closest height fallback). Это практично, т.к. стандартные высоты ворот не обязательно совпадают с высотой забора.

### Алгоритм (изменение в шаге 4):
```
4. Фильтр по высоте: gateHeight >= fenceHeightMm
   - Если найдены → предпочтение точному совпадению
   - Если НЕ найдены → fallback: сортировка по gateHeight DESC, выбор самых высоких
```

## Критерии приёмки

### AC-1: Откатные ворота находятся для высоты забора 2.0м
- При height=2.0м, gateType=SLIDING, gateWidth=4.0м → подбираются ворота h-1950mm

### AC-2: Откатные ворота находятся для высоты забора 2.2м и 2.5м
- При height=2.2м → подбираются ближайшие по высоте (h-1950mm)
- При height=2.5м → подбираются ближайшие по высоте (h-1950mm)

### AC-3: Обратная совместимость
- Распашные ворота продолжают работать как раньше (у них есть точные совпадения по высоте)
- Точное совпадение по высоте предпочтительнее приблизительного

### AC-4: Fallback логирует предупреждение
- При fallback (gate < fence height) — console.warn с деталями
