# ЧТЗ: Фикс порядка узлов верхнего пояса двускатной фермы

## Описание проблемы
В `buildDoubleSlope()` правые узлы верхнего пояса генерируются в обратном порядке по x (6000→5000→4000 вместо 4000→5000→6000). Из-за этого:
- Один элемент верхнего пояса перескакивает от конька до правого края (диагональ через весь скат)
- Остальные элементы идут в обратном направлении
- ВП-2 получает неверную длину (5590 вместо 3354 для пролёта 6000)

## Корневая причина
Файл: `src/services/truss/trussGeometry.ts:159-166`
Цикл `for (let i = 0; i <= halfN; i++)` ставит правые узлы как `x = width - i * panelLen`, что даёт убывание x.

## Решение
После генерации правых узлов — отсортировать их по возрастанию x. Либо переписать цикл так, чтобы узлы шли по возрастанию x.

## Критерии приёмки
1. Правые узлы верхнего пояса идут по возрастанию x
2. Элементы верхнего пояса не перескакивают через весь скат
3. ВП-1 == ВП-2 для симметричной двускатной фермы
4. Существующие тесты проходят (`npm test`)
5. lint + tsc без ошибок

## Файлы для изменения
- `src/services/truss/trussGeometry.ts` — функция `buildDoubleSlope()`, строки 159-166
