## 1. Описание задачи

Разработать калькулятор для расчёта нагрузки и проектирования ферм навесов с 4 типами крыш. Калькулятор размещается в админ-панели как отдельная вкладка «Калькулятор ферм» перед вкладкой «О нас».

### 1.1. Типы крыш

| ID | Название | Описание |
|----|----------|----------|

| `DOUBLE_SLOPE` | Двухскатная | Треугольная ферма с коньком в центре |
| `ARCH` | Арочная | Ферма с дугообразным верхним поясом |
| `SINGLE_SLOPE_CURVED` | Односкатная в дуге | Дуга с несимметричным профилем, один край ниже |

## 2. Расчёт нагрузок (СП 20.13330.2016, Московская область)

### 2.1. Снеговая нагрузка

```
S = ce × ct × μ × Sg × γf
```

**Параметры:**
- `Sg = 180 кг/м²` — нормативное значение веса снегового покрова (район III)
- `ce = 1.0` — коэффициент exposures
- `ct = 1.0` — термический коэффициент
- `γf = 1.4` — коэффициент надёжности по нагрузке

**Коэффициент μ:**
- **Односкатная:** μ = 1.0 при α ≤ 25°, μ = (60-α)/35 при 25° < α ≤ 60°, μ = 0 при α > 60°
- **Двухскатная (вариант 2):** μ₁ = 1.0 (наветренная сторона), μ₂ = 0.75 (подветренная). Расчёт по μ₁
- **Арочная:** μ = l/(8f) при l/(8f) ≤ 1.0, где l — пролёт, f — стрела подъёма
- **Односкатная в дуге:** аналогично арочной с корректировкой на асимметрию

### 2.2. Ветровая нагрузка

```
Wm = w0 × k(ze) × c × γf
```

**Параметры:**
- `w0 = 23 кг/м²` — нормативное значение ветрового давления (район I)
- `γf = 1.4` — коэффициент надёжности
- `k(ze)` — по таблице в зависимости от высоты и типа местности (B — городская)
- `c` — аэродинамический коэффициент:
  - Односкатная: c = -0.5...+0.3 (по СП)
  - Двухскатная: c = -0.4...+0.4
  - Арочная: c = -0.6...+0.3
  - Односкатная в дуге: c = -0.5...+0.3

**Таблица k(ze) для местности типа B:**
| Высота ze (м) | k(ze) |
|----------------|-------|
| ≤ 5 | 0.5 |
| 10 | 0.65 |
| 20 | 0.85 |
| 40 | 1.1 |

### 2.3. Собственный вес

```
q_dead = q_roof + q_structure
```
- `q_roof = weightPerSqm × γf` (вес покрытия, γf = 1.1)
- `q_structure` = вес всех профилей фермы / площадь кровли

### 2.4. Суммарная нагрузка на ферму

```
q_total = (S + |Wm| + q_dead) — кг/м²
Q_truss = q_total × truss_spacing / 1000 — кг/м (погонная нагрузка)
F_total = Q_truss × span / 1000 — кг (суммарная нагрузка на ферму)
```

## 3. Проектирование геометрии фермы

### 3.1. Определение количества панелей

```
panelLength = 1000 мм (целевой размер панели)
n_panels = max(3, round(span / panelLength))
actualPanelLength = span / n_panels
```

### 3.2. Расчёт узлов для каждого типа

#### Односкатная (SINGLE_SLOPE)

```
Нижний пояс: горизонтальная линия y=0, от x=0 до x=span
Верхний пояс: от (0, wallHeight) до (span, ridgeHeight)
  slope = (ridgeHeight - wallHeight) / span
  α = atan(slope) — угол наклона
Узлы: n_panels+1 точек по нижнему поясу + n_panels+1 по верхнему
Перемычки: вертикальные + диагональные между соседними узлами
```

#### Двухскатная (DOUBLE_SLOPE)

```
Нижний пояс: горизонтальная линия y=0, от x=0 до x=span
Левый верхний пояс: от (0, eaveHeight) до (span/2, ridgeHeight)
Правый верхний пояс: от (span/2, ridgeHeight) до (span, eaveHeight)
  eaveHeight = минимальная высота (карниз), вычисляется из ridgeHeight и угла
  α = atan(2 × (ridgeHeight - eaveHeight) / span)
Узлы: n_panels+1 по нижнему + по (n_panels/2+1) по каждому скату
Перемычки: вертикальные + диагональные
Конёк: узел в центре
```

#### Арочная (ARCH)

```
Нижний пояс: горизонтальная линия y=0, от x=0 до x=span
Верхний пояс: дуга окружности
  R = (span² + 4×rise²) / (8×rise), где rise = ridgeHeight - bottomHeight
  Центр окружности: (span/2, ridgeHeight - R)
Для каждого узла i (от 0 до n_panels):
  x_i = i × actualPanelLength
  y_i = R - sqrt(R² - (x_i - span/2)²) + (ridgeHeight - R)  [дуга]
Перемычки: вертикальные от нижнего пояса до дуги + диагональные (зигзаг)
Длина дуги верхнего пояса: L_arc = R × 2 × asin(span/(2×R))
```

#### Односкатная в дуге (SINGLE_SLOPE_CURVED)

```
Нижний пояс: горизонтальная линия y=0, от x=0 до x=span
Верхний пояс: несимметричная дуга
  Левый край: wallHeight (низкий)
  Правый край: ridgeHeight (высокий)
  Дуга: парабола через (0, wallHeight), (span/2, curvePeak), (span, ridgeHeight)
  curvePeak = (wallHeight + ridgeHeight)/2 + extraRise
Перемычки: вертикальные + диагональные
Длина дуги: численное интегрирование
```

### 3.3. Выходные данные геометрии

```typescript
interface TrussGeometryResult {
  nodes: Array<{ id: number; x: number; y: number; type: 'bottom' | 'top' | 'ridge' }>;
  members: Array<{
    id: number;
    startNodeId: number;
    endNodeId: number;
    type: 'bottom_chord' | 'top_chord' | 'vertical' | 'diagonal';
    length: number; // mm
    angle: number; // градусы
  }>;
  span: number;
  ridgeHeight: number;
  slopeAngle: number;
  arcLength?: number;
  panelLength: number;
  panelCount: number;
}
```

## 4. Проверка и подбор профиля

### 4.1. Расчёт усилий в элементах

Для каждого стержня фермы:
1. Узловая нагрузка: `P = Q_truss × actualPanelLength / 1000` (кг)
2. Усилия определяются методом вырезания узлов или сечений:
   - **Нижний пояс (растяжение):** `N_bottom = q × L² / (8 × h)` где h — высота фермы
   - **Верхний пояс (сжатие):** `N_top = N_bottom / cos(α)` для прямых, по дуге для арочных
   - **Вертикальные стойки (сжатие):** `N_vert = P`
   - **Раскосы:** `N_diag = P / sin(β)` где β — угол раскоса

### 4.2. Проверка по предельным состояниям

**Растяжение:**
```
σ = N / A ≤ Ry × γc
```

**Сжатие (с устойчивостью):**
```
σ = N / (φ × A) ≤ Ry × γc
λ = lef / i (гибкость)
φ = f(λ) — по таблице СП 16.13330
lef = μ × L (расчётная длина, μ = 0.8 для поясов, 1.0 для решётки)
```

**Изгиб (для поясов при распределённой нагрузке):**
```
σ = M / W ≤ Ry × γc
M = q × L² / 8 (максимальный момент)
```

**Параметры:**
- `Ry = 235 МПа` (сталь S235)
- `γc = 0.9` (коэффициент условий работы)

### 4.3. Подбор профиля

Если текущий профиль не проходит проверку:
1. Отсортировать все профили той же категории по `sectionModulusX` (возрастание)
2. Найти первый профиль, для которого все проверки проходят
3. Вернуть рекомендацию: «Текущий профиль X недостаточен. Рекомендуется профиль Y»
4. Показать запас прочности: `k = (Ry × γc) / σ_max`

### 4.4. Коэффициент запаса

```
safetyFactor = (Ry × γc) / max(σ_all_members)
```
- `safetyFactor ≥ 1.0` — конструкция выдерживает нагрузку
- `safetyFactor < 1.0` — КОНСТРУКЦИЯ НЕ ВЫДЕРЖИВАЕТ, нужен усиленный профиль

## 5. SVG-чертёж фермы

### 5.1. Формат

SVG-разметка, рендерится в браузере и конвертируется в PNG для Word.

### 5.2. Элементы чертежа

1. **Координатная сетка** — тонкие серые линии (необязательно)
2. **Нижний пояс** — толстая линия (stroke-width: 3)
3. **Верхний пояс(а)** — толстая линия (stroke-width: 3)
4. **Перемычки вертикальные** — средняя линия (stroke-width: 2)
5. **Перемычки диагональные** — средняя линия (stroke-width: 2)
6. **Узлы** — кружки (r=4)
7. **Размерные линии:**
   - Ширина навеса (пролёт) — снизу
   - Высота конька/центра — справа
   - Высота стены (для односкатной) — слева
8. **Угловые аннотации:**
   - Угол наклона верхнего пояса (для прямых)
   - Угол начала/конца дуги (для арочных)
9. **Размеры перемычек:**
   - Длина каждой перемычки в мм
   - Шаг перемычек
10. **Масштабная линейка**
11. **Подписи профиля** — для каждого типа элемента (пояс, стойки, раскосы)

### 5.3. Масштабирование

```
svgWidth = 900px, svgHeight = 500px
padding = 80px (для размерных линий)
scaleX = (svgWidth - 2×padding) / span
scaleY = (svgHeight - 2×padding) / max_height
scale = min(scaleX, scaleY) — единый масштаб
```

### 5.4. Цветовая схема

| Элемент | Цвет | Толщина |
|---------|------|---------|
| Нижний пояс | #1e40af (синий) | 3px |
| Верхний пояс | #1e40af (синий) | 3px |
| Вертикальные стойки | #059669 (зелёный) | 2px |
| Диагональные раскосы | #dc2626 (красный) | 2px |
| Узлы | #1e40af | r=4 |
| Размерные линии | #6b7280 (серый) | 1px |
| Текст размеров | #374151 | 12px |

## 6. Спецификация материалов

### 6.1. Расчёт количества ферм

```
n_trusses = floor(length / trussSpacing) + 1
```

### 6.2. Материалы на одну ферму

| Материал | Формула |
|----------|---------|
| Нижний пояс | 1 шт × span |
| Верхний пояс (прямые) | 1-2 шт × длина верхнего пояса |
| Верхний пояс (арочный) | 1 шт × длина дуги |
| Вертикальные стойки | n_vert × h_i (каждая своя длина) |
| Диагональные раскосы | n_diag × L_i (каждая своя длина) |

### 6.3. Материалы на весь навес

| Материал | Расчёт | Профиль |
|----------|--------|---------|
| Столбы | (n_trusses + 1) × 2 шт × высота столба | POST |
| Перекладины (прогоны) | n_trusses × span × количество рядов прогонов | CROSSBEAM |
| Нижний пояс фермы | n_trusses × span | STRUT (или CROSSBEAM) |
| Верхний пояс фермы | n_trusses × длина верхнего пояса | STRUT / ARCH |
| Перемычки фермы | n_trusses × суммарная длина перемычек | STRUT |
| Покрытие крыши | площадь кровли (с учётом уклона) | — |
| Крепёж | расчётный | — |

### 6.4. Формат вывода

Таблица в UI и Word:
| № | Наименование | Профиль | Длина (мм) | Кол-во | Общая длина (м) | Вес (кг) | Цена (руб) |

### 8.4. Поведение

1. Пользователь заполняет параметры → нажимает «Рассчитать»
2. Отправляется POST на `/api/admin/truss-calculations/calculate`
3. Сервер рассчитывает нагрузки, геометрию, проверяет профили
4. Результат отображается: чертёж + нагрузки + материалы + рекомендации
5. Если профиль недостаточен — жёлтое предупреждение с рекомендацией
6. Кнопка «Сохранить» — POST на `/api/admin/truss-calculations` (сохраняет в БД)
7. Кнопка «Скачать Word» — GET на `/api/admin/truss-calculations/[id]/export`

## 12. Ограничения

1. **Не заменяет инженерный расчёт** — калькулятор даёт предварительную оценку
2. **Только Московская область** — снеговой район III, ветровой район I (в будущем можно расширить)
3. **Только стальные профильные трубы** (ГОСТ 30245-2012)
4. **Максимальный пролёт:** 12 м
5. **Шаг ферм:** 1.5-3 м
