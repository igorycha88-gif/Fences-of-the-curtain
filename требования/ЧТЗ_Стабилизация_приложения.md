# ЧТЗ: Стабилизация приложения — исправление 5 критических проблем

**Дата:** 2026-04-10
**Приоритет:** Критический
**Тип:** Баг-фикс

---

## 1. Описание проблемы

Приложение работает нестабильно по совокупности причин:
- Утечка памяти через Redis connections (EventEmitter leak)
- Блокирующие таймауты при отправке email (несуществующий хост mailhog)
- Ошибки Telegram API с плейсхолдер-токеном
- Некорректный расчёт маржи для panel3d и installation
- React warning для javascript: URL

---

## 2. Задачи

### TASK-STAB-001: Redis утечка памяти (MaxListenersExceeded)
**Файл:** `src/lib/redis.ts`
**Проблема:** Каждый hot-reload/SSR может создавать новый Redis-клиент. `globalForRedis` singleton не гарантируется в dev-режиме Next.js. Каждый клиент добавляет error listener → через 11 инстансов срабатывает MaxListenersExceeded.
**Решение:** Улучшить singleton-паттерн, добавить `setMaxListeners`,Graceful disconnect при hot-reload.

### TASK-STAB-002: Email таймаут (ENOTFOUND mailhog)
**Файл:** `.env`, `src/services/email/sender.ts`
**Проблема:** `USE_LOCAL_SMTP=true` + нет контейнера mailhog → DNS-резолв таймаутит 30 сек при каждой отправке email, блокируя запросы.
**Решение:** Отключить USE_LOCAL_SMTP в .env (установить false), т.к. реальный SMTP настроен. Добавить timeout в nodemailer transport.

### TASK-STAB-003: Telegram Bot плейсхолдер
**Файлы:** `src/services/telegram*`, API routes использующие Telegram
**Проблема:** `TELEGRAM_BOT_TOKEN="your-bot-token"` — плейсхолдер → 404 от Telegram API при каждой попытке уведомления.
**Решение:** Добавить проверку валидности токена перед отправкой. Если плейсхолдер — пропускать отправку без ошибки.

### TASK-STAB-004: marginCalculator — unknown categories
**Файл:** `src/lib/utils/marginCalculator.ts`
**Проблема:** Категории `panel3d` и `installation` не обрабатываются в `getPurchasePrice()`.
**Решение:** Добавить обработку category `panel3d` (поиск в Panel3D модели) и `installation` (работы — return null или расчёт по себестоимости).

### TASK-STAB-005: javascript: URL в not-found.tsx
**Файл:** `src/app/not-found.tsx`
**Проблема:** `href="javascript:history.back()"` — React warning о безопасности.
**Решение:** Заменить на `<button onClick={() => router.back()}>` или `<a href="#" onClick>`.
