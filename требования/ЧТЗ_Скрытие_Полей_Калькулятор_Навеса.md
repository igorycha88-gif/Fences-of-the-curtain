# ЧТЗ: Скрытие полей в клиентском калькуляторе навеса

**Дата:** 2026-06-17
**Маршрут:** Аналитик → Разработчик → Тестировщик → DevOps
**Тип задачи:** Малая (UI-изменение, 2 файла)

---

## 1. Постановка

В клиентском калькуляторе навеса (`/calculator/canopy`) скрыть три поля:

1. **Высота в коньке** (`ridgeHeight`) — number input
2. **Тип установки** (`installationType`) — select
3. **Водосточная система** (`hasWaterSystem`) — checkbox

Скрытие = убрать элементы ввода из UI и убрать отображение этих параметров в блоке «Параметры вашего навеса» (в правой панели результата и в модалке индивидуального расчёта).

## 2. Решение (как скрыть)

- В state формы `CanopyCalculatorForm` поля **оставляем** со значениями по умолчанию:
  - `ridgeHeight: 1.0`
  - `installationType: 'ground'`
  - `hasWaterSystem: false`
- В объект `canopyParameters` поля **оставляем** (модалка и валидатор требуют их presence, бэкенд заказа их использует).
- Удаляем только UI: инпуты/селекты/чекбоксы и строки отображения в сводке параметров.

Это гарантирует, что:
- не сломается `canopyCalculatorSchema` (валидатор требует ridgeHeight, installationType, hasWaterSystem)
- не сломается `CanopyNomenclatureNotFoundModal` (interface требует эти поля)
- не сломается API `/api/orders` и админка (OrderDetailPage показывает installationTypeLabel, водосток)

## 3. Файлы для изменения

| Файл | Что меняем |
|------|-----------|
| `src/app/(public)/calculator/canopy/page.tsx` | 1) Убрать инпут «Высота конька» (расширить «Высота» на всю строку). 2) Убрать селект «Тип установки». 3) Убрать чекбокс «Водосточная система». 4) Убрать 3 строки из сводки параметров в правой панели. |
| `src/components/calculator/CanopyNomenclatureNotFoundModal.tsx` | Убрать 3 строки из сводки «Параметры вашего навеса» (Высота конька, Установка, Водосток). |

## 4. Критерии приёмки

1. ✅ На странице `/calculator/canopy` отсутствуют поля: Высота конька, Тип установки, Водосточная система.
2. ✅ Поле «Высота» корректно отображается (занимает доступную ширину, не нарушая layout).
3. ✅ В сводке «Параметры вашего навеса» (правая панель) нет строк: Высота конька, Установка, Водосток.
4. ✅ В модалке индивидуального расчёта в сводке параметров нет этих трёх строк.
5. ✅ Кнопка «Рассчитать стоимость» работает, расчёт корректный.
6. ✅ Модалка отправки заявки открывается и работает.
7. ✅ `npm run lint && npx tsc --noEmit` проходят без ошибок.
8. ✅ Существующие тесты не сломаны (`npm test`).

## 5. Не входит в задачу

- Изменение формулы расчёта стоимости.
- Изменение бэкенда, валидатора, API.
- Удаление полей из типов/интерфейсов (оставляем для совместимости).
