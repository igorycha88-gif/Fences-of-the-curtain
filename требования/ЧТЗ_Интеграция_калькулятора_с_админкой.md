## 2. Цели и задачи

### 2.1 Бизнес-цель
Обеспечить актуальность цен в онлайн-калькуляторе заборов через интеграцию с существующей системой справочников, чтобы клиенты получали корректные расчеты, а менеджеры могли оперативно обновлять цены без участия разработчиков.

### 2.2 Пользовательская ценность
Клиенты получают мгновенные точные расчеты с актуальными ценами из базы данных, а менеджеры - единый источник правды для управления всеми материалами, ценами и параметрами расчета через уже реализованную админ-панель.

### 2.3 Ключевые метрики успеха
- Актуальность цен в калькуляторе = 100% (синхронизация с БД)
- Время обновления цен админом < 5 минут
- Время расчета калькулятора < 2 секунд
- Конверсия расчет → заявка ≥ 15%

## 4. Требования к продукту

### 4.1 Функциональные требования

#### F1: Интеграция калькулятора с существующими справочниками

**User Story:**
*Как клиент, я хочу чтобы калькулятор использовал актуальные цены из базы данных, чтобы расчет был точным.*

**Acceptance Criteria:**
- Калькулятор загружает типы заборов из таблицы `FenceType`
- Калькулятор загружает типы покрытия из таблицы `CoatingType`
- Калькулятор загружает лаги из таблицы `LagType`
- Калькулятор загружает столбы из таблицы `PostType`
- Калькулятор загружает материалы из таблицы `FenceMaterial` с учетом высот
- При изменении цен в админке, калькулятор автоматически использует новые цены
- Кеширование справочников в Redis (TTL 5 минут) для производительности

**Технические детали:**
- Обновить `fenceCalculator.ts` для использования Prisma вместо hardcoded цен
- Добавить загрузку данных из БД через существующие сервисы
- Реализовать кеширование часто используемых данных

#### F2: Управление воротами и калитками

**User Story:**
*Как менеджер, я хочу управлять ценами на ворота и калитки через админку, чтобы актуализировать их независимо от других материалов.*

**Acceptance Criteria:**
- Добавить категорию `GATES` и `WICKETS` в справочник материалов
- Поля для ворот:
  - Тип (распашные, откатные)
  - Базовая ширина (м)
  - Базовая цена (руб)
  - Цена за дополнительный метр ширины (руб/м)
  - Опция "Автоматические" (+фиксированная сумма или %)
- Поля для калиток:
  - Базовая ширина (м)
  - Базовая цена (руб)
  - Цена за дополнительный метр ширины (руб/м)
- В калькуляторе:
  - Выбор типа ворот из справочника
  - Расчет стоимости ворот = базовая цена + (фактическая ширина - базовая) × цена за метр
  - Чекбокс "Автоматические ворота" с надбавкой

**Технические детали:**
```typescript
// Расширение модели FenceMaterial
{
  category: 'GATES',
  name: 'Ворота распашные',
  basePrice: 15000,
  baseWidth: 3.5,
  pricePerExtraMeter: 2000,
  gateOptions: {
    automatic: {
      enabled: true,
      priceType: 'FIXED', // или 'PERCENT'
      priceValue: 25000
    }
  }
}
```

#### F3: Управление ценами на работы

**User Story:**
*Как менеджер, я хочу управлять ценами на монтажные работы через админку, чтобы оперативно реагировать на изменения рынка.*

**Acceptance Criteria:**
- Использовать существующую таблицу `WorkPrice`
- Категории работ:
  - Монтаж забора (руб/м.п.)
  - Бетонирование столбов (руб/шт)
  - Установка ворот (руб/шт)
  - Установка калитки (руб/шт)
  - Демонтаж старого забора (руб/м.п.)
  - Доставка (руб + руб/км)
- UI админки для управления ценами на работы
- В калькуляторе использовать актуальные цены из `WorkPrice`

**Технические детали:**
```sql
-- Пример данных WorkPrice
```

#### F4: Система доставки

**User Story:**
*Как клиент, я хочу видеть стоимость доставки в расчете, чтобы понимать полную стоимость заказа.*

**Acceptance Criteria:**
- Добавить параметры доставки в калькулятор:
  - Расстояние от МКАД/центра (км)
  - Или выбор района/города (опционально)
- Формула расчета доставки:
  ```
  deliveryCost = baseDeliveryPrice + (distance × pricePerKm)
  ```
- В админке:
  - Базовая стоимость доставки (руб)
  - Цена за км (руб/км)
  - Зоны доставки с фиксированными ценами (опционально)
- Отображение доставки в детализации расчета

**Технические детали:**
```typescript

  name: 'Доставка',
  basePrice: 5000,
  pricePerKm: 50
}
```

```typescript
import { prisma } from '@/lib/prisma';
import { redis } from '@/lib/redis';

export async function calculateFence(input: FenceCalculatorInput) {
  // 1. Загрузка данных из БД (с кешированием)
  const cacheKey = `calculator:fence:data`;
  let data = await redis.get(cacheKey);
  
  if (!data) {
    data = await loadCalculatorData();
    await redis.setex(cacheKey, 300, JSON.stringify(data)); // 5 минут
  } else {
    data = JSON.parse(data);
  }
  
  // 2. Получение актуальных цен
  const fenceType = data.fenceTypes.find(t => t.id === input.fenceTypeId);
  const material = data.materials.find(m => m.id === input.materialId);
  const heightCoef = material.availableHeights.find(h => h.height === input.selectedHeight)?.priceCoef || 1.0;
  
  // 3. Расчет материалов
  const materials = calculateMaterials(input, material, heightCoef, data);
  
  // 4. Расчет работ
  const works = calculateWorks(input, data.workPrices);
  
  // 5. Расчет доставки
  const delivery = calculateDelivery(input.deliveryDistance, data.workPrices);
  
  // 6. Применение коэффициентов
  const coefficients = applyCoefficients(input, data.soilTypes, data.coefficients);
  
  // 7. Итого
  const materialsTotal = materials.reduce((sum, m) => sum + m.total, 0);
  const worksTotal = works.reduce((sum, w) => sum + w.total, 0);
  const coefficientsTotal = (materialsTotal + worksTotal) * (coefficients.multiplier - 1);
  
  return {
    materials,
    works,
    delivery,
    coefficients,
    materialsTotal,
    worksTotal,
    deliveryTotal: delivery.total,
    coefficientsTotal,
    grandTotal: materialsTotal + worksTotal + delivery.total + coefficientsTotal
  };
}
```

### Б.2 Формула расчета ворот

```typescript
function calculateGate(gateMaterial: FenceMaterial, width: number, automatic: boolean) {
  const basePrice = gateMaterial.basePrice;
  const baseWidth = gateMaterial.baseWidth || 3.5;
  const pricePerExtraMeter = gateMaterial.pricePerExtraMeter || 2000;
  
  // Базовая стоимость + доплата за ширину
  let gatePrice = basePrice;
  if (width > baseWidth) {
    gatePrice += (width - baseWidth) * pricePerExtraMeter;
  }
  
  // Автоматика
  if (automatic && gateMaterial.gateOptions?.automatic) {
    const autoOption = gateMaterial.gateOptions.automatic;
    if (autoOption.priceType === 'FIXED') {
      gatePrice += autoOption.priceValue;
    } else {
      gatePrice *= (1 + autoOption.priceValue / 100);
    }
  }
  
  return gatePrice;
}
```
