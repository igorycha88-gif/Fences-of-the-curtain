# ЧТЗ: Скрытие столбов в калькуляторе навеса + фикс валидатора truss (v1.14.1)

> Постдеплойный фикс (ПРАВИЛО 7). Создан после релиза v1.14.0.

## Контекст проблемы

После деплоя v1.14.0 обнаружено:
1. **Калькулятор навеса нерабочий**: кнопка «Рассчитать» всегда disabled, т.к. требует `postTypeId` и `roofCoveringId`, а таблицы `TrussProfileType`/`TrussRoofCovering` пустые (seed не применился).
2. **POST /api/admin/truss-profiles → 400** при добавлении профиля: валидатор `trussProfileCreateSchema` использует `.optional()` для закупочных цен, а форма отправляет `null` → Zod отвергает null. Та же ошибка в `trussRoofCoveringCreateSchema.purchasePricePerSqm`.

## Решение пользователя

- Поле «Столбы» СКРЫТЬ из калькулятора навеса (при текущем расчёте L×W×8500 не нужно).
- Поле «Материал кровли» ОСТАВИТЬ + засеять данные (seed).
- Валидатор truss починить (чтобы админка покрытий/профилей работала).

## Маршрутизация

- Маршрут: Аналитик → Разработчик → Тестировщик → DevOps
- Архитектор НЕ привлекается (изменения тривиальные: скрытие поля + `.nullable()`)
