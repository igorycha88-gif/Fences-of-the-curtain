# ЧТЗ (упрощённое): Фон шапки при скролле — светло-оранжевый вместо яркого

**Дата:** 2026-09-10
**Маршрут:** Маршрут 1 (Аналитик → Разработчик → Тестировщик → DevOps)
**Тип:** Малая задача (<3 файлов, без БД/API/архитектуры)

---

## 1. Проблема

При скролле страницы шапка сайта получает класс `.glass` (полупрозрачный белый фон
`hsl(var(--glass-bg))` = белый 0.7 + `backdrop-filter: blur(12px)`). Сквозь эту
полупрозрачную подложку просвечивает тёплый оранжевый фон героя (`bg-primary/10`
blur-блобы, `--primary: 25 95% 53%`), из-за чего шапка визуально воспринимается
как яркое жёлтое пятно.

Пользователь: «не нравится, что при скролле header выделяется жёлтым — сделать
менее ярко, светло-оранжевым (в цвет бренда)».

**Решение по ответу пользователя:** светло-оранжевый (вариант рекомендован и выбран).

## 2. Что делаем

1. В `src/app/globals.css` добавить НОВЫЙ компонентный класс `.glass-header`:
   - фон: едва заметный тёплый оранжевый оттенок с достаточно высокой
     непрозрачностью, чтобы перекрыть тёплую подложку героя
     (light: `hsl(25 100% 98% / 0.92)`);
   - `backdrop-filter: blur(12px)` (с `-webkit-`);
   - нижняя граница/тень в тёлом тоне (тонкая, деликатная);
   - тёмная тема (`.dark`): тёплый тёмный оттенок с лёгкой оранжевой примесью.
2. В `src/components/layout/Header.tsx` при `isScrolled` использовать
   `glass-header` вместо `glass` (класс `.glass` НЕ трогать — он используется
   в bento-карточках, баннерах, отзывах).
3. Обновить автотесты `__tests__/components/layout/Header.test.tsx`:
   - до скролла header НЕ имеет класса `glass-header`;
   - после скролла (scrollY > 20) header ИМЕЕТ класс `glass-header` и не имеет `glass`.

## 3. Файлы для изменения

| Файл | Изменение |
|------|-----------|
| `src/app/globals.css` | + класс `.glass-header` (light + dark) |
| `src/components/layout/Header.tsx` | `glass` → `glass-header` при скролле |
| `__tests__/components/layout/Header.test.tsx` | + тесты скролл-состояния |

## 4. Критерии приёмки

1. При скролле >20px фон шапки — светло-оранжевый, мягкий, без «жёлтого пятна».
2. В тёмной теме шапка при скролле — тёмная с тёплым оттенком, читаемая.
3. До скролла шапка остаётся прозрачной (как сейчас).
4. Прочие использования `.glass` (главная, баннеры, отзывы) не изменяются.
5. `npm test && npm run lint && npx tsc --noEmit` — зелёные.
