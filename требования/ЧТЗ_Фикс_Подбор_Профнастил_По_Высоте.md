# ЧТЗ: Фикс подбора профнастила по высоте

## Описание проблемы
При выборе высоты забора 1.8м для типа «Профнастил» калькулятор подбирает профлист 2.0м вместо 1.8м.

## Корневая причина
В `profnastilCalculator.ts` функция `getActiveProfnastil()` сортирует записи по `priority ASC, length ASC`. Поскольку 2.0м листы имеют более низкий приоритет (1-3), чем 1.8м листы (4-11), они всегда оказываются первыми в отфильтрованном списке, даже когда точное совпадение по высоте (1.8м) доступно.

## Решение
После фильтрации по `length >= fenceHeightMm` пересортировать результаты: сначала по `length ASC` (ближайшая подходящая высота), затем по `priority ASC`. Это гарантирует выбор листа с минимальной подходящей высотой.

## Файлы для изменения
- `src/services/calculator/profnastilCalculator.ts` — добавить сортировку после фильтрации

## Критерии приёмки
1. При высоте 1.8м подбирается профлист 1.8м (для всех покрытий)
2. При высоте 2.0м подбирается профлист 2.0м
3. При высоте 1.5м подбирается ближайший доступный (1.8м)
4. При нестандартной высоте (например 2.1м) подбирается ближайший больший (2.2м)
5. Существующие тесты продолжают проходить
