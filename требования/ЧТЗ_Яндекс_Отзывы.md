# ЧТЗ: Интеграция отзывов с Яндекс.Бизнесом

## 1. Цель задачи
Вывести на главную страницу информацию об отзывах с Яндекс.Бизнеса и предоставить пользователям возможность оставить отзыв о компании прямо с сайта.

## 2. Анализ технических решений

### 2.1. Варианты интеграции

#### Вариант А: Яндекс.Карты API (Рекомендуется)
**Плюсы:**
- Официальный API
- Не требует авторизации для чтения отзывов
- Можно использовать виджет рейтинга
- Бесплатно для базового использования

**Минусы:**
- Требует API ключ
- Ограничения по количеству запросов

**Реализация:**
```typescript
// API endpoint для получения отзывов
GET /api/yandex-reviews

// Возвращает:
{
  rating: number,
  reviewsCount: number,
  reviews: Review[]
}
```

#### Вариант Б: Виджет Яндекс.Карт
**Плюсы:**
- Готовый виджет
- Официальное решение
- Автоматическое обновление

**Минусы:**
- Ограниченная кастомизация
- Внешняя зависимость
- Может замедлить загрузку

#### Вариант В: Кэшированные отзывы через Backend
**Плюсы:**
- Полный контроль над данными
- Быстрая загрузка
- Кэширование в Redis

**Минусы:**
- Требует периодического обновления
- Не real-time

### 2.2. Рекомендуемое решение

**Гибридный подход:**
1. **Отображение рейтинга** - через Яндекс API или виджет
2. **Кнопка "Оставить отзыв"** - прямая ссылка на Яндекс.Карты
3. **Кэширование** - хранить отзывы в Redis с TTL 1 час
4. **Fallback** - показать заглушку если API недоступен
