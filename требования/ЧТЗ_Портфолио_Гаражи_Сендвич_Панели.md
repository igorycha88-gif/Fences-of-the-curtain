# ЧТЗ: Раздел «Гаражи из сендвич-панелей» в портфолио

## 1. Описание задачи

Добавить новую категорию портфолио **«Гаражи из сендвич-панелей»** (`garage`) в существующую систему портфолио. В админ-панели при создании/редактировании элемента портфолио добавить третий вариант категории. На клиентской странице портфолио добавить вкладку-фильтр «Гаражи» и отображать элементы этой категории.

## 2. Контекст

Существующая система портфолио поддерживает 2 категории: `fence` (Заборы) и `canopy` (Навесы). Категория — это строковое поле `category` в модели `PortfolioItem`, валидируемое через Zod `z.enum(['fence', 'canopy'])`. Задача — механически расширить enum до `['fence', 'canopy', 'garage']` и обновить UI-метки во всех местах.

## 4. Критерии приёмки

1. В админ-панели при создании/редактировании элемента портфолио доступна категория «Гаражи из сендвич-панелей»

3. В админ-списке элементы категории «Гаражи» отображаются с меткой «Гаражи» (оранжевый/amber цвет)
