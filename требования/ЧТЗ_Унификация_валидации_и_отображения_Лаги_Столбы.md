## 1. Общая информация

### 1.1 Название проекта
Унификация отображения таблиц и форм справочников Лаги и Столбы + валидация уникальности с учётом длины

## 2. Цели и задачи

### 2.1 Бизнес-цель
Обеспечить единообразие пользовательского интерфейса между справочниками Лаги и Столбы, а также корректную валидацию уникальности номенклатуры с учётом длины.

### 2.2 Пользовательская ценность
- Единообразный интерфейс между справочниками
- Возможность создавать номенклатуры с одинаковыми параметрами, но разными длинами
- Упрощение работы администраторов

### 2.3 Ключевые метрики успеха
- 100% консистентность UI между Лагами и Столбами
- Успешное создание номенклатур с разными длинами

#### 3.1.3 Требование 3: Валидация уникальности с учётом длины

**User Story 3:**
*Как администратор, я хочу создавать номенклатуры с одинаковыми параметрами, но разными длинами, без необходимости указывать срок действия для существующей.*

**Бизнес-правила:**

| Правило | Описание |
|---------|----------|
| BR-3.1 | Уникальность номенклатуры определяется по: name + dimensions + **length** |
| BR-3.2 | Если длина отличается - это новая уникальная номенклатура |
| BR-3.3 | Если длина совпадает - проверяется пересечение периодов |
| BR-3.4 | Не требуется указывать срок действия для существующей номенклатуры при разных длинах |

**Требования:**

| ID | Требование | Обоснование |
|----|------------|-------------|
| REQ-3.1 | Добавить поле `length` в проверку уникальности для Лаги | Бизнес-правило |
| REQ-3.2 | Добавить поле `length` в проверку уникальности для Столбы | Бизнес-правило |
| REQ-3.3 | Если длины разные - не показывать warning о дубликате | UX |
| REQ-3.4 | Если длины одинаковые - существующая логика проверки периодов | Сохранение логики |

**Примеры сценариев:**

| Сценарий | Существующая номенклатура | Новая номенклатура | Результат |
|----------|---------------------------|-------------------|-----------|
| 1 | Профиль 60x60x2.5, длина 2.5м | Профиль 60x60x2.5, длина 3.0м | ✅ Создаётся без warning |
| 2 | Профиль 60x60x2.5, длина 2.5м | Профиль 60x60x2.5, длина 2.5м | ⚠️ Warning о дубликате |
| 3 | Профиль 40x20x2.0, длина 2.5м | Профиль 40x20x2.0, длина 3.0м | ✅ Создаётся без warning |

**Acceptance Criteria:**
- [ ] Номенклатура с той же ценой, но другой длиной создаётся без warning
- [ ] Номенклатура с той же ценой И той же длиной показывает warning
- [ ] Логика работает для обоих справочников (Лаги и Столбы)
