# ЧТЗ (упрощённое): Выгрузка посадочных страниц и SEO-формулировок в Excel

## Задача
Сформировать Excel-файл со всеми посадочными страницами сайта и SEO-формулировками
(ключевыми запросами), добавленными для поиска.

## Источники данных (только чтение, без изменения кода сайта)

| # | Источник | Что содержит | Объём |
|---|----------|--------------|-------|
| 1 | `src/lib/seo/constants.ts` → `PAGE_METADATA` | Статичные страницы: title, description, keywords | 13 страниц |
| 2 | `src/lib/geo/cities.ts` + `src/lib/geo/content.ts` | Гео-посадочные: 32 города + 3 хаба направлений, ключи генерируются `generateCityKeywords()` | 35 страниц |
| 3 | `scripts/seed-service-pages.ts` | Страницы услуг `/services/[slug]`: seoTitle, seoDescription, seoKeywords | 6 страниц |
| 4 | `scripts/seed-blog.ts` + `scripts/seed-blog-expanded.ts` | Статьи блога `/blog/[slug]`: seoTitle, seoDescription, seoKeywords | ~21 статья (дедуп по slug) |
| 5 | Таблица БД `seo_keywords` (SEO-мониторинг) | Формулировки для отслеживания позиций | В dev-базе пусто; включить при наличии |

## Структура Excel-файла

**Лист 1 «Посадочные страницы»:** №, Тип страницы, URL, Path, SEO Title, SEO Description,
Ключевые запросы (через «; »), Кол-во запросов, Источник данных.

**Лист 2 «Ключевые запросы»:** №, Формулировка (запрос), Страница, Тип страницы, Источник —
по одной строке на пару «запрос + страница».

**Лист 3 «Сводка»:** количество страниц по типам, всего уникальных запросов, дата формирования.

## Критерии приёмки
1. Все 4 источника включены (статичные, гео, услуги, блог).
2. Полные URL вида `https://zabor-i-naves.ru/...`.
3. Ключи гео-страниц соответствуют `generateCityKeywords()` (10 запросов на город) + 3 ключа на хаб.
4. Дедупликация статей блога по slug.
5. Файл открывается в Excel / LibreOffice, корректная кодировка кириллицы.
6. Код сайта не изменяется — экспорт однострочным скриптом вне src/.

## Маршрутизация
- Исполнитель: Разработчик (скрипт генерации xlsx).
- DevOps-деплой: НЕ требуется (изменений приложения нет; ЧТЗ не предусматривает правок кода сайта).
- Контроль: Тестировщик сверяет данные файла с исходниками.
