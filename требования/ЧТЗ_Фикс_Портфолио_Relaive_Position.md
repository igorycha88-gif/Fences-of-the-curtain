# ЧТЗ: Фикс — Фото портфолио растягиваются на весь экран

**Дата:** 2026-05-05  
**Приоритет:** Критический  
**Маршрут:** Разработчик → Тестировщик → DevOps

---

## Описание проблемы

На странице `/portfolio` все фотографии, кроме одной, не отображаются. Одна фотография (навес) растянута на весь экран.

**Причина:** В компоненте `PortfolioClient.tsx` родительский `<div>` для `ImageWithFallback` (Next.js `Image` с `fill`) не имеет CSS-класса `relative`. Без него `position: absolute` изображения позиционируется относительно viewport — все фото складываются друг на друга, видна только верхняя.

## Файлы для изменения

1. `src/components/portfolio/PortfolioClient.tsx` — добавить `relative` в className родительского div

## Критерии приёмки

1. Все 8 карточек портфолио отображают свои миниатюры корректно
2. Ни одно изображение не растягивается за пределы карточки
3. Карточки выстроены в сетку (3 столбца на десктопе)
4. Плейсхолдер «Нет фото» показывается если `thumbnailUrl` пустой
