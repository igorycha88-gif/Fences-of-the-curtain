# Инструкция по восстановлению сервера

## Шаг 1: Подключение к серверу

Откройте Терминал (в macOS) и выполните:

```bash
ssh root@37.143.13.196
```

Когда спросят пароль, введите: `*********` (символы не будут видны при вводе)

## Шаг 2: Переход в директорию проекта

После успешного подключения вы увидите что-то вроде `root@server:~#`
Введите:

```bash
cd /root/Fences-of-the-curtain
```

## Шаг 3: Запуск восстановления

Просто скопируйте и вставьте эту команду:

```bash
bash scripts/recover.sh
```

Сценарий автоматически:
1. Проверит состояние системы
2. Обновит код
3. Установит зависимости
4. Перезапустит приложение

## Если возникнут проблемы:

### Проверка статуса приложения:
```bash
pm2 status
pm2 logs fences-app --lines 50
```

### Проверка ответа приложения:
```bash
curl http://localhost:3001/
```

### Ручной перезапуск:
```bash
cd /root/Fences-of-the-curtain
pm2 restart fences-app
```

## Настройка SSL (если есть домен)

Замените `yourdomain.com` на ваш реальный домен:

```bash
bash scripts/setup-ssl.sh yourdomain.com
```

## Настройка автоматических бэкапов

Выполните один раз:

```bash
crontab -e
```

Нажмите `i` для редактирования, добавьте строку:
```
0 2 * * * /root/Fences-of-the-curtain/scripts/backup-db.sh
```

Нажмите `Esc`, затем `:wq` и `Enter` для сохранения.

## Выход с сервера

```bash
exit
```
