# Инструкции для тестирования CRUD лаги/столбы

## Шаги для тестирования:

### 1. Dev сервер запущен
✅ Сервер работает на: **http://localhost:3000**

### 2. Откройте браузер и консоль разработчика
- Откройте http://localhost:3000
- Откройте DevTools (F12 или Cmd+Option+I)
- Перейдите на вкладку "Console" для просмотра логов

### 3. Откройте страницу справочника Лаги
- Перейдите в админку
- Откройте раздел "Справочники" -> "Лаги"

### 4. Попробуйте создать новую лагу
- Нажмите кнопку "Добавить"
- Заполните форму
- Откройте вкладку "Network" в DevTools
- Нажмите "Создать"
- Посмотрите:
  - Логи в консоли браузера (должны быть логи [LAGS PAGE])
  - Запрос в Network tab (найдите POST /api/admin/lag-types)
  - Ответ сервера

### 5. Посмотрите логи сервера
```bash
tail -f /tmp/next-dev.log
```

Или в другом терминале:
```bash
tail -n 50 /tmp/next-dev.log | grep -E "(LAG|POST|PUT|Error)"
```

## Что нужно проверить:

1. **При создании:**
   - Лог в консоли браузера: `[LAGS PAGE] Form submitted`
   - Лог в консоли браузера: `[LAGS PAGE] Sending request: POST /api/admin/lag-types`
   - Лог на сервере: `[LAG-TYPES POST] Starting create lag type...`
   - Toast уведомление: "Лага успешно создана"
   - Запись появляется в таблице

2. **При редактировании:**
   - Лог в консоли браузера: `[LAGS PAGE] Form submitted`
   - Лог в консоли браузера: `[LAGS PAGE] Sending request: PUT /api/admin/lag-types/...`
   - Лог на сервере: `[LAG-TYPES PUT] Starting update lag type...`
   - Toast уведомление: "Лага успешно обновлена"
   - Изменения отображаются в таблице

3. **Если ничего не происходит:**
   - Проверьте консоль браузера на ошибки JavaScript
   - Проверьте Network tab - отправляется ли запрос вообще
   - Проверьте авторизованы ли вы (есть ли сессия)
   - Проверьте вашу роль (нужна роль ADMIN)

## Логи для проверки:

### Браузер (Console):
```

[LAGS PAGE] Sending request: POST /api/admin/lag-types

### Сервер (terminal):

[LAG-TYPES POST] Validated data: {...}
[LAG-TYPES POST] Created lag with id: ...
```

## Возможные проблемы:

1. **Не отправляется запрос:**
   - Проверьте консоль браузера на ошибки JavaScript
   - Проверьте, что кнопка имеет type="submit"
   - Проверьте, что форма не вложена в другую форму

2. **Запрос отправляется, но ошибка 401/403:**
   - Вы не авторизованы
   - У вас не роль ADMIN

3. **Запрос отправляется, но ошибка 400:**
   - Проблема с валидацией данных
   - Посмотрите детали ошибки в ответе сервера

4. **Запрос успешен (200/201), но изменения не видны:**
   - Проблема с обновлением таблицы
   - Проверьте, что вызывается fetchLags()
