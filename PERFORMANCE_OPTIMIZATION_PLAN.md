# План оптимизации производительности

## Выявленные проблемы

### 🔴 КРИТИЧЕСКИЕ

#### 1. **Console.log в production (cache.ts)**
- **Проблема**: Каждая операция кеширования логируется в консоль
- **Влияние**: Существенное замедление всех операций с кешем
- **Решение**: Удалить console.log или заменить на условное логирование только в dev режиме

**Файлы:**
- `src/lib/cache.ts` - строки 17, 28, 32, 44, 58, 81

#### 2. **Отсутствие connection pooling для PostgreSQL**
- **Проблема**: Prisma создает новое соединение для каждого запроса
- **Влияние**: Медленные запросы к БД, особенно под нагрузкой
- **Решение**: Добавить PgBouncer или настроить connection pooling в Prisma

#### 3. **Redis lazyConnect**
- **Проблема**: `lazyConnect: true` вызывает задержку при первом запросе
- **Влияние**: Медленный первый запрос к кешу
- **Решение**: Убрать lazyConnect или добавить предварительное подключение

### 🟡 СРЕДНИЕ

#### 4. **Нет сжатия gzip/brotli в Nginx**
- **Проблема**: Статические файлы передаются без сжатия
- **Влияние**: Большой размер передаваемых данных, медленная загрузка
- **Решение**: Включить gzip/brotli в nginx.conf

#### 5. **Короткое время кеширования в Nginx**
- **Проблема**: GET запросы кешируются только на 10 минут
- **Влияние**: Частые обращения к приложению вместо отдачи из кеша
- **Решение**: Увеличить время кеширования для статического контента

#### 6. **Нет оптимизации изображений Next.js**
- **Проблема**: Изображения не оптимизируются автоматически
- **Влияние**: Большие размеры файлов изображений
- **Решение**: Настроить next.config.js для оптимизации изображений

### 🟢 НИЗКИЙ ПРИОРИТЕТ

#### 7. **Нет standalone output в Next.js**
- **Проблема**: Весь node_modules копируется в Docker образ
- **Влияние**: Большой размер Docker образа, медленный деплой
- **Решение**: Включить `output: 'standalone'` в next.config.js

#### 8. **Нет HTTP/2 Push**
- **Проблема**: Критические ресурсы не пушатся proactively
- **Влияние**: Дополнительные round-trip для загрузки ресурсов
- **Решение**: Настроить HTTP/2 Server Push в Nginx
