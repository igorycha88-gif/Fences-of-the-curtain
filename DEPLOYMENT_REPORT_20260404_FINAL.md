**Проблема:** SMTP не сконфигурирован, используются placeholder значения:
```
SMTP_USER="your-email@gmail.com"
SMTP_PASS="your-app-password"
```

**Ошибка в логах:**
```
Email error: Invalid login: 535-5.7.8 Username and Password not accepted
```

**Решение:** Настроить Yandex SMTP (рекомендуется для igorycha.s@yandex.ru):

```bash
ssh root@37.143.13.196
cd /root/Fences-of-the-curtain
nano .env
```

Заменить:
```
SMTP_HOST="smtp.yandex.ru"
SMTP_PORT="465"
SMTP_USER="igorycha.s@yandex.ru"
SMTP_PASS="ВАШ_ПАРОЛЬ_ПРИЛОЖЕНИЯ_YANDEX"
```

**Как получить пароль приложения Yandex:**
1. https://passport.yandex.ru/profile
2. Безопасность → Пароли приложений → Создать
3. Название: "Fences App"
4. Скопировать пароль

**После настройки:**
```bash
pm2 restart fences-app
```
