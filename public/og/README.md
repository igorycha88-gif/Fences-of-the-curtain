# OG Images Directory

This directory should contain Open Graph images for social media sharing.

Required images:
- og-main.jpg (1200x630 px)
- og-services.jpg (1200x630 px)
- og-calculator.jpg (1200x630 px)
- og-portfolio.jpg (1200x630 px)
- og-contacts.jpg (1200x630 px)

Specifications:
- Format: JPEG or PNG
- Size: 1200x630 pixels (Facebook/LinkedIn recommendation)
- File size: < 200 KB each
- Include company name and page title
- Use consistent branding

Note: Actual image files should be created by a designer and placed here.
