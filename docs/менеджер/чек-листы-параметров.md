# Чек-листы параметров для расчёта

Документ для менеджера: какие параметры уточнить у клиента, чтобы рассчитать стоимость. Параметры соответствуют калькулятору проекта — то, что менеджер соберёт по чек-листу,可直接 переносится в `/admin/calculator`.

> **Как пользоваться:** пройти чек-лист сверху вниз. Пункты без пометки — обязательны. Помеченные «по желанию» — уточнить, но можно пропустить.

## 1. Общие параметры (для всех заборов)

Эти параметры уточняются **всегда**, независимо от типа забора.

| # | Параметр | Что спросить у клиента | Допустимые значения |
|---|----------|------------------------|---------------------|
| 1.1 | **Тип забора** | «Какой тип забора вас интересует?» | Профнастил / Евроштакетник / 3D-панели / Сетка-рабица |
| 1.2 | **Длина забора** | «Какая общая длина забора (по периметру)?» | от 10 до 1000 м |
| 1.3 | **Высота забора** | «Какая высота забора нужна?» | от 1,5 до 3,5 м |
| 1.4 | **Покрытие** | «Какое покрытие металла?» — влияет на цену и срок службы | Оцинкованное / Полимер одностороннее / Полимер двустороннее |
| 1.5 | **Нужны ли ворота?** | «Нужны ли ворота? Какие — откатные или распашные?» | Да/Нет → см. [Чек-лист: Ворота](#6-чек-лист-ворота) |
| 1.6 | **Нужна ли калитка?** | «Нужна ли калитка?» | Да/Нет → см. [Чек-лист: Калитка](#7-чек-лист-калитка) |
| 1.7 | **Монтаж** | «Нужен ли монтаж нашими силами?» (или только материал) | Да / Нет |
| 1.8 | **Рельеф и грунт** *(по возможности)* | «Участок ровный или есть перепады по высоте? Какой грунт?» | Ровный / перепады; песок/глина/камень/торф |

> **Совет менеджеру:** длина и высота — базовые величины, из них считается площадь и количество материала. Если клиент не знает длину — попросите схему участка или длину сторон. Ворота и калитка **вычитаются** из общей длины полотна, поэтому их ширину нужно знать точно.

## 2. Чек-лист: Профнастил

| # | Параметр | Что спросить у клиента | Значения |

| 2.3 | Покрытие | оцинкованный / полимер одностор. / полимер двусторон. | см. общие 1.4 |
| 2.4 | **Количество лаг** | «Сколько рядов лаг (прожилин)? 2 или 3?» — 3 ряда жёстче, дороже | 2 / 3 |

| Автоматика *(только откатные)* | «Нужна автоматика?» | Да / Нет → выбрать модель |
| Количество | «Сколько ворот нужно?» | 1 / 2 |

**Калитка** — спросить: «Нужна ли калитка?»

*Если да:*

|---|---|---|

> **Важно:** покрытие определяет тип листа профнастила и его цену. Стандарт — 2 ряда лаг; для высоких заборов (3 м+) рекомендуется 3 ряда.

## 9. Финальная проверка перед расчётом

Прежде чем вводить данные в калькулятор, менеджер проверяет:

- [ ] Тип забора определён
- [ ] Длина и высота заполнены (числа, в метрах)
- [ ] Указаны все специфичные параметры для выбранного типа:
  - Профнастил → кол-во лаг, покрытие
  - Евроштакетник → профиль, шаг, тип монтажа (одностор./шахматка)
  - 3D-панели → (лаги не нужны)
  - Сетка-рабица → ячейка, толщина проволоки, покрытие
- [ ] Если есть ворота → тип, ширина, высота, (автоматика для откатных)
- [ ] Если есть калитка → ширина, высота
- [ ] Монтаж: включён или нет
- [ ] Сумма ширин ворот и калиток логична и не превышает длину забора
- [ ] При навесе → тип крыши, назначение, длина/ширина/высота, тип установки, покрытие

> Если все пункты собраны — расчёт в `/admin/calculator` даст корректную смету без уточняющих вопросов.

## Быстрая шпаргалка: что критично для цены

| Тип забора | Что сильнее всего влияет на цену |
|------------|----------------------------------|
| Профнастил | покрытие (двусторонний полимер дороже), кол-во лаг, высота |
| Евроштакетник | **тип монтажа** (шахматка ×2), шаг, профиль |
| 3D-панели | высота (подбирает секцию) |
| Сетка-рабица | толщина проволоки, покрытие, размер ячейки |
| Ворота | тип (откатные дороже), ширина, автоматика |
| Навес | форма крыши, площадь, тип установки |
