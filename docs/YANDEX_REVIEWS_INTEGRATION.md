# Интеграция отзывов с Яндекс.Бизнесом

## 🎯 Быстрый старт (Рекомендуется)

### Использование официального виджета Яндекса

Самый простой способ - использовать готовый виджет Яндекса, который показывает рейтинг и количество отзывов.

**Преимущества:**
- ✅ Официальный виджет Яндекса
- ✅ Автоматическое обновление данных
- ✅ Не требует API ключей
- ✅ Мгновенная загрузка
- ✅ Доверие пользователей

**Интеграция:**

```tsx
import { YandexReviews } from '@/components/reviews/YandexReviews';

// На главной странице
<YandexReviews showReviews={true} maxReviews={3} />
```

Виджет автоматически отображается в секции отзывов.

### Компонент виджета

Для использования в других местах:

```tsx
import { YandexRatingBadge } from '@/components/reviews/YandexRatingBadge';

// Рейтинг
<YandexRatingBadge orgId="154197841574" type="rating" />

// Отзывы
<YandexRatingBadge orgId="154197841574" type="reviews" />
```

## 📋 Конфигурация

### Переменные окружения

Добавьте в `.env`:

```bash
# ID организации в Яндекс.Картах
YANDEX_ORG_ID="154197841574"

# URL организации (для кнопок "Читать отзывы" и "Оставить отзыв")
NEXT_PUBLIC_YANDEX_ORG_URL="https://yandex.ru/maps/org/154197841574/"
```

### Получение ID организации

1. Откройте Яндекс.Карты: https://yandex.ru/maps
2. Найдите вашу организацию
3. Скопируите ID из URL: `https://yandex.ru/maps/org/ID_ОРГАНИЗАЦИИ/`
4. Или из кода виджета в Яндекс.Бизнесе

## 📝 Статические отзывы

По умолчанию используются статические отзывы из базы данных. Они показываются в карточках под виджетом.

### Редактирование отзывов

Файл: `src/app/api/yandex-reviews/route.ts`

```typescript
const STATIC_REVIEWS: Review[] = [
  {
    id: '1',
    author: 'Александр К.',
    rating: 5,
    text: 'Отличный забор! Установили за 2 дня...',
    date: '2026-03-15'
  },
  // Добавьте свои отзывы...
];
```

### API Endpoint

**GET /api/yandex-reviews**

Возвращает:
```json
{
  "rating": 4.9,
  "reviewsCount": 127,
  "reviews": [...],
  "yandexUrl": "https://yandex.ru/maps/org/154197841574/",
  "source": "static"
}
```

## 🔧 Расширенная интеграция (Опционально)

### Real-time отзывы через Яндекс API

Если нужна автоматическая синхронизация с реальными отзывами:

**1. Получите API ключ:**
- Зарегистрируйтесь в Яндекс.Бизнесе: https://yandex.ru/business
- Получите API ключ в настройках разработчика

**2. Добавьте в .env:**
```bash
YANDEX_API_KEY="ваш_ключ_яндекс_api"
```

**3. API автоматически:**
- Запросит отзывы из Яндекс API
- Закэширует в Redis (1 час)
- Показывает реальные данные

### Кэширование

- **Redis**: данные кэшируются на 1 час
- **Ключ**: `yandex_reviews`
- **TTL**: 3600 секунд (можно изменить)

## 🛠️ Troubleshooting

### Виджет не отображается
1. Проверьте ID организации: `YANDEX_ORG_ID`
2. Убедитесь, что организация верифицирована в Яндексе
3. Проверьте блокировщики рекламы (могут блокировать iframe)

### API возвращает ошибку
```bash
# Проверьте логи
docker-compose logs app | grep yandex-reviews

# Очистите кэш
redis-cli DEL yandex_reviews
```

### Redis не подключается
```bash
# Проверьте статус Redis
docker-compose ps redis

# Перезапустите Redis
docker-compose restart redis
```
