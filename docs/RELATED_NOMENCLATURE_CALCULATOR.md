# Связанные номенклатуры для расчета калькулятора

## 📋 Обзор

Функциональность позволяет связывать дополнительные элементы (работы по монтажу, монтажная фурнитура) с основными номенклатурами материалов (столбы, лаги, профнастил, 3D-панели, ворота, калитка) и учитывать их при расчете стоимости забора в калькуляторе.

## 🎯 Как это работает

### В админ-панели

Для каждой номенклатуры в справочнике можно добавить связанные элементы:

1. **Работы по монтажу** (`/admin/references/works`)
   - Отображаются в разделе "🔧 Связанные работы по монтажу"
   - Можно связать с конкретной номенклатурой (например, "3D-панель h-2")
   - Проверяется поле `useInCalculator` - только работы с галочкой "Использовать в калькуляторе" попадают в расчет

2. **Монтажная фурнитура** (`/admin/references/mounting-hardware`)
   - Отображается в разделе "🔩 Связанная монтажная фурнитура"
   - Можно связать с конкретной номенклатурой
   - Проверяется поле `useInCalculator` - только фурнитура с галочкой "Использовать в калькуляторе" попадает в расчет
   - Имеет метод расчета (`BY_QUANTITY`, `BY_LENGTH`, `BY_AREA`, `BY_RATIO`, `BY_INVERSE_RATIO`)

### В калькуляторе

При расчете стоимости забора система автоматически:

1. Проверяет каждую номенклатуру в расчете (столбы, лаги, профнастил, 3D-панели, ворота, калитка)
2. Если у номенклатуры есть связанные элементы:
   - Для **работ**: проверяет `useInCalculator = true` и добавляет работу в раздел "монтаж" с учетом цены
   - Для **монтажной фурнитуры**: проверяет `useInCalculator = true` и рассчитывает количество согласно методу расчета
3. Результаты добавляются к основным материалам в смете

## 📝 Требования к данным

### Для работ по монтажу (Work)

Минимальные требования:
- `name`: Название работы (обязательно)
- `category`: Категория работы (MOUNTING, DELIVERY, ADDITIONAL, MEASUREMENT)
- `unit`: Единица измерения (M, KM, PCS, FIXED, M2)
- `price`: Стоимость работы (обязательно)
- `useInCalculator`: Галочка "Использовать в калькуляторе" (важно!)
- `active`: Статус активности (по умолчанию true)

Для использования в калькуляторе:
- `useInCalculator` должно быть `true`
- Работа должна быть **связана с номенклатурой** через таблицу `WorkRelation`

### Связь с номенклатурой (WorkRelation)

Таблица связывает работы с номенклатурами:

```prisma
model WorkRelation {
  id          String   @id @default(cuid())
  workId       String
  fenceType    String?  // Тип забора (для общих работ)
  referenceType String?  // Тип номенклатуры: LAG, POST, PROFNASTIL, PICKET, GATE, WICKET, PANEL_3D
  referenceId   String?  // ID номенклатуры
  createdAt    DateTime @default(now())
  
  work         Work     @relation(fields: [workId], references: [id])
}
```

Примеры связей:
- `fenceType: "PROFNASTIL"` - работа для всего типа забора "Профнастил"
- `referenceType: "PANEL_3D"` + `referenceId: "panel-id"` - работа для конкретной 3D-панели
- `referenceType: "GATE"` + `referenceId: "gate-id"` - работа для конкретных ворот
- `referenceType: "WICKET"` + `referenceId: "wicket-id"` - работа для конкретной калитки

### Для монтажной фурнитуры (MountingHardware)

Минимальные требования:
- `name`: Название фурнитуры (обязательно)
- `retailPrice`: Розничная цена (обязательно)
- `calculationMethod`: Метод расчета (BY_QUANTITY, BY_LENGTH, BY_AREA, BY_RATIO, BY_INVERSE_RATIO)
- `calculationValue`: Значение для метода (зависит от метода)
- `useInCalculator`: Галочка "Использовать в калькуляторе" (важно!)
- `active`: Статус активности (по умолчанию true)

Для использования в калькуляторе:
- `useInCalculator` должно быть `true`
- Фурнитура должна быть **связана с номенклатурой** через таблицу `MountingHardwareRelation`

### Связь с номенклатурой (MountingHardwareRelation)

Таблица связывает фурнитуру с номенклатурами:

```prisma
model MountingHardwareRelation {
  id                 String   @id @default(cuid())
  mountingHardwareId String
  referenceType      String   // Тип номенклатуры: POST, LAG, PROFNASTIL, PANEL_3D, GATE, WICKET
  referenceId        String   // ID номенклатуры
  createdAt          DateTime @default(now())
  
  mountingHardware   MountingHardware @relation(fields: [mountingHardwareId], references: [id])
}
```

Примеры связей:
- `referenceType: "PANEL_3D"` + `referenceId: "panel-id"` - фурнитура для конкретной 3D-панели
- `referenceType: "GATE"` + `referenceId: "gate-id"` - фурнитура для конкретных ворот
- `referenceType: "WICKET"` + `referenceId: "wicket-id"` - фурнитура для конкретной калитки

## 🔧 Добавление связи в админке

### Работа по монтажу

1. Перейдите на страницу номенклатуры (например, 3D-панели)
2. В нижней части страницы найдите секцию "🔧 Связанные работы по монтажу"
3. Нажмите кнопку "Добавить работу"
4. Заполните форму:
   - **Название**: например, "Монтаж 3D-панели h-2"
   - **Категория**: MOUNTING (монтаж)
   - **Единица**: PCS (штук)
   - **Стоимость**: цена работы
   - ✅ **Использовать в калькуляторе**: установите галочку
   - **Связи**:
     - **Тип справочника**: выберите "3D-панели"
     - **ID номенклатуры**: выберите нужную панель
5. Сохраните

### Монтажная фурнитура

1. Перейдите на страницу номенклатуры (например, ворота)
2. В нижней части страницы найдите секцию "🔩 Связанная монтажная фурнитура"
3. Нажмите кнопку "Добавить фурнитуру"
4. Заполните форму:
   - **Название**: например, "Саморезы для ворот"
   - **Розничная цена**: цена за единицу
   - **Метод расчета**: выберите метод (BY_QUANTITY, BY_LENGTH, BY_AREA, BY_RATIO, BY_INVERSE_RATIO)
   - **Значение для метода**: количество единиц или значение коэффициента
   - ✅ **Использовать в калькуляторе**: установите галочку
   - **Связи**:
     - **Тип справочника**: выберите "Ворота"
     - **ID номенклатуры**: выберите нужные ворота
5. Сохраните

## 🧮 Методы расчета монтажной фурнитуры

### BY_QUANTITY
Количество рассчитывается по количеству основной номенклатуры.
- **Пример**: 2 самореза на 1 ворота

### BY_LENGTH
Количество рассчитывается по длине забора.
- **Пример**: 1 саморез на каждые 2 метра забора

### BY_AREA
Количество рассчитывается по площади забора.
- **Пример**: 4 самореза на каждый м² забора

### BY_RATIO
Количество рассчитывается как количество номенклатуры × коэффициент.
- **Пример**: коэффициент 0.5 означает 0.5 самореза на каждый столб

### BY_INVERSE_RATIO
Количество рассчитывается как количество номенклатуры / коэффициент.
- **Пример**: коэффициент 2 означает 1 саморез на каждые 2 столба

## 📊 Пример расчета

### Сценарий: Забор из 3D-панелей с воротами

```
Основные материалы:
- 3D-панели h-2: 20 шт × 100 ₽ = 2,000 ₽
- Ворота откатные 3м: 1 шт × 10,000 ₽ = 10,000 ₽
Итого материалов: 12,000 ₽

Связанные элементы:
- Работа "Монтаж 3D-панели": 1 шт × 2,000 ₽ = 2,000 ₽
- Работа "Монтаж ворот": 1 шт × 3,000 ₽ = 3,000 ₽
- Монтажная фурнитура (саморезы для ворот, BY_QUANTITY): 2 шт × 50 ₽ = 100 ₽

Итого с учетом связей: 17,100 ₽
```

### Сценарий: Забор из профнастила

```
Основные материалы:
- Профнастил С-8: 50 м² × 150 ₽/м² = 7,500 ₽

Связанные элементы:
- Работа "Монтаж профнастила": 1 работа × 3,000 ₽ = 3,000 ₽
- Монтажная фурнитура (саморезы, BY_AREA, 4 самореза/м²): 200 ₽

Итого с учетом связей: 10,500 ₽
```

## ⚠️ Важные моменты

1. **Галочка "Использовать в калькуляторе"**
   - Без этой галочки связанный элемент НЕ будет учтен в расчете
   - Проверьте галочку перед сохранением

2. **Метод расчета монтажной фурнитуры**
   - Должен соответствовать бизнес-логике
   - Убедитесь, что значение корректное (положительное число)

3. **Валидация связей**
   - Нельзя связать работу с собой (циклические связи)
   - Нельзя связать фурнитуру с собой

4. **Приоритеты**
   - Связанные элементы учитываются в порядке добавления
   - Можно изменить приоритет через поле `sortOrder`

5. **Активность**
   - Если номенклатура или связанный элемент деактивирован, он не будет учтен в расчете
   - Не забудьте деактивировать ненужные элементы вместо удаления

## 🔍 Проверка функциональности

### Как проверить, что связи работают

1. **В админке**
   - Откройте страницу номенклатуры
   - Проверьте, что разделы "Связанные работы" и "Связанная фурнитура" не пустые
   - Убедитесь, что галочки "Использовать в калькуляторе" установлены

2. **В калькуляторе**
   - Сделайте расчет забора
   - Проверьте раздел "Монтаж" в смете
   - Убедитесь, что связанные работы и фурнитура присутствуют
   - Проверьте, что цены корректно включены в итоговую сумму

### API endpoints

**Получение связанных работ:**
```
GET /api/admin/works/by-reference?referenceType=PANEL_3D&referenceId={id}
```

**Получение связанной фурнитуры:**
```
GET /api/admin/mounting-hardware/by-reference?referenceType=PANEL_3D&referenceId={id}
```

## 📝 Типы номенклатур для связей

- `POST` - Столбы
- `LAG` - Лаги
- `PROFNASTIL` - Профнастил
- `PICKET` - Штакетник (евроштакетник)
- `GATE` - Ворота
- `WICKET` - Калитки
- `PANEL_3D` - 3D-панели

## 🚀 Устранение неполадок

### Связи не отображаются в админке
1. Проверьте, что контейнер приложения запущен
2. Проверьте консоль браузера на ошибки
3. Обновите страницу (Ctrl+F5)

### Связи есть, но не учитываются в расчете
1. Проверьте галочку "Использовать в калькуляторе" на связанных элементах
2. Проверьте, что элементы активны (`active: true`)
3. Проверьте логи калькулятора на наличие ошибок

### Расчет дает некорректные результаты
1. Проверьте методы расчета монтажной фурнитуры
2. Проверьте, что значения `calculationValue` корректные
3. Убедитесь, что в админке не созданы циклические связи
4. Обновите страницу и сделайте новый расчет
