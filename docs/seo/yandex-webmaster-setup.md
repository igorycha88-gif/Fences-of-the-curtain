# Настройка Яндекс.Вебмастер

## Шаг 1: Регистрация
1. Перейдите на https://webmaster.yandex.ru/
2. Войдите под Яндекс-аккаунтом
3. Нажмите «Добавить сайт»
4. Введите URL: `https://zabor-i-naves.ru`

## Шаг 2: Подтверждение прав
Метатег уже добавлен в код сайта:
```html
<meta name="yandex-verification" content="b82b0cfe086d3936" />
```
Выберите способ «HTML-метатег» — сайт уже подтверждён.

## Шаг 3: Привязка региона
1. Перейдите в «Информация о сайте» → «Региональность»
2. Укажите регион: **Москва**
3. Дополнительно: **Московская область**
4. Это КРИТИЧЕСКИ ВАЖНО — без привязки сайта к Москве, он будет конкурировать по всей России

## Шаг 4: Отправка sitemap
1. Перейдите в «Индексирование» → «Файлы сайта»
2. Укажите путь: `https://zabor-i-naves.ru/sitemap.xml`
3. Нажмите «Добавить»

## Шаг 5: Проверка robots.txt
1. Перейдите в «Индексирование» → «Анализ robots.txt»
2. Убедитесь что:
   - `Allow: /` для публичных страниц
   - `Disallow: /admin` для административных
   - `Disallow: /api/auth`, `Disallow: /api/admin` для API
   - `Host: https://zabor-i-naves.ru` указан
   - `Sitemap: https://zabor-i-naves.ru/sitemap.xml` указан

## Шаг 6: Переобход страниц
После любых изменений на сайте:
1. Перейдите в «Индексирование» → «Переобход страниц»
2. Введите URL изменённой страницы
3. Нажмите «Отправить на переобход»

## Шаг 7: Мониторинг
Регулярно проверяйте:
- **«Диагностика»** — ошибки индексирования, проблемы с мета-тегами
- **«Представление в поиске»** — CTR, показы, клики
- **«Внешние ссылки»** — обратные ссылки на сайт
