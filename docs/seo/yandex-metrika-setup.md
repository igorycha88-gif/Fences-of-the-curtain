# Настройка Яндекс.Метрики

## Шаг 1: Создание счётчика
1. Перейдите на https://metrika.yandex.ru/
2. Войдите под Яндекс-аккаунтом
3. Нажмите «Добавить счётчик»
4. Заполните:
   - Имя счётчика: «Заборы и Навесы»
   - URL сайта: `https://zabor-i-naves.ru`
5. Включите:
   - Вебвизор (запись действий пользователей)
   - Карта кликов
   - Карта ссылок
   - Карта скроллинга
   - Аналитика форм
6. Нажмите «Создать счётчик»

## Шаг 2: Запись номера счётчика
Скопируйте номер счётчика (например, `12345678`).
Добавьте в `.env` файл:
```
NEXT_PUBLIC_YANDEX_METRIKA_ID=12345678
```

Код Метрики уже интегрирован в сайт и автоматически загрузится после добавления env-переменной.

## Шаг 3: Настройка целей
В интерфейсе Метрики создайте цели:

| Название | Тип | Идентификатор |
|----------|-----|---------------|
| Расчёт забора начат | JavaScript-событие | `calculator_start` |
| Расчёт забора завершён | JavaScript-событие | `calculator_complete` |
| Отправка контактной формы | JavaScript-событие | `contact_form_submit` |
| Клик по телефону | JavaScript-событие | `phone_click` |
| Просмотр портфолио | JavaScript-событие | `portfolio_view` |

### Как создать цель:
1. Перейдите в «Цели» → «Добавить цель»
2. Выберите тип «JavaScript-событие»
3. Укажите идентификатор из таблицы выше
4. Повторите для каждой цели

## Шаг 4: Проверка
1. Откройте сайт
2. Откройте Метрику → «Отчёты» → «Онлайн-визиты»
3. Убедитесь что ваш визит отображается
4. Проверьте срабатывание целей (совершите действие на сайте)

## События уже настроены в коде
Компонент `YandexMetrika.tsx` автоматически отправляет события:
- `calculator_start` — при начале расчёта
- `calculator_complete` — при завершении расчёта
- `contact_form_submit` — при отправке формы
- `phone_click` — при клике на телефон
- `portfolio_view` — при просмотре портфолио
