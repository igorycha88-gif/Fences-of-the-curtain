# Настройка Яндекс.Вебмастер

Данная инструкция поможет добавить сайт "Заборы и Навесы" в Яндекс.Вебмастер для отслеживания индексации.

## Шаг 1: Регистрация

1. Перейдите на [Яндекс.Вебмастер](https://webmaster.yandex.ru/)
2. Войдите в свой аккаунт Яндекс ID
3. Нажмите кнопку "Добавить сайт"

## Шаг 2: Добавление сайта

1. Введите адрес сайта: `https://zabor-i-naves.ru`
2. Выберите подходящий способ подтверждения прав на сайт

### Способы подтверждения:

#### 1. HTML-файл
- Скачайте файл `yandex_XXXXX.html`
- Положите его в корневую директорию `public/`
- Файл должен быть доступен по адресу `https://zabor-i-naves.ru/yandex_XXXXX.html`

#### 2. Meta-тег (рекомендуется)
- Добавьте следующий мета-тег в `src/app/layout.tsx`:
```tsx
<meta name="yandex-verification" content="XXXXXXXXXX" />
```

#### 3. DNS-запись
- Создайте TXT-запись для домена с указанным значением

## Шаг 3: Отправка sitemap.xml

1. После подтверждения прав, перейдите в раздел "Индексирование" → "Файлы Sitemap"
2. Нажмите "Добавить файл"
3. Введите URL: `https://zabor-i-naves.ru/sitemap.xml`
4. Нажмите "Добавить"

## Шаг 4: Проверка robots.txt

1. Перейдите в раздел "Инструменты" → "Анализ robots.txt"
2. Введите URL: `https://zabor-i-naves.ru/robots.txt`
3. Проверьте, что файл доступен и корректен

Текущий robots.txt:
```
User-agent: *
Allow: /

Disallow: /admin
Disallow: /api/auth
Disallow: /api/admin

Allow: /api/contact-info
Allow: /api/portfolio

Sitemap: https://zabor-i-naves.ru/sitemap.xml
```

## Шаг 5: Мониторинг

### Основные разделы:

1. **Индексирование** — статус индексации страниц
   - Посмотрите, сколько страниц в поиске
   - Проверьте исключённые страницы

2. **Поисковые запросы** — позиции и клики
   - Анализируйте по каким запросам сайт находят
   - Отслеживайте динамику позиций

3. **Ссылки** — внешние и внутренние ссылки
   - Проверьте качество внешних ссылок
   - Анализируйте структуру внутренних ссылок

4. **Диагностика сайта** — ошибки и предупреждения
   - Исправляйте найденные ошибки
   - Оптимизируйте сайт

## Рекомендации

- Регулярно проверяйте индексацию новых страниц (портфолио)
- Отслеживайте позиции по целевым запросам
- Анализируйте поведенческие факторы (CTR, время на сайте)
- Используйте отчеты для оптимизации контента
